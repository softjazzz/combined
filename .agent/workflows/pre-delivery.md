# 交付前验收检查

## 触发时机

当一个招标条款或 PRD 模块即将标记为"已完成"时，执行此检查。

## 步骤

### 1. 招标条款追溯

- [ ] 找到对应的招标原文条款编号（如 3.4.1）
- [ ] 确认 PRD 中该条款的状态已更新
- [ ] 確认招标原文中提到的**每一个具体举例**都能被系统命中

### 2. 代码完整性

- [ ] 后端 API 端点存在且有路由注册
- [ ] 前端有对应的页面/组件调用该 API
- [ ] 有单元测试覆盖核心逻辑

### 3. 数据验证

```bash
# 启动后端
cd "d:\大模型项目\lx0222\health-qc-monorepo\apps\medqc-web\backend"
python -m uvicorn app.main:app --host 0.0.0.0 --port 8001

# 运行单元测试
python -m pytest tests/ -v --tb=short
```

### 4. 浏览器验收

- [ ] 在工作站界面操作完整流程
- [ ] 截图保存关键界面作为验收证据
- [ ] 截图存放到 `docs/screenshots/` 或归入 walkthrough

### 5. 更新文档

- [ ] 更新 `docs/PRD-泸县验收收尾.md` 对应条款状态
- [ ] 如有设计文档变更，同步 `docs/plans/` 中的文件
- [ ] 执行 `/commit` 工作流提交

### 6. Gap 矩阵复查

- [ ] 重新检查 PRD §8 招标参数覆盖矩阵
- [ ] 确认新增已完成条款不会影响其他条款
