#### 1.1 创建科室规则（全新创建模式）

**步骤**:
1. 登录系统（使用 ADMIN 或 QC_MANAGER 账号）
2. 导航到 **科室规则管理** 页面
3. 点击 **[新增科室规则]** 按钮
4. 选择创建模式：**全新创建**
5. 填写表单：
   - 科室：选择 "测试心内科"
   - 规则编号：`MANUAL_TEST_001`
   - 规则名称：`手动测试规则-全新创建`
   - 规则描述：`这是一个手动测试的全新规则`
   - 规则分类：选择 "完整性"
   - 严重程度：选择 "严重"
   - 覆盖行为：选择 "覆盖配置"
   - 优先级：输入 `10`
6. 点击 **[确定]** 按钮

**预期结果**:
- [ ] 表单验证通过
- [ ] 规则创建成功，显示成功消息
