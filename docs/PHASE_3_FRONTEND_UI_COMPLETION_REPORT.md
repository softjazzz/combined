## 🚀 如何测试

### 1. 启动前端开发服务器

```bash
cd apps/medqc-web
npm run dev
```

前端将运行在 http://localhost:5173

### 2. 启动后端 API 服务器

```bash
cd apps/medqc-web/backend
source venv/bin/activate
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8001
```

后端 API 将运行在 http://localhost:8001

### 3. 访问科室规则管理页面

1. 登录系统（使用 ADMIN 或 QC_MANAGER 角色）
2. 导航到：**科室规则管理** (`/dashboard/department-rules`)
3. 测试以下功能：
   - 查看规则列表
   - 使用筛选功能
   - 创建新规则（两种模式）
   - 编辑现有规则
   - 发布草稿规则
   - 查看变更历史
   - 删除规则

### 4. API 文档

访问 Swagger UI 查看 API 文档：
- http://localhost:8001/docs
