## 2. 逐条对比分析

### LX-001: 入院记录-主诉中出现状/体征/疾病/病程的持续时间与病程不一致

#### 客户原始要求
**评分内容：** 主诉书写不规范或不能导出第一诊断。
**期望效果：** 需校验主诉中症状/体征/疾病持续时间与主诊断、年龄阶段是否逻辑一致（示例：主诉停经37+3周但主诊断为妊娠期糖尿病属于不匹配）。

#### 当前实现
**Description：** 检查主诉中描述的症状、体征、疾病或病程的持续时间与现病史中的病程记录是否一致。主诉应准确反映患者的主要症状及持续时间，与病程记录保持一致。
**Custom Prompt：** 无（使用默认模板）

#### 对比结论
- [ ] ✅ 完全一致
- [x] ⚠️ 需要调整：详见建议改进
- [ ] ❌ 理解偏差：

#### 建议改进
- 现状问题：当前只比较主诉与现病史的一致性，遗漏了主诉与最终诊断的逻辑校验及特殊人群年龄合理性，可能放过客户关注的场景。
- 调整建议：在描述和提示词中新增：①主诉症状需能支撑主诊断；②孕妇/儿童等特殊人群需与年龄阶段匹配；提示词要求列出不一致证据。

### LX-002: 入院记录-现病史缺少主要临床表现

#### 客户原始要求
**评分内容：** 现病史记录不全或描述不清（包括发病的时间、起病缓急、主要症状、一般情况）。

#### 当前实现
**Description：** 检查现病史是否包含患者的主要临床表现，包括主要症状、体征、病程发展等关键信息。现病史应详细描述患者的病情发展过程。
**Custom Prompt：** 无（使用默认模板）

#### 对比结论
- [ ] ✅ 完全一致
- [x] ⚠️ 需要调整：详见建议改进
- [ ] ❌ 理解偏差：

- 调整建议：把三大要素写入描述和提示词清单，要求LLM逐项确认并在缺项时输出具体字段。
