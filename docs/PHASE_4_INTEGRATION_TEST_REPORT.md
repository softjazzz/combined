## 🔧 性能优化建议

### 数据库优化

1. **确保索引存在**:
   - `idx_qc_rules_scope_department` - 科室规则查询
   - `idx_qc_rules_status_active` - 状态和激活状态查询
   - `idx_qc_rules_parent_rule` - 父规则关联查询
   - `idx_qc_rules_effective_period` - 生效期查询
   - `idx_qc_rule_change_logs_rule_id` - 变更历史查询

2. **定期维护**:
   ```sql
   VACUUM ANALYZE qc_rules;
   VACUUM ANALYZE qc_rule_change_logs;
   ```

3. **监控慢查询**:
   - 启用 `pg_stat_statements` 扩展
   - 设置 `log_min_duration_statement = 1000`

### 应用层优化

1. **前端优化**:
   - 使用虚拟滚动处理大量数据
   - 实现客户端缓存
   - 优化表格渲染性能

2. **后端优化**:
   - 添加 Redis 缓存层
   - 实现查询结果缓存
   - 优化 RPC 函数性能
