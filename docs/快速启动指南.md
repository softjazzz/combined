## 1. 项目概览

### 1.1 项目简介

**病案质控系统** 是一个基于 AI 技术的智能医疗质量控制平台，通过结合大语言模型（LLM）智能分析和规则引擎双重验证，为医疗机构提供高效、准确的病案质量评估服务。

### 1.2 技术栈

**前端**:
- Vue 3 + TypeScript + Vite
- Ant Design Vue 4.x
- Pinia (状态管理)
- ECharts (数据可视化)

**后端**:
- FastAPI (Python)
- PostgreSQL + Supabase
- Redis (缓存)
- OpenAI GPT / DeepSeek (LLM)

### 1.3 项目结构

```
health-qc-monorepo/
├── apps/
│   ├── medqc-web/              # 主应用
│   │   ├── src/                # 前端源码
│   │   ├── backend/            # 后端源码
│   │   └── supabase/           # 数据库脚本
│   └── yibao-web/              # 医保规则管理
├── packages/                    # 共享包
├── docs/                        # 文档
│   ├── PRD_病案质控系统产品需求文档.md
│   ├── TDD_病案质控系统技术设计文档.md
│   ├── API接口清单.md
│   ├── 开发计划_2025Q1.md
│   └── 任务清单_2025Q1.md
└── MedQC/                       # 质控标准数据
```

## 3. 快速启动

### 3.1 克隆项目

```bash
# 克隆仓库
git clone <repository-url>
cd health-qc-monorepo

# 查看项目结构
tree -L 2 -I 'node_modules|.git'
```

### 3.2 前端启动

```bash
# 进入前端目录
cd apps/medqc-web

# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 访问地址: http://localhost:3000
```

**预期输出**:
```
  VITE v6.0.5  ready in 608 ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: http://172.22.16.8:3000/
  ➜  press h + enter to show help
```

### 3.3 后端启动

```bash
# 进入后端目录
cd apps/medqc-web/backend

# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境
source .venv/bin/activate  # Mac/Linux
# .venv\Scripts\activate   # Windows

# 安装依赖
pip install -r requirements.txt

# 启动开发服务器
uvicorn app.main:app --reload --port 8001

# 访问地址: http://localhost:8001
# API文档: http://localhost:8001/docs
```

**预期输出**:
```
INFO:     Uvicorn running on http://0.0.0.0:8001 (Press CTRL+C to quit)
INFO:     Started reloader process [75128] using WatchFiles
INFO:     Started server process [75131]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
```

### 3.4 数据库初始化

```bash
# 使用 Supabase CLI
cd apps/medqc-web
supabase init
supabase db reset

# 或使用 SQL 脚本
psql -U postgres -d medqc -f supabase/setup-database.sql
```

### 3.5 环境变量配置

**前端 `.env`**:
```bash
# apps/medqc-web/.env
VITE_API_BASE_URL=http://localhost:8001
VITE_SUPABASE_URL=your-supabase-url
VITE_SUPABASE_ANON_KEY=your-supabase-key
```

**后端 `.env`**:
```bash
# apps/medqc-web/backend/.env
DATABASE_URL=postgresql://user:pass@localhost:5432/medqc
REDIS_URL=redis://localhost:6379/0
JWT_SECRET_KEY=your-secret-key
OPENAI_API_KEY=sk-...
DEEPSEEK_API_KEY=...
```

### 3.6 验证安装

```bash

curl http://localhost:3000

# 检查后端
curl http://localhost:8001/api/health

# 预期响应

  "status": "healthy",
```

## 4. 开发工作流

### 4.1 分支策略

```bash
# 创建功能分支
git checkout -b feature/T1.1.1-unified-llm-client

# 开发完成后提交
git add .
git commit -m "feat: 统一LLM客户端接口 (#T1.1.1)"

# 推送到远程
git push origin feature/T1.1.1-unified-llm-client

# 创建 Pull Request
```

**分支命名规范**:
- `feature/*` - 新功能
- `fix/*` - Bug修复
- `refactor/*` - 重构
- `docs/*` - 文档更新
- `test/*` - 测试相关

### 4.2 提交规范

使用 [Conventional Commits](https://www.conventionalcommits.org/) 规范:

```bash
# 格式
<type>(<scope>): <subject>

# 示例
feat(llm): 统一LLM客户端接口
fix(api): 修复申诉API响应格式错误
refactor(qc): 重构质控引擎代码
docs(readme): 更新快速启动指南
test(unit): 添加LLM客户端单元测试
```

**Type 类型**:
- `feat`: 新功能
- `fix`: Bug修复
- `refactor`: 重构
- `docs`: 文档
- `test`: 测试
- `chore`: 构建/工具
- `style`: 代码格式

### 4.3 代码审查

**提交 PR 前检查清单**:
- [ ] 代码符合规范（ESLint/Black通过）
- [ ] 单元测试通过
- [ ] 集成测试通过
- [ ] 文档已更新
- [ ] 无 TypeScript 错误
- [ ] 无 console.log 调试代码

**Code Review 要点**:
- 代码可读性
- 性能影响
- 安全性
- 测试覆盖率
- 文档完整性

### 4.4 测试流程

```bash
# 前端测试
cd apps/medqc-web
pnpm test              # 运行所有测试
pnpm test:unit         # 单元测试
pnpm test:e2e          # E2E测试

# 后端测试
cd apps/medqc-web/backend
pytest                 # 运行所有测试
pytest tests/unit/     # 单元测试
pytest tests/integration/  # 集成测试
pytest --cov           # 测试覆盖率
```

### 4.5 调试技巧

**前端调试**:

## 5. 常见问题

### 5.1 前端问题

**Q: pnpm install 失败**
```bash
# 清理缓存
pnpm store prune

# 删除 node_modules 和 lock 文件
rm -rf node_modules pnpm-lock.yaml

# 重新安装
pnpm install
```

**Q: Vite 代理不工作**
```javascript
// 检查 vite.config.ts
export default defineConfig({
  server: {
    proxy: {
      '/api': {
        target: 'http://127.0.0.1:8001',
        changeOrigin: true
      }
    }
  }
})
```

**Q: TypeScript 类型错误**
```bash
# 重新生成类型
pnpm run type-check

# 清理缓存
rm -rf node_modules/.vite
```

### 5.2 后端问题

**Q: uvicorn 启动失败**
```bash
# 检查端口占用
lsof -i :8001

# 杀死占用进程
kill -9 <PID>

# 使用其他端口
uvicorn app.main:app --reload --port 8002
```

**Q: 数据库连接失败**
```bash
# 检查 PostgreSQL 状态
pg_isready

# 检查连接字符串
echo $DATABASE_URL

# 测试连接
psql $DATABASE_URL
```

**Q: LLM API 调用失败**
```bash
# 检查 API Key
echo $OPENAI_API_KEY

# 测试 API
curl https://api.openai.com/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY"
```

### 5.3 数据库问题

**Q: 迁移失败**
```bash
# 回滚迁移
supabase db reset

# 重新运行迁移
supabase db push
```

**Q: 数据不一致**
```bash
# 验证数据库
psql -d medqc -f supabase/setup/verify_database.sql

# 修复数据
psql -d medqc -f supabase/fixes/database_simple_fix.sql
```
