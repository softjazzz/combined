## 概述

### 设计原则

1. **LLM 输出 = 模板输入**：LLM 结构化提取的字段名和格式与病案首页模板期望的输入完全一致，无需额外映射层。
2. **编码与文本双轨制**：对于有编码要求的字段（如性别、婚姻状况），同时提供编码字段和文本字段，增强容错能力。
3. **空值友好**：未提取到的字段填 `null` 或不返回，不影响其他字段的回填。

### 数据来源

- 病历原文（入院记录、出院小结、手术记录、病程记录等）
- LLM 多模块并行提取

### 数据去向

- 病案首页 HM 模板渲染（通过 `frontPageDraftToDeMap.ts` 转换为 DE 元素映射）
- DRG/DIP 分组计算
- 病案质控规则校验

  "basic_info": { },        // 患者基本信息

  "other_medical_info": { }, // 其他医疗信息

}
