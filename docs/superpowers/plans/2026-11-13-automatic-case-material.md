# 单病历自动取材（替代人工窗口准入）

基线：2907213e1。用户确认正常单病历自动一致性读取 CDM、保存不可变材料；缺材料只影响相关规则。

## 实施顺序

1. 先补取消人工窗口、来源缺表隔离和权限拒绝的回归，再修改捕获准入。
2. 在原只读 REPEATABLE READ 事务内记录来源可用性、可读取的逐键发布回执；不把回执等同于上游覆盖完整，不虚构发布正文哈希。
3. 可用性进入请求材料指纹及逐规则绑定；受影响规则待核，独立规则继续；原技术错误和身份保护保留。历史快照缺新增字段时保持原合同。
4. 合成材料验证正式 Binding/Finalizer 与保存读回；隔离 PG 验证事务一致性与发布回执。
5. 定向检查、一次独立复审、中文本地提交。不推送、不部署。

## 裁定

- 不要求为正常取材临时填写 QC_CDM_CAPTURE_WINDOW_UNTIL；原历史错误仍可安全显示。
- 临床表缺失不是数据库连接/权限失败。前者作为来源缺口，后者保留技术错误。
- 发布回执权限尚未现场交付：元数据不可读显式记录，不能将其伪装为已核版本，也不以此要求人工窗口。现有临床数据仍可自动捕获，未证明的临床缺失不得判缺陷。
- 既有 CDM 回执不含正文哈希与病例覆盖；不宣称已验证发布正文或全病历完整。
- 日常病程补充默认关闭；不修改同步代码与现场权限。
