# 08-02-02 引文安全诊断实现计划

> 执行方式：本会话直接实现，先补失败用例，再实现并做定向隔离验证；收尾做一次新上下文复核。

**Goal:** 使后续 08-02-02 引文拒绝可区分空引文、文书关联、空白和标点差异，保留原文引用及隐私保护。

**Architecture:** 只改出院意见提取器，在既有拒绝点增加固定类别及受限的 `doc_XX` 本次调用内编号。仍抛出相同 ValueError，由既有边界记录停止原因/Token并返回 model_invalid_output。文本归一化仅用于诊断，不用于放行。

**Tech Stack:** Python、标准库 Unicode 字符类别、pytest/pytest-asyncio、固定合成客户端。

**Spec:** 用户本轮授权及本文件的约束；基线 157c1af83 的 C27 历史失败不可回填。

## 约束与方案选择

- 不调用模型、规则主流程或数据库，不修改配置/旧任务/结果/快照，不合并部署。
- 不修改共享解析器或保存合同；保留 unknown+空引文的原有合法分支。
- 选择在原 ValueError 拒绝点追加安全日志；不改变异常类型/结果，不记录原文、quote、模型返回、业务文书号或任意输入 ID。
- 仅已知输入且符合 `doc_\d{2}` 的局部编号可以记录；未知/非法编号只记 `-`。
- 仅做安全类别归因；规范化相似不等于来源或医学语义等价。

## Review Focus

- unknown+空字符串保持合法；非 unknown 的空/空白引文仍拒绝。
- 引文在其他文书中出现仍拒绝，不改选原文书。
- 仅空白、仅标点及二者混合差异仍拒绝；不删除否定、数字或数学符号以冒充相似。
- 未知/重复/漏配编号不回显外部输入或患者身份；日志只有固定类别与安全局部编号。
- 隐私包装器及不可重试合同不改；旧日志停止原因与 Token 信息继续保留。
