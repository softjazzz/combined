## 实现

- 同一Evidence Session完整读取药品与非药品医嘱。使用受约束语义提取分类，未执行不等于取消，不使用病例/文书ID名单、正文长度或血液关键词硬匹配。明确取消排除，未知与来源失败不伪装成无医嘱。
- 045与046共用病程有效性提取。计划、拒绝、取消、延期、标题或模板不能因正文较长被判为有效记录；简短实际记录可有效。045负责整份缺失；046没有有效记录时资料不足，有效记录才逐份检查字段。
- 044/045/046对外使用transfusion_order_present，不再把医嘱存在发布为performed_transfusion_confirmed。无医嘱的不适用文案也不宣称患者未实际输血。
- 分类按64行、8000字符双限分批，禁止静默截断。一次执行缓存医嘱结果供三规则复用、病程结果供两规则复用，累计模型调用与token。全部响应严格校验索引、枚举及脱敏引用；原始坐标仍绑定同一快照。
- 补齐药品generic_name证据摘录，以及同文书ID多行、空格和数值ID引用兼容。重复业务文书的有效性冲突保留资料不足。
