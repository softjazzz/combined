# 智慧医保质控引擎使用说明（Yibao）

本文面向前后端开发者与实施同学，介绍医保质控引擎的工作方式、触发与命中条件、输入/输出格式、以及常见故障排查。

## 1. 引擎概览

- 承载形态：Supabase Edge Function `evaluate-rule`
- 规则来源：Postgres 表（`yibao_rules`、`yibao_rule_conditions`、`yibao_rule_actions`、`yibao_rule_triggers`）
- 功能要点：条件表达式 DSL（`all`/`any` 树 + 原子条件）、事件触发、内存缓存、批量评估、可选写库、返回 `ruleId/violationId`。

相关代码：`Yibao/supabase/functions/evaluate-rule/index.ts`

## 2. 事件与触发

- 事件字符串与触发器表严格匹配。默认事件：`order.drug.submit`。
- 触发器表：`yibao_rule_triggers (rule_id, event_type)`。

## 3. 条件表达式 DSL

- 结构：
  - 逻辑：`{ all: [...] }` / `{ any: [...] }`
  - 原子：`{ fact, op: '==|!=|>|>=|<|<=|in|not_in', value }`
- 常用 fact：`patient.age`、`patient.gender`、`visit.type`（`INPATIENT|OUTPATIENT`）、`order.drug_code`、`order.drug_name`。

示例：
```json
{
  "all": [
    { "fact": "visit.type", "op": "==", "value": "OUTPATIENT" },
    { "fact": "order.drug_code", "op": "==", "value": "DEMO_DRUG_INPATIENT" }
  ]
}
```

## 4. 输入与输出

- HTTP：`POST {SUPABASE_URL}/functions/v1/evaluate-rule`
- Headers：`Authorization: Bearer <ANON|SERVICE_ROLE>`、`Content-Type: application/json`

请求（单条）：
```json
{
  "event": "order.drug.submit",
  "record": true,
  "context": {
    "patient": { "age": 45, "gender": "M" },
    "visit":   { "id": "V123", "type": "OUTPATIENT" },
    "order":   { "drug_code": "DEMO_DRUG_INPATIENT", "drug_name": "示例住院专用药" }
  }
}
```

返回（单条）：
```json
{
  "decision": "block|warn|pass",
  "hits": [ { "ruleId": 12, "ruleCode": "DRUG_XXX", "severity": "warn", "action": "warn", "message": "...", "violationId": 345 } ],
  "performance": { "execution_time_ms": 12, "rules_evaluated": 20, "cache_hit_rate": 1 }
}
```

批量：
```json
{ "event": "order.drug.submit", "batch": true, "contexts": [ {"id":"ctx1", ...} ] }
```

## 5. 写入违规与忽略

- 写入：`record=true` 时把命中写入 `yibao_violations`，并在 `hits[i].violationId` 返回记录 ID。
- 忽略：`POST /functions/v1/violations?action=ignore`，体：`{ id, reason, note }`。

## 6. 规则创建与启用

通过 Edge Function 保存：`POST /functions/v1/rules?action=save`

最小示例：
```json
{
  "rule": { "code": "DRUG_VISIT_INPATIENT_ONLY", "name": "住院专用药限门诊", "rule_type": "visit_type", "severity": "block", "enabled": true },
  "conditions": [ { "expression_json": { "all": [
    {"fact":"visit.type","op":"==","value":"OUTPATIENT"},
    {"fact":"order.drug_code","op":"==","value":"DEMO_DRUG_INPATIENT"}
  ]}} ],
  "actions": [ { "action_type": "intercept", "message_template": "【拦截】{order.drug_name} 限住院患者使用" } ],
  "triggers": [ { "event_type": "order.drug.submit" } ]
}
```

表说明：`yibao_rules`（主表）、`yibao_rule_conditions`（条件）、`yibao_rule_actions`（动作/模板）、`yibao_rule_triggers`（触发）

## 7. 命中检查清单

1) 事件名正确（默认 `order.drug.submit`）  2) 规则启用  3) 条件与 `context` 对齐  4) 函数密钥配置正确  5) 种子/导入完成

## 8. 快速自测

```bash
curl -s -X POST "$SUPABASE_URL/functions/v1/evaluate-rule" \
 -H "Authorization: Bearer $SUPABASE_ANON_KEY" -H "Content-Type: application/json" \
 -d '{
   "event":"order.drug.submit","record":true,
   "context":{ "patient":{"age":30,"gender":"M"}, "visit":{"id":"V","type":"OUTPATIENT"},
                 "order":{"drug_code":"DEMO_DRUG_INPATIENT","drug_name":"示例住院专用药"} }
 }'
```

## 9. 性能参数

`BATCH_SIZE`、`MAX_CONCURRENT`、`CACHE_TTL_MS`、`ENABLE_PARALLEL` 通过环境变量配置；返回 `performance` 含时延与缓存信息。

## 10. precise 名称规则快速导入

- 生成：`scripts/generate-precise-rule-pack.ts` → `Yibao/generated/rule-pack-from-precise.json`
- 入库（推荐）：遍历该包调用 `/functions/v1/rules?action=save`；
- 本地演示：`scripts/import-precise-to-backend.ts` 写入 `apps/yibao-web/backend/medical_rules.json`（仅 mock，不会被 `evaluate-rule` 读取）。
