- 已在函数代码返回 CORS 头；生产请将 `Access-Control-Allow-Origin` 改为你的前端域名。

3) 测试
```bash
# 规则评估
curl -X POST https://<project>.supabase.co/functions/v1/evaluate-rule \
  -H "Authorization: Bearer <anon_key>" \
  -H "Content-Type: application/json" \
  -d '{"event":"drug_order","context":{"patient":{"age":30,"gender":"F"},"visit":{"type":"OUTPATIENT"},"order":{"drug_code":"DEMO_DRUG_INPATIENT"}},"record":true}'

# 违规列表
curl "https://<project>.supabase.co/functions/v1/violations?page=1&limit=10" \
  -H "Authorization: Bearer <anon_key>"

# Dashboard 统计
curl "https://<project>.supabase.co/functions/v1/statistics/dashboard" \
  -H "Authorization: Bearer <anon_key>"
```
