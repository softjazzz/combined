## 🚀 快速开始

### 步骤 1：刷新浏览器
- 访问：http://localhost:3000
- 或按 `F5` 刷新当前页面

### 步骤 2：进入测试页面
1. 在左侧菜单找到"LLM质控演示新版"
2. 点击进入测试页面
3. 确认页面正常加载

## 📞 问题反馈

### 如何报告问题
1. 记录问题描述
2. 记录复现步骤
3. 截图或录屏
4. 记录浏览器控制台错误

### 问题优先级
- **P0（严重）**：功能完全无法使用
- **P1（重要）**：功能部分无法使用
- **P2（一般）**：功能可用但体验不佳
- **P3（轻微）**：小问题，不影响使用
