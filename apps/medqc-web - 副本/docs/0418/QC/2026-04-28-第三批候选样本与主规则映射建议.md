输出目标：

## 2. 筛选口径

第三批不再重复纳入当前已在第一批/第二批主线上推进的家族：

- 第一批：
  - `SC-070` 会诊执行闭环
  - `SC-050` 上级查房内容问题
  - `SC-036` 异常检查结果未分析
- 第二批：
  - `SC-069` 会诊记录质量
  - `SC-039` 危急值完整性
  - `SC-146` 病程医嘱一致性

第三批优先看下面三类：

1. **现有规则已在库，且问题边界清楚**
2. **尽量依赖单文书正文，不依赖复杂 bundle 拼装**
3. **样本池现有分类口径已能承接，或只差很薄的一层映射补齐**

第二批的直接经验是：

- 跨文书、强依赖 bundle 证据的家族推进慢
- `missing` 往往不是 prompt 不够，而是证据没有进来
- 所以第三批优先选**首程 / 入院 / 日常病程 / 单份手术记录**这类单文书问题

## 5. 为什么这五类比其它待办更适合第三批

### 5.1 比 `SC-051 / SC-077` 更适合现在做

- 上级医师查房缺失/未及时书写仍偏 `hybrid`
- 需要时间轴和文书存在性一起判断
- 当前更像程序/混合增强，而不是纯语义主线

### 5.2 比 `SC-083 / SC-084 / SC-085` 更适合现在做

- `四级手术未 MDT` 价值很高，但对 `MDT / 会诊 / 术前讨论` 文书区分要求更高
- 如果第三批资源有限，建议先放在第四批前列观察位
- 当前可以保留样本：
  - `368602`
  - `287562`
  - `373216`

### 5.3 比输血链问题更适合现在做

- 输血链当前多落在 `todo_programmatic`
- 更像程序一致性 / 结构化时间比对问题
- 会和当前第三批“单文书语义回归”目标相冲突

## 6. 建议执行顺序

如果第三批只先开 `3` 个家族，建议顺序如下：

1. `SC-026` 首次病程诊断依据/鉴别诊断不足
2. `SC-008` 入院记录主诉/现病史不能导出第一诊断
3. `SC-033` 日常病程用药/异常指标缺分析缺处理

如果第三批允许扩到 `5` 个家族，再补：

4. `SC-027` 首次病程诊疗计划不具体
5. `SC-097` 手术记录缺项/描述不清

## 7. 建议给主线的最小动作

1. 先把上面 `5` 个问题族写入第三批候选白名单，不直接并入第二批回归脚本。
2. 每个问题族先固定 `1-3` 条 `visit_id` 真实样本，不追求一次铺满所有类似样本。
3. 对前四类优先复用当前样本池分类：
   - `first_course_reasoning`
   - `admission_consistency`
   - `daily_course_analysis`
4. `SC-097` 需要单独补一层“手术记录质量”问题族映射，不建议混到 `programmatic` 缺文书口径里。
