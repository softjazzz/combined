# 批量文件处理功能指南

## 🎯 功能概述

本系统新增了强大的批量文件处理功能，支持一次性上传和解析多个医疗文书文件，大大提高了工作效率。

## ✨ 主要特性

### 1. 文件上传增强

- ✅ **多文件选择**：支持一次性选择多个文件（最多20个）
- ✅ **格式支持**：PDF、DOC、DOCX、TXT等常见格式
- ✅ **大小限制**：单文件最大50MB
- ✅ **拖拽上传**：支持拖拽多个文件到上传区域
- ✅ **文件预览**：显示文件列表，包括名称、大小、状态等信息

### 2. 批量解析功能

- ✅ **一键解析**：点击按钮即可批量处理所有文件
- ✅ **并发处理**：智能队列管理，提高处理效率
- ✅ **实时进度**：显示整体进度条和单个文件状态
- ✅ **暂停/继续**：支持解析过程中的暂停和继续操作
- ✅ **取消功能**：可随时取消批量处理任务
- ✅ **错误处理**：单个文件失败不影响其他文件处理

### 3. 进度监控

- ✅ **整体进度条**：显示总体完成百分比
- ✅ **文件状态**：等待中、解析中、已完成、失败
- ✅ **当前处理**：显示正在处理的文件名称
- ✅ **统计信息**：成功/失败数量统计
- ✅ **置信度显示**：每个文件的解析置信度

### 4. 结果展示优化

- ✅ **分组查看**：按文件分组展示解析结果
- ✅ **树形结构**：医疗文书按分类层级展示
- ✅ **详情预览**：点击查看单个文件的详细解析结果
- ✅ **批量操作**：支持批量保存、导出等操作

## 🚀 使用指南

### 步骤1：访问批量导入页面

```
方式1：从智能导入页面点击"高级批量导入"按钮
方式2：直接访问 /dashboard/medical-records/batch-import
方式3：测试页面 /dashboard/test/batch-processor
```

### 步骤2：上传文件

1. **拖拽上传**：将多个文件拖拽到上传区域
2. **点击上传**：点击上传区域选择多个文件
3. **文件管理**：查看已上传文件列表，可删除不需要的文件

### 步骤3：批量解析

1. **开始解析**：点击"一键解析所有文件"按钮
2. **监控进度**：观察整体进度条和文件状态
3. **控制处理**：可暂停、继续或取消处理过程

### 步骤4：查看结果

1. **结果汇总**：查看批量处理统计信息
2. **详细结果**：点击"查看所有结果"查看详情
3. **单个查看**：点击单个文件查看解析结果

### 步骤5：保存导出

1. **批量保存**：将所有结果保存到数据库
2. **批量导出**：导出JSON或Excel格式
3. **单个操作**：对单个文件进行保存或导出

## 🔧 技术实现

### 核心技术栈

- **Vue 3 + TypeScript**：前端框架
- **Ant Design Vue**：UI组件库
- **文件处理**：FileReader API、FormData
- **状态管理**：Vue 3 Composition API
- **并发控制**：Promise队列管理

const startBatchProcessing = async () => {

## 📈 性能优化

### 优化策略

- **并发控制**：避免同时处理过多文件
- **内存管理**：及时清理文件预览URL
- **进度节流**：避免频繁的进度更新
- **错误隔离**：单个文件错误不影响整体处理

### 限制设置

- **文件数量**：最多20个文件
- **文件大小**：单文件最大50MB
- **并发数量**：同时处理1-3个文件
- **超时设置**：单文件处理超时5分钟

## 🚨 注意事项

### 使用建议

1. **文件准备**：确保文件格式正确，内容清晰
2. **网络稳定**：批量处理需要稳定的网络连接
3. **耐心等待**：大文件或多文件处理需要时间
4. **及时保存**：处理完成后及时保存结果

### 常见问题

1. **上传失败**：检查文件格式和大小限制
2. **解析失败**：检查文件内容是否为医疗文书
3. **进度卡住**：可尝试暂停后继续或取消重试
4. **结果丢失**：确保在页面刷新前保存结果
