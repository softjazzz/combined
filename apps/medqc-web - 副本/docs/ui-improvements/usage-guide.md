# 医疗记录详情页面增强视图使用指南

## 🚀 快速开始

### 1. 访问增强视图
1. 进入任意医疗记录详情页面
2. 在页面顶部找到视图切换按钮组
3. 点击 **"增强视图"** 按钮切换到新界面

```
[经典视图] [增强视图] ← 点击这里
```

### 2. 界面布局说明
增强视图采用双栏布局设计：
- **左侧**: 增强内容查看器 - 显示病历原始文本
- **右侧**: 信息面板 - 包含患者信息和文档分类

## 📖 内容查看器使用指南

### 🔍 搜索功能
1. **开始搜索**
   - 在顶部搜索框中输入关键词
   - 按回车键或点击搜索按钮
   - 匹配的文本会自动高亮显示

2. **搜索导航**
   - 使用 ⬆️ ⬇️ 按钮在匹配项间跳转
   - 查看搜索统计信息："找到 X 个匹配项 (第 Y 个)"
   - 点击 ❌ 按钮清除搜索结果

### ⚙️ 个性化设置
点击设置按钮 ⚙️ 打开设置菜单：

1. **字体大小**: 拖动滑块调整 (12px - 20px)
2. **行间距**: 调整行高 (1.2 - 2.0倍)
3. **自动换行**: 开启/关闭文本自动换行
4. **显示行号**: 开启/关闭左侧行号显示

### 🖥️ 全屏模式
- 点击全屏按钮 ⛶ 进入全屏阅读模式
- 按 ESC 键或点击退出全屏按钮退出
- 全屏模式下所有功能保持可用

### 📋 复制功能
- 点击复制按钮 📋 复制全部内容到剪贴板
- 也可以手动选择文本进行复制
- 支持键盘快捷键 Ctrl+C (选中文本时)

### 🧭 快速导航
如果文档包含章节标题，会在底部显示导航区域：
- 点击章节标题快速跳转到对应位置
- 自动识别常见的章节格式

## 📁 文档分类使用指南

### 📊 分类概览
右侧顶部显示分类统计信息：
- **总文档数**: 当前记录包含的文档总数
- **AI分类**: 通过AI自动分类的文档数量
- **分类类型**: 不同文档类型的数量
- **平均置信度**: AI分类的平均置信度

### 🌳 视图模式切换
使用视图切换按钮选择不同的展示方式：

#### 树形视图 🌲
- 按文档类型分组显示
- 层次化的文件夹结构
- 显示每个分类下的文档数量
- 点击展开/收起分类

#### 网格视图 ⊞
- 卡片式展示每个文档
- 显示文档图标、标题、类型
- 显示分类方法和置信度
- 适合快速浏览

#### 列表视图 ☰
- 详细的列表形式
- 显示完整的文档信息
- 包含操作按钮 (查看/编辑)
- 适合详细查看

### 🔧 筛选功能
点击筛选按钮 🔽 选择筛选条件：
- **全部文档**: 显示所有文档
- **AI分类**: 仅显示AI自动分类的文档
- **手动分类**: 仅显示人工分类的文档
- **高置信度**: 仅显示置信度>80%的文档

### 🔍 文档搜索
在搜索框中输入关键词搜索文档：
- 支持按文档标题搜索
- 支持按文档类型搜索
- 支持按文档内容搜索
- 实时显示搜索结果

### 🎯 置信度理解
AI分类的置信度用颜色和百分比表示：
- 🟢 **绿色 (≥90%)**: 分类非常准确，可以信任
- 🔵 **蓝色 (≥70%)**: 分类较为准确，建议检查
- 🟠 **橙色 (≥50%)**: 分类一般，需要人工确认
- 🔴 **红色 (<50%)**: 分类不确定，需要重新分类

### ⚡ 快速操作
右侧底部的快速操作区域：
- **🔄 重新分类**: 重新执行AI分类
- **📤 导出分类**: 导出分类结果
- **✅ 验证分类**: 验证分类准确性

## 📱 移动端使用

### 响应式适配
- **平板设备**: 自动切换为单栏布局
- **手机设备**: 紧凑布局，优化触控操作
- **横屏模式**: 自动调整为最佳显示效果

### 触控操作
- **双击**: 快速缩放内容
- **长按**: 选择文本进行复制
- **滑动**: 在搜索结果间快速切换

## ⌨️ 键盘快捷键

### 全局快捷键
- **Ctrl + F**: 聚焦搜索框
- **Ctrl + C**: 复制选中内容 (无选中时复制全部)
- **ESC**: 退出全屏模式

### 搜索快捷键
- **Enter**: 执行搜索
- **F3 / Ctrl + G**: 下一个匹配项
- **Shift + F3 / Ctrl + Shift + G**: 上一个匹配项

## 🔧 故障排除

### 常见问题

#### Q: 搜索功能不工作？
A: 请确保：
- 输入了有效的搜索关键词
- 文档内容已完全加载
- 尝试刷新页面重新加载

#### Q: 文档分类显示不正确？
A: 可以尝试：
- 点击"刷新分类"按钮
- 使用"重新分类"功能
- 检查网络连接是否正常

#### Q: 个性化设置不保存？
A: 请检查：
- 浏览器是否允许本地存储
- 是否在隐私模式下浏览
- 尝试清除浏览器缓存后重新设置

#### Q: 移动端显示异常？
A: 建议：
- 刷新页面
- 检查浏览器版本是否过旧
- 尝试横屏/竖屏切换

### 性能优化建议
- **大文档**: 使用搜索功能快速定位，避免滚动浏览
- **多文档**: 使用筛选功能减少显示数量
- **慢网络**: 等待内容完全加载后再进行操作
