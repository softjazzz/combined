# 医疗文书分类算法版本管理

## 📋 概述

本文档介绍了新增的医疗文书分类算法版本管理功能，该功能允许管理员在不同的分类算法版本之间进行切换，并监控系统性能。

## 🎯 功能特性

### ✅ 核心功能
- **多版本支持**：支持基础版本、增强版本、先进版本三种算法
- **动态切换**：无需重启系统即可切换算法版本
- **性能监控**：实时监控分类性能和使用统计
- **健康检查**：系统健康状态检查和诊断
- **回退机制**：自动回退到稳定版本的安全机制

### 🔧 版本说明

#### 1. 基础版本 (Basic)
- **特点**：简单关键词匹配算法
- **优势**：稳定可靠，处理速度快
- **适用场景**：系统负载高时的备用方案

#### 2. 增强版本 (Enhanced) 
- **特点**：层级化分类算法
- **优势**：分类准确度较高，支持复杂文书识别
- **适用场景**：日常生产环境推荐使用

#### 3. 先进版本 (Advanced)
- **特点**：基于MVP测试验证的高精度算法
- **优势**：最高的分类准确度，支持多格式识别
- **适用场景**：对准确度要求极高的场景

## 🚀 使用指南

### 访问版本管理

1. **登录系统**：使用管理员账户登录
2. **进入设置**：点击左侧菜单的"系统设置"
3. **选择标签**：点击"分类算法"标签页

### 版本切换操作

1. **查看当前版本**：在版本信息面板查看当前使用的算法版本
2. **选择目标版本**：在版本切换面板选择要切换的版本
3. **执行切换**：点击"切换到选中版本"按钮
4. **确认结果**：系统会显示切换结果和状态

### 性能监控

版本管理界面提供以下性能指标：

- **总请求数**：系统处理的分类请求总数
- **成功率**：分类成功的请求百分比
- **平均处理时间**：每次分类请求的平均耗时
- **版本使用分布**：各版本的使用次数统计

### 健康检查

定期运行健康检查以确保系统正常运行：

1. 点击"运行健康检查"按钮
2. 系统会自动测试分类功能和配置有效性
3. 查看检查结果和建议

## 🔧 API接口

### 版本信息
```http
GET /api/enhanced-classification/version/info
```

### 版本切换
```http
POST /api/enhanced-classification/version/switch
Content-Type: application/json

{
  "version": "advanced"
}
```

### 性能统计
```http
GET /api/enhanced-classification/performance/stats
```

### 健康检查
```http
GET /api/enhanced-classification/health
```

## ⚠️ 注意事项

### 权限要求
- 版本管理功能仅对**管理员用户**开放
- 需要`admin`角色权限才能访问

### 安全机制
- **自动回退**：如果新版本出现问题，系统会自动回退到稳定版本
- **配置验证**：切换前会验证配置的有效性
- **性能监控**：持续监控系统性能，及时发现问题

### 最佳实践
1. **测试环境验证**：在生产环境切换前，先在测试环境验证
2. **低峰期切换**：建议在系统负载较低时进行版本切换
3. **监控观察**：切换后密切观察系统性能指标
4. **备份配置**：切换前备份当前配置

## 🐛 故障排除

### 常见问题

#### 1. 版本切换失败
- **检查权限**：确认当前用户具有管理员权限
- **检查网络**：确认网络连接正常
- **查看日志**：检查系统日志获取详细错误信息

#### 2. 性能下降
- **检查版本**：确认当前使用的版本是否合适
- **监控资源**：检查系统资源使用情况
- **考虑回退**：如有必要，回退到稳定版本

#### 3. 分类结果异常
- **运行健康检查**：使用健康检查功能诊断问题
- **测试分类功能**：使用测试页面验证分类效果
- **检查配置**：确认算法配置正确
