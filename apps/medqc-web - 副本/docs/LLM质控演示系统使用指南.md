# LLM质控演示系统使用指南

## 📋 系统概述

LLM质控演示系统是一个完整的医疗质控流程演示平台，展示了基于大语言模型的智能质控规则执行、医生端通知处理和申诉管理的完整工作流程。

## 🚀 快速开始

### 访问方式
- **主演示页面**: http://localhost:3000/#/dashboard/llm-qc-demo-enhanced
- **导航路径**: 主菜单 → LLM质控演示增强版

### 基本操作
1. **开始演示**: 点击"开始演示"按钮启动完整演示流程
2. **步骤控制**: 使用"上一步"/"下一步"按钮或下拉选择器进行步骤跳转
3. **演示配置**: 点击"更多"→"演示配置"调整演示参数

## 📊 功能模块详解

### Phase 1: 基础框架搭建 ✅
- **演示控制**: 开始/暂停/停止/重播演示
- **进度跟踪**: 实时显示演示进度和当前步骤
- **状态管理**: 自动保存和恢复演示状态
- **配置管理**: 自定义演示参数和行为

### Phase 2: 质控规则演示 ✅
- **规则选择**: 选择和配置质控规则
- **分析过程**: 实时展示LLM分析步骤
- **结果展示**: 详细的质控分析结果和评分
- **可视化**: 分析过程的图表和统计信息

### Phase 3: 医生端通知模拟 ✅
- **通知接收**: 模拟医生工作站接收质控通知
- **通知管理**: 筛选、排序、分页和批量操作
- **详情查看**: 完整的质控结果详情和操作选项
- **实时更新**: 自动刷新和实时通知推送

### Phase 4: 申诉功能实现 ✅
- **申诉提交**: 完整的申诉表单和文件上传
- **申诉管理**: 申诉列表、筛选和批量操作
- **审核流程**: 自动化的申诉审核和状态管理
- **结果反馈**: 审核结果通知和质控结果更新

### Phase 5: 系统整合和优化 ✅
- **数据持久化**: 本地存储和状态恢复
- **导入导出**: 演示数据的备份和恢复
- **性能优化**: 响应式设计和动画效果
- **用户体验**: 统一的界面风格和交互模式

## 🎯 核心功能使用

### 1. 演示控制面板
```
[开始演示] [暂停] [停止] [重播] | [上一步] [步骤选择器] [下一步] | [更多▼]
```

**主要操作**:
- **开始演示**: 启动自动演示流程
- **步骤跳转**: 快速跳转到指定演示步骤
- **重播演示**: 重置所有状态，重新开始演示
- **更多操作**: 导出/导入数据、清除状态、演示配置

### 2. 质控规则配置
- **规则选择**: 从预设规则库中选择质控规则
- **参数配置**: 调整规则参数和阈值
- **测试记录**: 选择用于演示的病历记录
- **分析启动**: 开始LLM质控分析过程

### 3. 通知处理流程
- **通知列表**: 查看所有质控通知
- **筛选功能**: 按类型、严重程度、状态筛选
- **批量操作**: 批量确认、忽略或处理通知
- **详情查看**: 查看完整的质控分析结果

### 4. 申诉管理系统
- **申诉提交**: 
  - 申诉类型: 质量争议、规则质疑、数据纠正、流程申诉
  - 优先级: 低、中、高、紧急
  - 文件上传: 支持多种格式的证据材料
- **申诉审核**:
  - 自动审核流程 (5秒开始，8秒完成)
  - 70%通过率的智能审核
  - 审核结果通知和反馈

## ⚙️ 高级配置

### 演示配置选项
- **自动推进**: 是否自动进行到下一步
- **步骤间隔**: 自动推进的时间间隔 (1-60秒)
- **详细日志**: 是否显示详细的操作日志
- **模拟延迟**: 是否启用真实的处理时间模拟

### 数据管理
- **状态保存**: 自动保存演示状态到本地存储 (24小时有效)
- **数据导出**: 导出完整的演示数据为JSON文件
- **数据导入**: 从JSON文件恢复演示状态
- **状态清除**: 清除所有保存的演示状态

## 🔧 故障排除

### 常见问题
1. **演示无法启动**: 检查是否选择了质控规则和测试记录
2. **状态丢失**: 检查浏览器本地存储是否被清除
3. **通知不显示**: 确保已完成质控分析步骤
4. **申诉提交失败**: 检查表单验证和必填项

### 性能优化建议
- 定期清除过期的演示状态
- 避免同时打开多个演示页面
- 使用现代浏览器以获得最佳性能
