## 📝 使用说明

### 访问新数据
1. 登录系统后访问医生工作站
2. 点击"患者列表"按钮查看所有10个患者
3. 选择任意患者查看详细的病历内容

### 关闭患者列表
- **方法1**：点击右上角的红色关闭按钮（×）
- **方法2**：点击底部的"关闭患者列表"按钮
- **方法3**：点击模态框外的背景区域

### 质控分析
- 选择患者后，系统会自动进行质控分析
- 可以查看详细的质控结果和建议
- 支持手动重新分析功能
