| 字段 | 值 |
| --- | --- |
| 容量承诺值（QPS） | 待填写 |
| 承诺口径 | 稳态阶段的最低稳定 QPS，乘以安全系数后取整 |
| 安全系数 | 0.8（默认） |
| 约束条件 | P95 <= 目标值 且 错误率 <= 目标值 |

## 容量承诺填写规则

1. 选择目标环境，固定 `base_url`、认证方式和请求混合。
2. 使用同一套脚本，按递增并发执行多轮压测。
3. 找到最后一轮仍然满足目标的稳态结果。
4. 容量承诺值 = `稳态 QPS * 0.8`，再向下取整到最容易沟通的整数值。
5. 如果希望更保守，可再减去 10% 作为上线缓冲。
