## 门控语义

- 无取材、标本、送病理、快速病理或病理来源触发：rejected_by_system，表示 SC-099 不适用。
- 仅手术名称有“切除/肿物/病损”等弱提示，或手术记录/病理来源不足：data_quality_gap。
- 存在病理来源或手术/术后记录中明确取材、标本、送病理触发：pass_to_second_gate。
- 历史 LLM issue evidence 不作为源文书证据。
