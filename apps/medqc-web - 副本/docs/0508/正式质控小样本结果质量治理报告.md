## 正式质控结果后处理准入策略草案

non_compliant 展示给客户前必须满足：

- 有触发证据。
- 有缺陷证据。
- evidence 原文可读且和 findings 匹配。
- 跨文书/时间链规则有对照证据。
- 技术异常不能作为缺陷。
- 数据缺口不能直接作为医生病历缺陷。

降级规则：

- provider error -> `technical_error`，不进入缺陷清单。
- 缺文书/缺医嘱/缺执行清单 -> `data_quality_gap`。
- evidence 不足 -> `uncertain/evidence_insufficient`。
- 时间链证明不足 -> `uncertain`。
- 规则口径过宽 -> `needs_rule_tuning`。

页面建议展示分层：

- 确认缺陷。
- 待复核。
- 数据缺口。
- 技术异常。
