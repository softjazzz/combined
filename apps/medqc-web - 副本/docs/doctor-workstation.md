# 医生工作站功能模块

## 概述

医生工作站是医疗质控系统的核心功能模块，为医生提供智能化的病历编辑和实时质控分析功能。该模块集成了富文本编辑器、质控分析引擎和可视化展示组件，实现了病历录入、质控检查、问题提示和改进建议的一体化工作流程。

## 核心功能

### 1. 智能病历编辑器

#### 功能特性
- **富文本编辑**：支持文本格式化（粗体、斜体、下划线）
- **模板快速插入**：提供主诉、现病史、体格检查、诊断等常用模板
- **自动保存草稿**：防抖机制自动保存，避免数据丢失
- **快捷键支持**：Ctrl+S保存，Tab键插入缩进
- **特殊符号插入**：医学符号和常用符号快速插入
- **实时字数统计**：显示当前编辑内容的字数
- **光标位置显示**：实时显示光标所在行列位置

#### 使用方法
1. 在编辑器中直接输入病历内容
2. 使用工具栏按钮进行文本格式化
3. 点击模板按钮快速插入标准化内容
4. 系统会自动保存草稿，无需手动保存

### 2. 实时质控分析

#### 功能特性
- **实时分析**：在病历编辑过程中提供即时质控反馈
- **多维度检查**：完整性、一致性、合理性、及时性、准确性
- **智能评分**：基于规则引擎的自动评分系统
- **问题定位**：精确定位质控问题所在位置
- **改进建议**：提供具体的改进建议和修改指导

#### 质控规则类型
1. **完整性检查**：检查必填字段是否完整
2. **一致性检查**：验证数据前后是否一致
3. **合理性检查**：判断诊断与症状是否匹配
4. **及时性检查**：检查记录时间是否及时
5. **准确性检查**：验证数据格式和范围

### 3. 质控结果可视化

#### 功能特性
- **评分仪表盘**：直观显示总体质控评分
- **等级评定**：A/B/C/D等级自动评定
- **进度条展示**：可视化评分进度
- **规则检查结果**：详细展示每个规则的检查结果
- **问题分类展示**：按严重程度分类显示问题
- **改进建议列表**：可操作的改进建议

#### 评分标准
- **A级（90-100分）**：优秀，病历质量很高
- **B级（80-89分）**：良好，病历质量较好
- **C级（70-79分）**：合格，病历质量一般
- **D级（<70分）**：不合格，需要重大改进

### 4. 多场景演示

#### 演示场景
1. **完整病历场景**：展示高质量病历的评分效果
2. **不完整病历场景**：演示缺失信息的识别和提示
3. **数据不一致场景**：展示逻辑一致性验证功能
4. **诊断不合理场景**：演示合理性判断和建议

```

### API接口
```
src/api/medical-records.ts
├── getDoctorWorkstationTemplates()    # 获取病历模板
├── saveMedicalRecordDraft()          # 保存病历草稿
├── getMedicalRecordDraft()           # 获取病历草稿

### 数据流程
1. **病历编辑** → 自动保存草稿 → 本地存储
2. **质控分析** → 调用分析引擎 → 返回分析结果
3. **结果展示** → 可视化组件 → 用户界面

## 使用指南

### 基本操作流程

#### 1. 创建新病历
1. 点击"新建病历"按钮
2. 填写患者基本信息（姓名、年龄、性别）
3. 选择科室和病历类型
4. 可选择快速模板
5. 点击"创建病历"完成创建

#### 2. 编辑病历内容
1. 在编辑器中输入病历内容
2. 使用工具栏进行文本格式化
3. 点击模板按钮插入标准内容
4. 系统自动保存草稿

#### 3. 进行质控分析
1. 点击"质控分析"按钮
2. 系统自动分析病历内容
3. 在右侧面板查看分析结果
4. 根据建议进行改进

#### 4. 应用改进建议
1. 查看质控分析结果
2. 点击建议旁的"应用"按钮
3. 系统自动应用改进建议
4. 重新进行质控分析验证

### 演示模式使用

#### 访问演示页面
1. 访问 `/demo` 路径
2. 查看功能介绍
3. 选择演示场景
4. 开始体验功能

#### 演示场景说明
- **完整病历**：展示标准病历的高质量评分
- **不完整病历**：演示缺失信息的识别
- **数据不一致**：展示逻辑验证功能
- **诊断不合理**：演示合理性判断

- **doctor**：医生角色，可以使用工作站功能
- **admin**：管理员角色，拥有所有权限

## 扩展开发

### 添加新的病历模板
1. 在 `getDoctorWorkstationTemplates()` 中添加模板数据
2. 定义模板的分类和内容
3. 配置必填字段和可选字段

### 扩展质控规则
1. 在质控分析引擎中添加新规则
2. 定义规则的检查逻辑
3. 配置评分权重和建议内容

### 自定义编辑器功能
1. 在 `MedicalRecordEditor.vue` 中添加新功能
2. 扩展工具栏按钮
3. 实现相应的编辑逻辑

## 注意事项

1. **数据安全**：当前演示版本使用模拟数据，生产环境需要连接真实数据库
2. **权限控制**：确保只有授权用户可以访问工作站功能
3. **性能优化**：大量数据时需要考虑分页和虚拟滚动
4. **浏览器兼容**：建议使用现代浏览器以获得最佳体验
