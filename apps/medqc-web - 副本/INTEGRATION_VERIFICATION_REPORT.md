## 🚀 **部署建议**

### 📋 立即可执行的步骤

#### 1. 数据库初始化 (优先级: 🔥 高)
```bash
# 在 Supabase SQL Editor 中按顺序执行
database/setup/database_init_complete.sql
database/setup/database_init_part2.sql
database/setup/database_init_part3.sql
database/setup/verify_database.sql
```

#### 2. 前端依赖安装 (优先级: 🔥 高)
```bash
# 安装 pnpm (推荐) 或使用 npm
npm install -g pnpm
pnpm install

# 或使用 npm
npm install
```

#### 3. 后端依赖安装 (优先级: 🔥 高)
```bash
cd production_system
pip install -r requirements.txt
```

#### 4. 环境变量配置 (优先级: 🔥 高)
```bash
# 确保 .env 文件包含正确的配置
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_key
OPENAI_API_KEY=your_openai_key  # 可选，用于 AI 功能
```

### 🎯 启动系统

#### 前端启动
```bash
pnpm dev
# 或 npm run dev
# 访问: http://localhost:5173
```

#### 后端启动
```bash
cd production_system
python main.py
# 访问: http://localhost:8001
# API 文档: http://localhost:8001/docs
```
