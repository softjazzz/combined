## 🏗️ 技术架构

### 前端技术栈
```
Vue.js 3 + TypeScript + Ant Design Vue
├── 组件化设计
├── 状态管理 (Pinia)
├── 路由管理 (Vue Router)
├── 富文本编辑器
└── 图表可视化
```

### 后端技术栈
```
FastAPI + Python + PostgreSQL
├── RESTful API设计
├── 异步处理机制
├── 数据库ORM (SQLAlchemy)
├── 缓存优化 (Redis)
└── 任务队列 (Celery)
```

### 数据库设计
```sql
-- 5个核心数据表
├── test_medical_records      # 测试病历表
├── test_scenarios           # 测试场景表
├── scenario_records         # 场景病历关联表
├── test_executions          # 测试执行记录表
└── medical_record_templates # 病历模板表
```
