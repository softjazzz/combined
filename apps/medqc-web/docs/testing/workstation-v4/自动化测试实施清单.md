# Workstation V4 自动化测试实施清单

## 1. 目标

建立一套可重复执行的 `workstation v4` 自动化测试闸门，优先保证：

- 主链路可运行
- 前后端接口可衔接
- 数据库关键表可验证
- 鉴权链路正确

## 4. 用例与断言明细

### A04 登录与鉴权

- 前置：存在可登录测试账号
- 步骤：
  1. 调登录接口拿 token
  2. 未带 token 请求规则页接口
  3. 带 token 请求规则页接口
- 断言：
  - 未登录返回 `401`
  - 登录后返回 200
  - 请求头包含 `Authorization: Bearer ...`

### A05-A07 V4 主页面

- 前置：登录成功
- 步骤：
  1. 打开 `/workstation-v4`
  2. 等待列表加载
  3. 切换三个阶段队列
  4. 选中病历并打开详情
  5. 切换 `病历详情 / 病案首页 / 结算清单`
- 断言：
  - 列表有数据或空态可识别
  - 阶段切换后无报错
  - 详情面板可打开且接口成功

### B01-B03 首页链路

- 前置：准备待生成草稿和待质控病历
- 步骤：
  1. 触发首页草稿生成
  2. 进入首页页签查看结果
  3. 保存首页
  4. 执行首页质控
- 断言：
  - `ai_frontpage_draft` 新增或更新时间变化
  - 首页保存接口成功
  - `qc_result` 或 `qc_results` 有新增或更新
  - `qc_defects` 在命中规则时新增记录
  - `medical_documents` 质控回写字段发生变化

### B04 结算质控

- 前置：准备待结算质控病历
- 步骤：
  1. 打开结算页签
  2. 执行结算质控
  3. 刷新结果面板
- 断言：
  - 接口返回成功
  - 页面结果区域出现数据
  - 相关结果表有新增或更新

### B05-B06 规则与 ICD

- 步骤：
  1. 打开规则页三个 tab
  2. 打开 ICD 页面或搜索抽屉
  3. 执行关键词搜索与节点展开
  4. 执行一次编码回填
- 断言：
  - 三个规则接口都返回 200
  - ICD 搜索结果非报错
  - 回填接口成功

## 5. 建议命令与落地方式

建议保留三层自动化：

- 工程层：`npm run build`、`npm run type-check`、`npm run test:unit:release`
- 接口层：复用现有脚本或新增 API smoke 脚本
- 页面层：用 Playwright 跑 V4 主链路

建议优先复用现有能力：

- `scripts/verify-schema.ts`
- `tests/e2e/*.spec.ts`
- `scripts/check-workstation-v4-p0.mjs`
- `scripts/run-workstation-v4-p0-acceptance.mjs`

## 6. 验收标准

自动化实施完成后，至少应做到：

- 一条命令可串行跑完 P0 自动化闸门
- 能输出失败点：工程、接口、页面、数据库四类之一
- 主链路失败时能定位到具体接口或具体表
- 可在测试环境重复执行，不依赖人工临时改数据
