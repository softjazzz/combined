# SC-020 入院诊断定向复核说明

## 复核口径

本轮 SC-020 只强化通用诊断准确性判断，不写入患者姓名、疾病名称或单个样本答案。

SC-020 的客户样本验证页链路按同一份入院记录问题族 bundle 判断：入院诊断是否覆盖现病史、专科查体、辅助检查、既往检查中的核心异常证据。如果诊断只是症状、体征或笼统描述，而病历已有较明确的病因、损伤部位、器官疾病、并发症或疾病性质，则判为诊断不准确或不完整；如果证据不足以形成明确疾病诊断，且诊断含“待查”“原因待查”“待排”“？”等不确定表达，则不强行判为不合格。

结构化输出新增以下字段，用于验收复现和回归比对：

- `admission_diagnoses`：入院诊断或初步诊断列表。
- `symptom_or_sign_only_diagnoses`：症状性、体征性或过宽诊断。
- `core_abnormal_evidence`：现病史、查体、辅助检查、既往检查中的核心异常证据。
- `diagnosis_coverage`：`covered` / `partially_covered` / `not_covered` / `uncertain`。
- `qc_result`：`non_compliant` / `compliant` / `uncertain`。
