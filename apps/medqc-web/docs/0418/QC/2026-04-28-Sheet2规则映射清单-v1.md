# 2026-04-28 Sheet2 规则映射清单 v1

## 1. 目标

这份清单用于把 [运行病历质控记录.xls](/d:/LLM/LX888/docs/运行病历质控记录.xls) `Sheet2` 的 `存在问题` 列，映射到项目库里的已有规则体系，明确：

- 哪些问题可以直接落到已有 `SC/LX/LXE` 规则
- 哪些问题需要扩展已有规则的语义实现
- 哪些问题虽然能找到近似规则，但还缺程序化证据链
- 哪些问题需要新增规则

当前目标不是一次性把 `Sheet2` 的每一条问题都直接自动质控出来，而是先把“问题口径 -> 规则口径 -> 实现方式”这条映射链固定下来。

## 2. 映射原则

映射不是只看“有没有同名规则”，而是按下面三层处理：

1. `direct_match`
   已有规则基本能直接承接该问题。

2. `extend_existing`
   规则库里有接近规则，但当前实现只覆盖存在性/时效性，尚未覆盖 `Sheet2` 所需的语义深度。

3. `new_rule`
   现有规则只覆盖了外围闭环，不能表达 `Sheet2` 的核心判错逻辑，需要新增规则或新增子规则。

同时，每个问题都会标记执行方式：

- `programmatic`
- `semantic`
- `hybrid`
- `manual`

- 需要优先补语义实现的高频问题

  - 记录写了“遵会诊意见”但实际医嘱/治疗未落实
  - 上级查房内容空洞、复制粘贴、身份错位
  - 异常检验结果未分析、病程过于简略、缺处理意见
  - 手术记录/术后首次病程内容缺项和逻辑错误

- 需要新增规则或新增子规则的部分
  - 会诊意见已写执行但实际未落实
  - 查房记录疑似代写/伪造
  - 输血时间、输血量、输血后评价跨文书一致性比对

另外还有 `114` 条问题目前仍落在 `manual_review`，这些大多属于：

- 纯病历内涵书写质量问题
- 复合问题一条文本里夹带多缺陷
- 现有关键词规则尚未拆细的交叉问题

这批问题不是不能做，而是需要第二轮把 `normalized_issue_family` 继续细拆。
