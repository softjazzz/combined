# 2026-04-29 SC 质控点与《四川省住院病历质量评定标准（2023 年版）》对照审计

本次审计只看两件事：

- 质控点要求是否与四川标准原文一致
- 对应文书映射是否与标准原文一致

不在本次范围：

- 各规则在真实样本上的命中效果
- 各规则 prompt 的模型效果优劣
- `LX` / `LXE` 扩展规则

## 2. 总体结论

当前 `146` 条 `SC` 规则的 **编号、名称、章节归属** 与四川标准 2023 版总体一致，章节结构可以完整对上：

- `3.x` 入院记录
- `4.x` 病程记录
- `5.x` 手术相关记录
- `6.x` 出院/死亡记录
- `7.x` 知情同意书
- `8.x` 辅助检查
- `9.x` 医嘱

本轮核对后的结论分三类：

- `大体正确`
  - 大多数 `SC` 规则的原始要求与标准一致，且主文书归属正确
- `已修正`
  - 确认了 `7` 条规则存在文书提示或跨文书映射偏差，当前工作区已修正
- `待后续增强`
  - 少数规则虽然主文书归属没错，但执行时仍需要跨文书联合取证，后续应继续在 evidence 侧增强

## 3. 章节级对照

### 3.1 入院记录 `3.x`

结论：

- 当前 `SC-001 ~ SC-020` 的规则要求与标准原文一致
- 主文书仍应是 `admission_record`
- 本轮未发现明确的章节级错映射

标准原文关键口径：

- `3.1.1` 无入院记录（或再次/多次入院记录）或 24 小时内入出院（死亡）记录
- `3.5.1` 主诉书写不规范或不能导出第一诊断
- `3.6.1 ~ 3.6.4` 重点围绕现病史的完整性、一致性与诊治经过

### 3.2 病程记录 `4.x`

结论：

- `SC-021 ~ SC-079` 整体章节归属正确
- 会诊、危急值、输血、上级查房等规则与标准原文一致
- 发现 `SC-065` 需要把“可替代阶段小结的文书”补进映射

标准原文关键口径：

- `4.1.1 ~ 4.1.7` 首次病程记录
- `4.6.1` 病程中无危急值报告及处理记录，或未详细记录时间、内容等关键信息
- `4.13.1 ~ 4.13.3` 上级医师首次查房/病情分析/诊疗意见
- `4.20.1 ~ 4.20.6` 会诊记录及执行闭环

### 3.3 手术相关记录 `5.x`

结论：

- `SC-080 ~ SC-115` 的条文编号和规则名称整体正确
- 当前最容易出错的是 **跨文书规则**：
  - 规则名写的是两个文书条件之一
  - 但规则源里只挂了单一文书
- 本轮主要修的就是这类偏差

标准原文关键口径：

- `5.2.1` 除急诊抢救外，住院患者手术必须有术前讨论，术者必须参加
- `5.2.2` 四级手术需要多学科讨论
- `5.3.1` 术前讨论的结论未记入病历
- `5.3.2` 结论记录不完整
- `5.4.1` 无术前一天内主刀医生查看病人的记录或无麻醉术前访视记录
- `5.14.1` 无术后首次病程记录或无麻醉术后访视记录
- `5.16.1` 术后三天无连续病程记录或无术后三天内上级医师查看病人记录
- `5.18.1` 择期非计划再次手术病程记录、术前小结中未对上一次手术做出总结或原因说明

### 3.4 出院/死亡记录 `6.x`

结论：

- `SC-116 ~ SC-127` 的要求和主文书 `discharge_record` 与标准一致
- 本轮未发现明确错映射

标准原文关键口径：

- `6.1.1` 出院病人无出院记录或死亡病人无死亡记录
- `6.1.6` 诊疗经过不全面、不详细
- `6.1.7` 无出院医嘱或出院医嘱不全
- `6.1.8` 出院带药不详细

### 3.5 知情同意书 / 辅助检查 / 医嘱 `7.x ~ 9.x`

结论：

- `SC-128 ~ SC-146` 与标准原文整体一致
- `SC-146` 作为 `病程记录 + 医嘱` 的跨文书规则，当前映射口径正确

## 4. 本轮已修正的问题

### 4.1 已在前序修正：`SC-084 / SC-085`

问题：

- 标准原文要求这两条归属 **术前讨论**
- 规则 prompt 文案里曾错误写成 `operation_record`

当前状态：

- 已修正为 `presurg_discussion`

### 4.2 本轮新修正的 5 条跨文书映射

| 规则     | 标准原文口径                                               | 修正前                                                             | 修正后                                                       |
| -------- | ---------------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------ |
| `SC-065` | 阶段小结可由交班/接班/转入/转出记录代替                    | 只挂 `summary_record`                                              | `summary_record + handoff/handover/transfer_in/transfer_out` |
| `SC-086` | 主刀医生查看病人记录 **或** 麻醉术前访视记录               | 只挂 `anesthesia_record` / 旧源甚至是 `operation_record`           | `presurg_summary + senior_course_record + anesthesia_record` |
| `SC-104` | 术后首次病程记录 **或** 麻醉术后访视记录                   | 只挂 `postsurg_firstcourse_record` / 旧源甚至是 `operation_record` | `postsurg_firstcourse_record + anesthesia_record`            |
| `SC-107` | 术后三天连续病程记录 **且** 术后三天内上级医师查看病人记录 | 只挂 `daily_course_record` / 旧源甚至是 `operation_record`         | `daily_course_record + senior_course_record`                 |
| `SC-113` | 病程记录、术前小结中未对上一次手术做总结或原因说明         | 只挂 `presurg_summary` / 旧源甚至是 `operation_record`             | `daily_course_record + presurg_summary`                      |

## 5. 当前仍建议继续增强的点

以下不属于“规则定义错误”，但属于“执行取证还应增强”：

### 5.1 `SC-039`

标准口径：

- `4.6.1` 病程中无危急值报告及处理记录，或未详细记录时间、内容等关键信息

当前结论：

- 文书归属 `daily_course_record` 是对的
- 但执行时仍要保证病历正文中真实的危急值处理记录能进入 bundle 证据

### 5.2 `SC-070`

标准口径：

- 申请会诊医师应在病程记录中记录会诊意见执行情况

当前结论：

- 主文书 `daily_course_record` 正确
- 但执行时仍需同时参考 `consultation_record` 作为 supporting evidence

### 5.3 `SC-146`

标准口径：

- 缺诊疗医嘱，或诊疗医嘱与病程记录不一致

当前结论：

- `daily_course_record + medical_order` 映射正确
- 但后续样本验证仍需继续维护跨文书时间一致性兜底

## 6. 当前审计结论

可以收口成一句话：

**SC 规则体系与《四川省住院病历质量评定标准（2023 年版）》在章节和条文要求上总体一致；本轮主要发现并修正的是 5 条跨文书映射偏差，外加前序已修正的 `SC-084 / SC-085` prompt 文书提示偏差。**

当前建议：

1. 以后新增或调整 `SC` 规则时，先按 PDF 条文判断它是“单文书”还是“跨文书”
2. `updated` 规则源与主规则源必须同步维护，不能一边修了另一边还停在旧 `operation_record`
3. 样本验证阶段优先继续推进语义规则回归，不再把这几条基础映射问题反复带入测试噪音
