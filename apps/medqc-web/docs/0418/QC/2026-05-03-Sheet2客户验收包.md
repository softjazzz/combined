### 可补规则（12）

- 定义：原始文书可回收，但现有主规则或跨文书链路无法精确覆盖人工锚点，属于规则能力缺口。
- 下一轮动作：优先补主规则、次规则重试与跨文书证据拼接，再回归样本验证页。
- 重点问题族：首次病程诊断依据/鉴别诊断/诊疗计划缺陷 x 4；病程记录缺分析/缺处理意见 x 3；输血时间/量/前后记录不一致 x 1；上级查房内容空洞/复制粘贴/身份异常；输血记录链缺失/不全 x 1；主治首次查房48小时；病程记录缺分析/缺处理意见 x 1
- 样例：
  - `Sheet2-R0066` / `SC-020`：入院记录诊断不全，患者无房颤，但入院记录心率和脉搏不等，首次病程记录中鉴别诊断不全面。 （规则不支持）
  - `Sheet2-R0073` / `SC-023`：入院查体无专科情况描述，患者入院时BP151/121mmHg，首次病程中未做分析、未提出诊疗计划。 （规则不支持）
  - `Sheet2-R0077` / `SC-074`：输血后评价记录时间记录错误，记录时间早于输血时间 （规则不支持）

### 需补源文书（34）

- 定义：人工问题可能成立，但当前缺少可核对的原始正文、诊断字段、执行清单或时序元数据。
- 下一轮动作：优先补 admission diagnosis、手术/会诊正文、执行清单与病程时间轴等源数据快照。
- 重点问题族：入院记录内容不完整/前后矛盾 x 5；病程记录缺分析/缺处理意见 x 5；病程记录病情变化记录不全 x 3；手术记录缺项/时间错误/逻辑不清/签名异常 x 3；诊疗医嘱与病程记录不一致 x 3
- 样例：
  - `Sheet2-R0030` / `SC-050`：三级医师查房执行不到位（主治医师查房写的是管床医生本人查房） （证据链不足）
  - `Sheet2-R0031` / `CL-275`：请会诊执行记录中复制粘贴严重，记录中“ 余同贵科！谢邀！我科愿随访”直接引用会诊意见未进行修改。 （证据链不足）
  - `Sheet2-R0042` / `SC-050`：9月2日上级查房医师为王标，但在分析病情时是孙治庆医师在查房，涉嫌伪造病历。 （证据链不足）

### 人工问题过宽/不可判（48）

- 定义：已经核到原始文书，但人工问题过宽、跨多个锚点或与现存正文冲突，无法按原句精确复现。
- 下一轮动作：建议客户下一轮把人工问题拆到单锚点、单文书、单日期，并保留原句截图。
- 重点问题族：入院记录内容不完整/前后矛盾 x 16；病程记录缺分析/缺处理意见 x 14；首次病程诊断依据/鉴别诊断/诊疗计划缺陷 x 4；病程记录病情变化记录不全 x 3；会诊意见已写遵执但实际未落实 x 2
- 样例：
  - `Sheet2-R0009` / `SC-036`：使用抗菌药物治疗的患者，使用情况未在病程记录中记录（(依普林)左氧氟沙星氯化钠注射液） （人工问题原文不可判）
  - `Sheet2-R0010` / `SC-018`：入院记录-体格检查缺体重 （人工问题原文不可判）
  - `Sheet2-R0015` / `SC-010`：入院记录中未记录患儿喂养史（患儿2岁1月） （人工问题原文不可判）

### 需客户确认口径（9）

- 定义：争议点更多落在评价口径或业务阈值，而不是单纯的规则遗漏。
- 下一轮动作：需先与客户确认“欠妥/不详细/无法体现水平/诊断是否充分”等判定阈值，再决定是否规则化。
- 重点问题族：入院记录内容不完整/前后矛盾 x 8；病程记录缺分析/缺处理意见 x 1
- 样例：
