### 可补规则（24）

- 定义：原始文书可回收，但现有主规则或跨文书链路无法精确覆盖人工锚点，属于规则能力缺口。
- 下一轮动作：优先补主规则、次规则重试与跨文书证据拼接，再回归样本验证页。
- 重点问题族：首次病程诊断依据/鉴别诊断/诊疗计划缺陷 x 10；病程记录缺分析/缺处理意见 x 5；病程记录病情变化记录不全 x 2；诊疗医嘱与病程记录不一致 x 2；四级手术未 MDT x 1
- 样例：
  - `Sheet2-R0046` / `SC-023`：转科记录书写不规范，未按照转入记录模板进行书写，缺少转入时间、目前患者情况总结及下一步诊疗计划等 （规则不支持）
  - `Sheet2-R0052` / `SC-032`：现病史记录不全，缺一般情况的描述，专科检查未描述左下肢情况，初步诊断不全。 （规则不支持）
  - `Sheet2-R0056` / `SC-023`：手术记录及术后首次病程记录中，关于术中情况描述，“同法处理对侧”不恰当。因患者右侧卵巢无病变，也未做处理。 （规则不支持）

### 需补源文书（19）

- 定义：人工问题可能成立，但当前缺少可核对的原始正文、诊断字段、执行清单或时序元数据。
- 下一轮动作：优先补 admission diagnosis、手术/会诊正文、执行清单与病程时间轴等源数据快照。
- 重点问题族：入院记录内容不完整/前后矛盾 x 5；病程记录缺分析/缺处理意见 x 4；病程记录病情变化记录不全 x 2；首次病程诊断依据/鉴别诊断/诊疗计划缺陷 x 2；有创诊疗操作记录缺失/书写不规范 x 2
- 样例：
  - `Sheet2-R0053` / `SC-009`：现病史中检查项目记录有错误，阴性症状应位于诊治经过前面，既往史记录双手麻木但无相关诊断。 （证据链不足）
  - `Sheet2-R0058` / `SC-008`：现病史未描述疼痛性质、持续时间、缓解方式等，既往史未询问出患者既往有肺结核病史。 （证据链不足）
  - `Sheet2-R0067` / `SC-009`：入院记录中现病史缺患者发病时间，初步诊断中腰椎病未诊断。 （证据链不足）

### 人工问题过宽/不可判（64）

- 定义：已经核到原始文书，但人工问题过宽、跨多个锚点或与现存正文冲突，无法按原句精确复现。
- 下一轮动作：建议客户下一轮把人工问题拆到单锚点、单文书、单日期，并保留原句截图。
- 重点问题族：入院记录内容不完整/前后矛盾 x 19；病程记录缺分析/缺处理意见 x 13；首次病程诊断依据/鉴别诊断/诊疗计划缺陷 x 4；上级查房内容空洞/复制粘贴/身份异常 x 3；病程记录病情变化记录不全 x 3
