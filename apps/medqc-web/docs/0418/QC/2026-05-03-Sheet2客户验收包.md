### 可补规则（5）

- 定义：原始文书可回收，但现有主规则或跨文书链路无法精确覆盖人工锚点，属于规则能力缺口。
- 下一轮动作：优先补主规则、次规则重试与跨文书证据拼接，再回归样本验证页。
- 重点问题族：上级查房内容空洞/复制粘贴/身份异常；输血记录链缺失/不全 x 1；首次病程记录存在/时效；术前主刀医生查房/麻醉术前访视缺失；术后首次病程/麻醉术后访视缺失 x 1；会诊执行记录缺失/未写执行情况；病程时效/缺失 x 1；病程记录缺分析/缺处理意见 x 1；会诊记录质量缺陷 x 1
- 样例：
  - `Sheet2-R0108` / `LX-018`：2025.11.18田安琴主治医师查房记录无内容；11月17日及11月18日，无输血前评估、无输血记录、无输血后评估。 （规则不支持）
  - `Sheet2-R0172` / `LX-020`：患者2月4日手术，无术前主刀医师查房记录，无术后首次病程记录及手术记录。 （规则不支持）
  - `Sheet2-R0173` / `LX-016`：1月30日后7天无病程记录，请心血管、肾内科、呼吸科、麻醉科、皮肤科等科室会诊后，无请会诊执行记录。 （规则不支持）

### 需补源文书（42）

- 定义：人工问题可能成立，但当前缺少可核对的原始正文、诊断字段、执行清单或时序元数据。
- 下一轮动作：优先补 admission diagnosis、手术/会诊正文、执行清单与病程时间轴等源数据快照。
- 重点问题族：病程记录缺分析/缺处理意见 x 7；首次病程诊断依据/鉴别诊断/诊疗计划缺陷 x 6；入院记录内容不完整/前后矛盾 x 5；病程记录病情变化记录不全 x 3；手术记录缺项/时间错误/逻辑不清/签名异常 x 3
- 样例：
  - `Sheet2-R0030` / `SC-050`：三级医师查房执行不到位（主治医师查房写的是管床医生本人查房） （证据链不足）
  - `Sheet2-R0031` / `CL-275`：请会诊执行记录中复制粘贴严重，记录中“ 余同贵科！谢邀！我科愿随访”直接引用会诊意见未进行修改。 （证据链不足）

### 人工问题过宽/不可判（46）

- 定义：已经核到原始文书，但人工问题过宽、跨多个锚点或与现存正文冲突，无法按原句精确复现。
- 下一轮动作：建议客户下一轮把人工问题拆到单锚点、单文书、单日期，并保留原句截图。
- 重点问题族：入院记录内容不完整/前后矛盾 x 16；病程记录缺分析/缺处理意见 x 13；首次病程诊断依据/鉴别诊断/诊疗计划缺陷 x 4；病程记录病情变化记录不全 x 3；会诊意见已写遵执但实际未落实 x 2

### 需客户确认口径（10）
