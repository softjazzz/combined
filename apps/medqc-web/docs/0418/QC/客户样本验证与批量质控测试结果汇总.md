当前 `workstation-v4 / 客户样本验证` 主链路已经达到 **可交付联调阶段**。

## 3. 已覆盖项

### 3.1 模板导入

已验证：

- 只填 `住院号` 可导入
- 只填 `visit_id` 可导入
- `存在问题` 可为空
- 简化模板下载内容正确
- 导入成功后可自动切换到新样本池

结论：

- 当前模板口径已收敛到最小可用输入
- 客户不需要复杂人工问题字段即可导入病历清单

### 3.2 真实病历池聚合

已验证：

- 多条样本行可聚合成一份真实病历
- 前端主列表按真实病历展示
- 病历行能带出：
  - 关联人工问题数
  - 问题摘要
  - 候选规则
  - 样本项 ID 集合

结论：

- 客户前端操作对象已从“样本行”收口为“真实病历”

### 3.3 定向同步

已验证：

- `同步样本病历` 只处理当前样本池病历
- 同步任务采用任务化执行
- 页面可展示同步进度
- 轮询进度会递增
- 任务完成后会刷新样本池和病历池列表

结论：

- 同步流程对客户是可见的，不再是黑盒执行

### 3.4 病历匹配

已验证：

- 可执行病历过滤逻辑正确
- 勾选不可执行病历时会提示
- 只要存在可执行病历，就会自动跳过不可执行病历并继续提交任务

结论：

- 病历匹配和可执行性判断已经与前端勾选交互打通

### 3.5 批量质控执行

已验证：

- 不勾选时可执行全部可运行病历
- 勾选后只执行选中的真实病历
- 病历级并发数 `1 / 2 / 4` 可由前端设置
- 后端 `run` 接口能正确接收：
  - `record_ids`
  - `sample_item_ids`
  - `max_parallel_records`
- 后端任务创建时：
  - `selected_record_ids`
  - `selected_sample_item_ids`
  - `selected_sample_count`
  - `dedup_record_count`
    会正确落入 filters

结论：

- 批量任务创建逻辑稳定
- 病历级并发链路已打通

### 3.6 任务进度与结果展示

已验证：

- 发起验证后可自动打开结果抽屉
- 同步任务进度可见
- 结果抽屉统计与明细一致
- 结果抽屉可按规则筛选

结论：

- 前端结果展示链路已具备演示条件

### 3.7 病历原文查看

已验证：

- 可从客户样本验证页直接点击 `查看病历`
- 可打开病历联审详情抽屉

结论：

- 客户可以从验证页直接进入病历原文，不需要切换系统
