## 📝 技术设计建议

### RuleParamsDrawer 组件设计

**组件接口**：
```typescript
// Props
interface RuleParamsDrawerProps {
  visible: boolean          // 抽屉是否可见
  ruleId: string           // 当前配置的规则 ID
  ruleName: string         // 规则名称
  currentParams?: RuleParams  // 当前参数值
}

// Emits
interface RuleParamsDrawerEmits {
  'update:visible': [visible: boolean]
  'save': [ruleId: string, params: RuleParams]
  'reset': [ruleId: string]
}

// 参数类型
interface RuleParams {
  weight: number           // 权重 (0.1 - 2.0)
  threshold?: number       // 阈值 (0 - 100)
  enabled: boolean         // 是否启用
  severity: 'low' | 'medium' | 'high'  // 严重程度
}
```

**表单字段**：
1. **权重**（weight）
   - 组件：`a-input-number`
   - 范围：0.1 - 2.0
   - 步长：0.1
   - 默认值：1.0

2. **阈值**（threshold）
   - 组件：`a-slider`
   - 范围：0 - 100
   - 步长：1
   - 默认值：80

3. **启用/禁用**（enabled）
   - 组件：`a-switch`
   - 默认值：true

4. **严重程度**（severity）
   - 组件：`a-select`
   - 选项：轻微、重要、严重
   - 默认值：medium

**Store 扩展**：
```typescript
// State
const ruleParams = ref<Record<string, RuleParams>>({})

// Actions
const updateRuleParams = (ruleId: string, params: RuleParams) => {
  ruleParams.value[ruleId] = params
  saveDemoState()
}

const getRuleParams = (ruleId: string): RuleParams => {
  return ruleParams.value[ruleId] || {
    weight: 1.0,
    enabled: true,
    severity: 'medium'
  }
}

const resetRuleParams = (ruleId: string) => {
  delete ruleParams.value[ruleId]
  saveDemoState()
}
```
