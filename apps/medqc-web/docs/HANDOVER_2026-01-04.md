## 📋 项目概述

**项目名称**：病案首页质控系统（MedQC）  
**核心功能**：基于 AI/LLM 的医疗病案质量控制平台

| 组件 | 技术栈 | 端口 |
|------|--------|------|
| 前端 | Vue 3 + TypeScript + Ant Design Vue + Tailwind CSS | 3000 |
| 后端 | FastAPI + Python 3.11 | 8001 |
| 图表 | ECharts (vue-echarts) | - |
| LLM | 阿里云百炼 (qwen3-next-80b-a3b-instruct) | - |

---

## ✅ 已完成功能

### 1. LLM 结构化数据提取
- **端点**: `POST /api/v1/case-front-page/extract`
- **功能**: 从病历原文提取结构化病案首页数据
- **文件**: 
  - `backend-fastapi/app/services/llm_service.py` (`extract_frontpage_structured` 方法)
  - `backend-fastapi/app/api/case_front_page.py`

### 2. 外部 ICD 编码服务集成
- **端点**: `POST /api/v1/case-front-page/extract-coding`
- **外部服务**: `http://122.51.111.253:8002` (异步任务队列)
- **功能**: 获取准确的 ICD-10/ICD-9-CM-3 编码 + 置信度 + 证据位置
- **文件**: 
  - `backend-fastapi/app/services/external_coding_service.py` [新建]
  - `backend-fastapi/app/api/case_front_page.py`

### 3. 可拖拽分隔条
- **位置**: Demo 页面左右面板之间
- **功能**: 鼠标拖拽调整左右面板宽度（20%-80%）
- **文件**: `src/views/demo/FrontPageDemoView.vue` (`leftPanelWidth`, `startResize`, `doResize`, `stopResize`)

### 4. AI 画像分析可视化仪表盘
- **位置**: Demo 页面 "AI 画像分析" 标签页
- **功能**:
  - 3D 人体模型可视化（交互热点标记诊断位置）
  - Vitals Monitor 生命体征曲线
  - Labs Radar 检验指标雷达图
  - Risk Assessment 风险评估仪表盘
- **文件**: 
  - `src/views/demo/FrontPageDemoView.vue`
  - `public/human_body_schematic.png` [新建]
