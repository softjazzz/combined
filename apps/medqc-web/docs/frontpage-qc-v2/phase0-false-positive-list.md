# 首页形式质控 阶段 0：误报清单

> **更正（2026-10-13，V2 字段盘点后）**：本文第三节“数据同步层面的发现”中，“整块缺失约 197 份”“列错位约 32 份”“主诊断无编码 121 份”“主诊断不在第一条 75 份”均来自 232 份测试和合成病例，不是医院同步问题。287 份真实同步首页这几项都是 0，绝大多数字段 100% 有值。真实数据的缺口只有：入院和出院时间（各 10%）、编码员（2%）、职业（1%）、籍贯、工作单位和自付金额（0%）。另外，填写说明规定无内容时填“-”，本文把“-”算作空值，偏严。以上以 `rule-catalog-review.md` 为准。

- 日期：2026-10-13
- 范围：`FrontpageFormalQC` 全部 82 条规则 × 本地 `medqc` 库全部 519 份正式首页（`get_frontpage_sheet` 输出）
- 方式：只读连接（`default_transaction_read_only=on`），不调用模型，不写库；本文只含聚合统计和值的格式形态（数字→9、字母→A、汉字→汉…），不含病历原文
- 口径说明
  - **现状失败率**：把 `get_frontpage_sheet` 的嵌套结构（`basic / diagnoses / surgeries / cost / other_medical_info`）原样喂给引擎，等同于前端现在的调用方式
  - **拍平后失败率**：把 `basic` 展开到顶层后再跑，用来区分“结构没对上”和“字段名/口径没对上”
  - 规则抛异常时引擎默认判“通过”，所以“异常”列也是隐性问题

## 一、结论先说

1. **现状基本不可用**：42 条规则对 519 份首页 100% 判失败，原因是引擎读平铺键（`fp.get("sex")`），而首页数据是嵌套的 `basic.sex`。这 42 条全是误报。
2. **拍平后仍有 31 条规则 100% 失败**：规则字段名与库里列名对不上（如 `patient_name` vs `name`、`discharge_method` vs `leaving_hospital_way`），大部分有明确可映射的列，少数库里根本没有对应列。
3. **编码格式规则误报严重**：ICD-10 正则不认国临版扩展码（`K35.800x001` 这类），946 个诊断编码被判格式错；ICD-9-CM-3 同理 263 个手术编码。
4. **主诊断取法错误**：引擎取 `diagnoses[0]` 当主诊断，有 75 份首页第一条其实是“其他诊断”。
5. **有 14 条规则永远不会触发**（字段不存在或类型异常被吞），看起来“全部通过”，实际没检查。
6. **数据本身有同步缺口**，不是医生漏填：入院/出院时间分别只有 44% / 38% 有值，287 份两者都空；约 197 份缺整块“过敏/血型/尸检/付款方式”字段；约 32 份出现列错位（“证件类型”列里是身份证号，“过敏标志”列里是“已脱敏签名”）。这类在修完映射前不能判“不合规”，应判“资料不足”。

## 三、数据同步层面的发现（不改规则也要处理）

1. **入出院时间缺失**：`admission_datetime` 44.1%，`discharge_datetime` 37.6%，287 份两者都空。首页里没有入出院时间是不正常的，应先查同步映射，不能判医生不合规。
2. **整块缺失**：过敏、血型、尸检、付款方式、再住院计划等字段都约 62%（322 份）有值，说明约 197 份首页整块没同步进来。
3. **列错位**：约 32 份首页的 `id_card_type` 列里是身份证号形态（`999999********9999`），`allergy_sign` / `death_autopsy_sign` 列里是“已脱敏签名”。这批疑似同步时列对歪了。
4. **主诊断无编码**：121 份主诊断没有编码，全部来自非 `mr_diagnosis` 来源（`source_table` 为空的那路）。
5. 填充率分层很明显（100% / 91.3% / 85.5% / 62% / 44%），对应不同的同步来源或批次，可以作为排查线索。

## 四、需要你拍板的口径

1. **数据缺口怎么判**：同步缺块（上面第三节的 1–4 条）是统一判“资料不足（data_gap）”不出缺陷，还是照常判不合规？建议判资料不足，并在结果里单独计数。
2. **D 类条件必填**：表中“建议口径”是否同意？尤其是质控签名三项（FQ-093～095）是否停用或延后到归档后。
3. **本院不采集的字段**：FQ-060 治疗类别、FQ-066 出生地、FQ-087 工作地址、FQ-091 健康卡号，是停用还是保留为“提示”级？
4. **编码校验方式**：用正则兼容国临版格式（快，1 天内），还是查本院 ICD 字典（准，需要确认字典来源，就是待办里 ICD 数显示 `--` 的那张表）？
5. **规则异常的默认值**：建议异常一律判“资料不足”并记日志，不能再默认通过。
