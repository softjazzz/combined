- 规则依据：

## 一、通用约定

1. **“-”算已填写**。填写说明规定，栏目没有可填内容时填“—”，所以“-”“—”“无”都视为已填写，不判缺项。
2. **四态结论**：合规 / 不合规 / 资料不足 / 不适用。只有“不合规”扣分、进问题列表。
3. **严重程度**：
   - **扣分**：对应评分表条目，按分值扣分
   - **必填**：属于 76 项必填但评分表没有单列，只计入“填报完整率”，不扣分
   - **提示**：逻辑上可疑但不能确定，不扣分，单独展示
4. **同项不重复扣分**：一个评分项（如“离院方式”）缺项或填错，只扣一次。
5. **停用**：库里没有对应字段、或本院不采集的项目，规则保留但不执行，不计入分母。
6. **资料不足来源配置**：已确认首页同步没有带入的字段写在配置里，为空时判“资料不足”，不判不合规。同步修好后删掉配置即可恢复。

## 五、评分

- 满分 100：患者信息 18、住院过程 26、诊疗信息 50、费用 6。
- 各项按第二节的类别扣分，D 类和“分/项”类有封顶。
- 停用、资料不足、不适用的项目不扣分。结果里同时给出“可评分项占比”。
- 等级：≥ 90 分为优秀，75–90 分为合格，< 75 分为不合格（已确认）。
