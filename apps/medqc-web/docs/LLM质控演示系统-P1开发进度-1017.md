## 🔍 技术要点

### 1. 组件设计原则
- **单一职责**：每个组件只负责一个功能
- **数据驱动**：所有数据来自 Store，组件只负责展示和交互
- **Props Down, Events Up**：遵循 Vue 数据流规范
- **响应式设计**：适配不同屏幕尺寸

### 2. Store 集成
- 使用 `useQCDemoStore()` 获取 Store 实例
- 直接访问 Store 的响应式数据
- 调用 Store 的 Action 方法修改状态
- 不在组件内部维护重复的状态

### 3. Ant Design Vue 组件使用
- `a-card` - 卡片容器
- `a-list` - 列表展示
- `a-descriptions` - 描述列表
- `a-statistic` - 统计数值
- `a-input-search` - 搜索输入框
- `a-select` - 下拉选择器
- `a-tag` - 标签
- `a-badge` - 徽标
- `a-empty` - 空状态

### 4. 样式设计
- 使用 `scoped` 样式避免污染
- 使用 Less 预处理器
- 使用 `:deep()` 修改组件内部样式
- 使用渐变背景增强视觉效果
- 使用过渡动画提升用户体验
