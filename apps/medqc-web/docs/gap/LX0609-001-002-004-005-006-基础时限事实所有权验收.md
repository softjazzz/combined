# LX0609-001/002/004/005/006 基础时限事实所有权验收

## 范围

本次只收口 LX0609-001、002、004、005、006 已迁移基础时限规则族的客户展示事实合同；不改变 native 执行器的判定、状态、原因码、客户文案或证据选择。

## 所有权

- `basic_timeliness_customer_projection.py` 是五条规则客户事实白名单与 `status ↔ customer_display_facts` 自洽校验的唯一所有者。
- `canonical_result_finalizer.py` 对该规则族接管 facts 合同失败：缺失 facts、非法私有 `fact_ref`/文书标识或状态与 facts 矛盾时，清除客户事实和证据并安全降级为 `technical_error`，不得伪装为 `data_gap`。
- 证据仍由现有公共 `fact_refs` projector 投影。Finalizer 的声明仅关闭 Aggregator 对本规则族的旧来源级回退，不选择材料或生成证据。
- Aggregator 保留通用装配、排序及公共证据投影；不存在五条规则号的专属业务分支。架构冻结测试将五个规则号在 Aggregator 源码中的引用计数固定为 0；Finalizer 内的纯声明式 owner 守卫不属于 Aggregator 业务引用。

## 覆盖场景

- 五条规则各自 `within → compliant` 的合法 facts 形状。
- 001 的时间冲突 `before → uncertain`，以及 004 的抢救记录缺失 `→ data_gap`。
- 缺 facts、状态与 facts 矛盾、含私有 `source_document_refs` 的非法 facts 均降级为 `technical_error` 且不泄露客户事实/证据。
- 原有冻结回归覆盖 Aggregator 的零规则号引用、执行器结果、公共证据坐标及事实投影。
