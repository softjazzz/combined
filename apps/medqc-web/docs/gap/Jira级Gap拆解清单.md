# Jira 级别 Gap 拆解清单

## 1. 使用说明

- 本清单按 `Epic -> Story/Task` 组织，可直接拆到 Jira。
- 本轮开发默认基于 `workstation v4` 现有前后端增量开发。
- 允许新增页面、接口、聚合层和数据模型。
- 默认不修改现有项目前后端脚本；如必须修改，需先人工确认。
- 基础设施默认口径：
  - `PG` 为主数据源
  - `Redis` 为调度与异步执行基础设施
  - 第一阶段优先 `Celery + Redis`
  - 不引入 RabbitMQ / RocketMQ
- 登录模块范围已按内网场景收敛：
  - 保留 `用户名/密码登录`
  - 保留 `手机号/密码登录`
  - 手机号作为同一账户的备用登录标识，不新增独立手机号账户体系
  - 不做扫码登录
  - 不做短信验证码发送与校验
- 优先级定义：
  - `P0`：不补就无法形成 V3.6 主链路
  - `P1`：主链路可跑，但离可交付还有明显差距
  - `P2`：增强项或收尾项
- 预估口径：
  - `S`：1-2 天
  - `M`：3-5 天
  - `L`：1-2 周
