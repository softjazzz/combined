# LX0609-054/055/057/058 抗菌药物事实所有权验收

## 范围

本次仅做抗菌药物规则族 LX0609-054、055、057、058 的展示 facts 结构迁移。native 执行器、状态/原因码、特殊级药物目录、提示词、客户文案、Renderer 和 API 均未修改。

## 所有权

- `antimicrobial_result_mapping.py` 是这四条规则的展示 facts 白名单、字段关系和 `status ↔ facts` 自洽校验的唯一所有者；它不读取材料、不选择证据，也不生成文书 DTO。
- `canonical_result_finalizer.py` 接管 Typed/native 决策链的事实合同：非法 facts、私有文书引用或状态冲突清除客户 facts/证据并降级为 `technical_error`，不会改写为 `data_gap` 或 `uncertain`。既有公共 direct aggregation 入口对同类非法输入继续 fail-closed 抛 `ValueError`。
- Finalizer 声明四规则只允许公共逐行 `fact_refs` projector 提供证据；没有精确坐标时不回退到 Aggregator 的旧来源级反查。
- Aggregator 保留通用装配、排序和公共证据投影，删除四规则专属 `verification_kind`、字段白名单、058 时间关系和 054/055 关联校验。硬守卫冻结四个规则号在 Aggregator 源码中的引用计数为 0。

## 冻结覆盖

- 054 的合规、不合规和关联失败；055 的合规、不合规、窗口未成熟及 horizon 缺失；057 的合规/不合规。
- 058 的合规、专家支持迟到、首用药时间缺失和关联失败。
- 非法私有 `fact_ref`、字段关系非法、状态冲突均安全降级为 `technical_error`。
- 原生聚焦回归同时验证精确 `fact_refs` 只投影实际消费的抗菌药物医嘱、匹配病程/会诊记录，排除无关文书。
