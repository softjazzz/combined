# LX0609-052/053 危急值族结构迁移验收

## 范围

- 迁移 052（危急值处置时限）与 053（危急值处置存在性）的客户展示事实白名单和状态自洽校验。
- 保持 native 执行器的状态、原因码、文案、Prompt 与 API 契约不变。
- 不改动材料读取、事实选择或证据选择；客户证据仅由 `fact_refs` 经公共 selected-document projector 投影。

## 结构验收

- `critical_value_result_mapping.py` 是两规则展示事实合同的唯一所有者，只做事实白名单和 `status ↔ facts` 自洽校验。
- Canonical Finalizer 接管两规则合同失败，并将无效事实或状态冲突安全降级为 `technical_error`。
- Aggregator 对 `LX0609-052`、`LX0609-053` 的文本引用为 0；不再持有两规则的危急值事件、窗口或事实字段校验。
- 两规则仅允许公共逐行 `fact_refs` 证据投影；缺少精确坐标时不得回退到旧来源级反查。

## 回归场景

- 052：及时处置、超时处置、未处置且窗口已成熟、窗口未成熟、评价终点缺失。
- 053：已处置、未处置。
- 两规则：检验结果明细缺失、无效客户事实、状态与事实冲突。
