# 📖 智能病案质控系统用户手册

## 🎯 系统概述

智能病案质控系统是一个基于AI技术的医疗病案质量控制平台，通过DeepSeek AI分析和规则引擎双重验证，为医疗机构提供高效、准确的病案质量评估服务。

### ✨ 核心功能

- 🤖 **AI智能分析**: 基于DeepSeek大模型的病案内容分析
- 📋 **规则引擎**: 50+条质控规则自动检查
- 📊 **多维度评分**: 完整性、一致性、合理性、及时性四维评估
- 📈 **统计分析**: 实时数据统计和趋势分析
- 👥 **多角色管理**: 支持5种用户角色和权限控制
- 📱 **移动端适配**: 完美支持手机和平板设备

## 📋 病案管理

### 上传病案

1. **单个上传**
   - 点击"上传病案"按钮
   - 填写患者基本信息（姓名、年龄、性别、科室等）
   - 选择病案文件（支持PDF、Word、图片格式）
   - 输入或粘贴病案内容
   - 点击"提交"完成上传

2. **批量上传**
   - 点击"批量上传"选项
   - 选择多个病案文件
   - 系统自动识别文件内容
   - 确认信息后批量提交

### 病案列表

**功能特点**：
- 🔍 **智能搜索**: 支持患者姓名、科室、病案类型搜索
- 🏷️ **状态筛选**: 按分析状态（待分析、分析中、已完成）筛选
- 📅 **时间筛选**: 按创建时间或入院时间筛选
- 📱 **响应式设计**: 自动适配不同屏幕尺寸

**操作说明**：
- **查看详情**: 点击病案条目查看详细信息
- **开始分析**: 点击"分析"按钮启动质控分析
- **批量操作**: 勾选多个病案进行批量分析或导出
- **更多操作**: 通过下拉菜单进行编辑、下载、删除等操作

## 🤖 质控分析

### 分析模式

1. **综合分析** (推荐)
   - AI分析 + 规则引擎双重验证
   - 分析时间: 2-4秒
   - 准确率: 95%以上

2. **快速分析**
   - 重点关注关键质控问题
   - 分析时间: 1-2秒
   - 适用于初步筛查

3. **专项分析**
   - 针对特定质控项目深度分析
   - 可自定义分析重点
   - 适用于专业质控

### 分析结果

**评分体系**：
- **总体评分**: 0-100分，综合质量评估
- **等级评定**: A级(90-100分)、B级(75-89分)、C级(60-74分)、D级(60分以下)

**四维评分**：
- 📝 **完整性**: 病案记录的完整程度
- 🔄 **一致性**: 各项记录之间的一致性
- 🧠 **合理性**: 诊疗过程的合理性
- ⏰ **及时性**: 记录时间的及时性

**问题识别**：
- 🔴 **严重问题**: 影响医疗安全的关键问题
- 🟡 **一般问题**: 需要改进的质量问题
- 🔵 **建议优化**: 可以进一步完善的地方

### 批量分析

1. **选择病案**
   - 在病案列表中勾选需要分析的病案
   - 支持全选或按条件筛选后批量选择
   - 最多支持50条病案同时分析

2. **设置参数**
   - 选择分析模式
   - 设置优先级（高、普通、低）
   - 选择质控规则类别

3. **监控进度**
   - 实时显示分析进度
   - 显示成功/失败统计
   - 支持暂停和取消操作

## ❓ 常见问题

### 使用问题

**Q: 分析速度慢怎么办？**
A: 
- 检查网络连接是否稳定
- 尝试使用"快速分析"模式
- 联系管理员检查系统负载

**Q: 分析结果不准确？**
A: 
- 确认病案内容完整清晰
- 检查是否选择了合适的分析模式
- 可以尝试重新分析或联系质控专员

**Q: 无法上传文件？**
A: 
- 检查文件格式是否支持（PDF、Word、图片）
- 确认文件大小不超过限制（50MB）
- 尝试刷新页面后重新上传

### 技术问题

**Q: 页面加载慢？**
A: 
- 清除浏览器缓存
- 检查网络连接
- 尝试使用其他浏览器

**Q: 移动端显示异常？**
A: 
- 更新浏览器到最新版本
- 检查屏幕方向设置
- 尝试刷新页面
