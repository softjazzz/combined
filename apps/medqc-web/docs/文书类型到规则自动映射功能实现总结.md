# 文书类型到规则自动映射功能实现总结

> **实现日期**: 2025-10-20  
> **功能版本**: v1.0  
> **相关需求**: 根据选中的文书类型自动筛选适用的质控规则

---

## 📋 功能概述

### 问题背景
在之前的实现中，无论用户选择什么类型的文书（入院记录、首次病程记录、手术记录等），系统都会显示所有68条质控规则。这导致：
- 用户可能选择不适用于当前文书类型的规则
- 质控结果不准确（例如对"首次病程记录"应用"手术记录"的规则）
- 用户体验差，需要手动筛选大量规则

### 解决方案
实现了**文书类型到规则的自动映射**功能：
- 当用户选择文书时，系统自动筛选出适用于该文书类型的规则
- 只显示相关规则，隐藏不适用的规则
- 当用户切换文书类型时，自动更新规则列表和选中的规则

## 🔧 技术实现

### 1. 数据模型

#### 规则数据结构
每条质控规则包含 `applicable_documents` 字段，定义该规则适用的文书类型：

```typescript
interface QCRule {
  id: string
  rule_code: string
  name: string
  description: string
  applicable_documents: string[]  // 适用的文书类型列表
  // ... 其他字段
}
```

**示例**：
```json
{
  "rule_code": "SC-001",
  "name": "入院记录完整性检查",
  "applicable_documents": ["入院记录", "24小时入院记录"],
  // ...
}
```

- `applicable_documents` 为空或 null：通用规则，适用于所有文书类型
- `applicable_documents` 包含特定类型：只适用于列表中的文书类型

### 2. 前端实现（qcDemo.ts）

#### 2.1 添加计算属性 `applicableRules`

在 `qcDemo.ts` 中添加了一个计算属性，根据当前选中的文书类型过滤规则：

```typescript
// 根据当前选中文书类型过滤的适用规则
const applicableRules = computed<QualityControlRule[]>(() => {
  // 如果没有选择文书，返回所有规则
  if (!selectedDocumentPrimary.value?.type) {
    return availableRules.value
  }
  
  const documentType = selectedDocumentPrimary.value.type
  
  // 过滤规则：
  // 1. applicable_documents 为空或 null 的通用规则
  // 2. applicable_documents 包含当前文书类型的规则
  const filtered = availableRules.value.filter((rule: any) => {
    const applicableDocs = rule.applicable_documents || []
    
    // 通用规则（适用于所有文书类型）
    if (!applicableDocs || applicableDocs.length === 0) {
      return true
    }
    
    // 检查是否包含当前文书类型
    // 支持完全匹配和部分匹配（例如 "病程记录" 可以匹配 "首次病程记录"）
    return applicableDocs.some((doc: string) => 
      doc === documentType || 
      documentType.includes(doc) || 
      doc.includes(documentType)
    )
  })
  
  console.log(`[QCDemoStore] 规则过滤: 文书类型="${documentType}", 总规则=${availableRules.value.length}, 适用规则=${filtered.length}`)
  
  return filtered
})
```

**过滤逻辑**：
1. 如果规则的 `applicable_documents` 为空 → 通用规则，保留
2. 如果 `applicable_documents` 包含当前文书类型 → 适用规则，保留
3. 支持模糊匹配（例如"病程记录"可以匹配"首次病程记录"）

#### 2.2 添加统计计算属性

```typescript
// 可用规则总数（基于当前文书类型过滤后的规则）
const totalRulesCount = computed(() => applicableRules.value.length)

// 所有规则总数（未过滤）
const allRulesCount = computed(() => availableRules.value.length)
```

#### 2.3 添加文书类型变化监听器

当用户切换文书类型时，自动更新规则选择：

```typescript
// 监听文书选择变化，自动更新规则选择
watch(
  () => selectedDocumentPrimary.value?.type,
  (newDocumentType, oldDocumentType) => {
    // 只有在文书类型真正改变时才触发
    if (newDocumentType && newDocumentType !== oldDocumentType && availableRules.value.length > 0) {
      console.log(`[QCDemoStore] 文书类型变化: "${oldDocumentType}" → "${newDocumentType}"`)
      
      // 清空当前选中的规则
      selectedRules.value = []
      
      // 自动选择适用于新文书类型的规则（最多3条）
      const categories = new Set<string>()
      const selectedRulesList: unknown[] = []
      
      for (const rule of applicableRules.value.filter((r: any) => r.isActive || r.is_active)) {
        if (selectedRulesList.length >= 3) break
        if (!categories.has((rule as any).category) || selectedRulesList.length < 2) {
          selectedRulesList.push(rule)
          categories.add((rule as any).category)
        }
      }
      
      selectedRules.value = selectedRulesList
      
      console.log(`[QCDemoStore] 自动选择规则: 适用规则=${applicableRules.value.length}, 已选规则=${selectedRulesList.length}`)
      
      // 添加日志提示用户
      addDemoLog('info', `文书类型已切换为"${newDocumentType}"`, {
        applicableRulesCount: applicableRules.value.length,
        selectedRulesCount: selectedRulesList.length
      })
    }
  }
)
```

**监听器功能**：
1. 检测文书类型变化
2. 清空之前选中的规则
3. 自动选择适用于新文书类型的规则（最多3条，优先选择不同类别）
4. 记录日志，提示用户

#### 2.4 修改默认规则选择逻辑

在数据加载完成后，使用 `applicableRules` 而不是 `availableRules` 来选择默认规则：

```typescript
// 智能选择默认规则（基于当前文书类型的适用规则）
if (selectedRules.value.length === 0 && applicableRules.value.length > 0) {
  // 优先选择不同类别的活跃规则
  const categories = new Set<string>()
  const selectedRulesList: unknown[] = []

  for (const rule of applicableRules.value.filter((r: any) => r.isActive || r.is_active)) {
    if (selectedRulesList.length >= 3) break
    if (!categories.has(rule.category) || selectedRulesList.length < 2) {
      selectedRulesList.push(rule)
      categories.add(rule.category)
    }
  }

  selectedRules.value = selectedRulesList
  
  console.log(`[QCDemoStore] 自动选择规则: 文书类型="${selectedDocumentPrimary.value?.type}", 选中规则=${selectedRulesList.length}`)
}
```

### 4. 后端支持（已实现）

后端已经支持 `rule_ids` 参数，前端会将用户选择的规则ID传递给后端：

```typescript
// 提取用户选择的规则ID列表
const ruleIds = selectedRules.value
  .map(rule => rule.rule_code || rule.id)
  .filter(id => id) // 过滤掉空值

const sichuanPayload = {
  document_id: primaryDocument.id,
  document_content: documentContent,
  document_type: primaryDocument.type || '病程记录',
  rule_ids: ruleIds.length > 0 ? ruleIds : undefined, // 只有选择了规则才传递
  persist: false
}
```

后端会根据 `rule_ids` 过滤规则，只评估指定的规则。
