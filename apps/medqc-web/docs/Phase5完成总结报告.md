## 🏗️ 系统架构总览

### 技术栈
- **前端**: Vue 3 + TypeScript + Ant Design Vue
- **状态管理**: Pinia
- **构建工具**: Vite
- **样式**: SCSS + 响应式设计
- **路由**: Vue Router

### 组件架构
```
LLMQCDemoEnhanced (主演示页面)
├── QCRulesDemoPanel (规则演示)
├── QCAnalysisDemoPanel (分析演示)
├── QCNotificationDemoPanel (通知演示)
├── QCAppealDemoPanel (申诉演示)
├── QCNotificationModal (通知详情)
└── QCAppealModal (申诉提交)
```

### 状态管理
- **qcDemo Store**: 统一的状态管理中心
- **持久化**: 本地存储 + 自动恢复
- **数据流**: 单向数据流 + 事件驱动
