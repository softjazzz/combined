## 覆盖等级说明

- `精确覆盖`：现有规则的检查对象、触发条件和客户质控点基本一致。
- `近似覆盖`：现有规则可解释该问题，但阈值、文书范围或触发条件不完全一致。
- `部分覆盖`：只覆盖缺失、时限、签名、记录等一部分，不覆盖完整客户描述。
- `待补规则`：未找到可直接承载的规则。
- `需数据联查`：依赖医嘱、费用、检查、检验、手术、麻醉、输血等多源数据，不能只靠文书文本判断。

## 汇总结论

按客户 49 条质控点逐条比对：

- `精确覆盖`：26 条，主要集中在文书缺失、时限、术前讨论、输血知情同意、输血评估等规则。
- `近似覆盖`：10 条，主要是 CT/MRI、细菌培养、会诊执行、植入物字段等，需要补充时限、字段范围或执行条件。
- `部分覆盖`：6 条，主要是病危/病重查房、恶性肿瘤淋巴结清扫、麻醉访视、术中输血多文书一致性。
- `待补规则`：3 条，主要是恶性肿瘤出院治疗计划、麻醉访视填写规范、麻醉记录单缺失。
- `需数据联查`：4 条，主要是 CT/MRI 检查前记录、化疗医嘱一致性、抗菌药物预防使用时长、输血医嘱与收费一致性。

注：部分规则同时属于“近似覆盖”和“需数据联查”。正式验收时应以能否在真实病历上跑出结构化证据为准。

## 建议实施顺序

1. 先把 `精确覆盖` 和高可信 `近似覆盖` 的规则整理成“客户第一批质控点 v1”规则包，避免演示时在全量规则库里搜索。
2. 对 `病重 2 天 / 病危每日查房 / CT-MRI 24 小时 / 细菌培养 24 小时` 做最小补强，因为这些是客户文字里明确写了阈值的规则。
3. 对 `化疗记录与医嘱一致性 / 抗菌药物预防使用时长 / 输血医嘱与收费一致性` 标记为多源数据联查规则，演示时说明需要医嘱、费用、检查检验数据共同支撑。
4. 对 `恶性肿瘤淋巴结清扫 / 出院后肿瘤治疗计划 / 麻醉记录单 / 麻醉访视规范` 新增专项语义规则，补齐客户第一批清单的明显空缺。
