- 保留现有可执行规则，重点补齐三类 golden cases 和评估证据。

**证据任务**

- 输出固定证据字段：问题标题、命中文书、命中字段或片段、规则依据、证据摘要、建议处理、风险等级。

- 输出固定证据字段：问题标题、命中文书、命中字段或片段、规则依据、证据摘要、建议处理、风险等级。

**样本任务**

- 从复核队列处理候选：待复核 0，已接受 0，已拒绝 0。
- 每条规则必须补齐阳性、阴性、边界样本各至少 1 例。
- 当前无候选样本，需要扩大样本池检索或新增合成验证病历。
- 评估未就绪原因：规则状态为 ready_with_data_gap，不是 formal_ready；缺少样本类型: positive, negative, boundary；样本或预测不足，无法计算精确率/召回率

**验收闸门**

- 目录校验通过，rule_id 能在可执行规则源中找到。
- 阳性、阴性、边界 golden cases 全部齐备。
- 精确率 >= 0.90，召回率 >= 0.85。
- 客户样本验证页可查看命中证据、病历定位和导出报告。
- 低于阈值时只能标记为试运行或需复核，不能进入正式版。
