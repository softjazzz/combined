## 不能直接上线的原因

当前 `luxian_0609_qc_v1` 仍是演示/验证规则包，不是正式上线规则包。主要原因：

1. 大量规则只做到“近似纳入”，没有完全按客户原文口径实现。
2. 多数跨文书规则缺少规则级上下文聚合，无法稳定比较指定文书。
3. 跨表联查规则还没有统一医嘱、检查、检验、费用时间轴。
4. 49 条规则还没有 golden cases，因此无法计算每条规则的精确率和召回率。
5. `formal_ready` 规则也只是候选，仍需真实样本验证后才能进入正式版规则集。
6. `LX0609-001`、`LX0609-002`、`LX0609-016` 已降级为 `ready_with_data_gap`：当前客户样本池缺少可覆盖样本的入院时间或首次病程正文，不能把空数据当成正式可执行规则。
