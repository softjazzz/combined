# 泸县0609质控集-上线边界与验收口径

## 当前定位

`luxian_0609_qc_v1` 当前定位为演示、受控 POC 和影子运行规则集。目标是证明执行链路、状态口径和证据链可复核，不是直接形成正式质控结论。

## 不允许的用途

- 不写入正式质控缺陷库。
- 不作为归档拦截依据。
- 不影响医保结算、绩效扣分、科室考核。
- 不把合成样本通过率写成真实样本准确率。
- 不暴露 `prompt`、`raw_response`、`embedding` 或完整病历全文。

## 验收口径

P1 验收只看以下能力：

1. 七状态口径固定，`data_gap`、`not_applicable`、`not_executed`、`technical_error` 不伪装为合格。
2. 客户样本结果包含证据链字段，可看到触发事实、来源、引用片段、阈值、实际值、差值和缺失数据。
3. 真实候选 Golden Set 已生成待标注表和系统/人工对比框架。
4. 人工标注未完成前，只能说“具备试点复核基础”，不能说真实准确率达标。

## 进入试点前置条件

- 质控员完成 20-30 份真实候选病历的 `human_status` 标注。
- 系统结果回填 `system_status`、`system_evidence_summary`。
- 对比表完成 `is_match`、`evidence_ok`、`error_type`。
- 对 `data_gap` 和 `technical_error` 单独复盘，不纳入合格率美化。
