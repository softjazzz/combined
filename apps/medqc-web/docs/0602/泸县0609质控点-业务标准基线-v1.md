## 3. 状态定义

| 标记       | 含义                                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------------------- |
| 正式       | 属于当前67条正式规则，可依据现行规范或客户明确口径验收                                                               |
| 临时       | 属于经批准的8条临时规则：050、054、055、056、057、059、063、075                                                      |
| 已确定     | 业务标准足以实施；数据缺失应返回数据不足，不得重新解释标准                                                           |
| 部分确定   | 已确定子判定可以实施，未确定子判定不得影响最终状态                                                                   |
| 待确认     | 不允许输出确定问题或合规结论，只能说明缺少的标准或资料                                                               |
| 待真实验收 | 合同和代码边界已冻结，但尚未完成授权真实病例金标、性能与客户验收；发布阶段必须保持 `pending_definition/not_executed` |

正式/临时是产品发布属性，已确定/部分确定/待确认是标准完整性属性，两者不能混用。

当前可执行规则共68条，其中正式规则63条、临时规则5条；其余7条规则失败关闭为`not_executed`。不得把“当前可执行68条”表述为“68条正式规则”。

### 9.1 术后病程族交付状态合同

以下状态集合仅覆盖 064–066，不得套用于其他扩展规则。状态使用 Canonical Envelope 词表；运行时通用状态词表不能替代本表的单规则合同。

| 规则 | 允许交付状态                                         | 不允许交付状态               | 状态边界                                                                                                                                                                         |
| ---- | ---------------------------------------------------- | ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 064  | `compliant; non_compliant; not_applicable; data_gap` | `uncertain; technical_error` | 已实施传统手术且术后三日窗口成熟后，按连续三日病程及术者查房覆盖判合规或不合规；无已实施传统手术或观察窗口未成熟判不适用；手术时间、评价终点、文书时间或单台关联不足判数据不足。 |
| 065  | `compliant; non_compliant; not_applicable; data_gap` | `uncertain; technical_error` | 已实施传统手术且72小时窗口可核对时，按上级医师查房覆盖判合规或不合规；无已实施传统手术判不适用；手术时间、评价终点、查房身份/时间或单台关联不足判数据不足。                      |
| 066  | `compliant; non_compliant; not_applicable; data_gap` | `uncertain; technical_error` | 已实施传统手术且能唯一关联术后首次病程时判合规或不合规；无已实施传统手术判不适用；手术事件、病程或单台关联资料不足判数据不足。                                                   |

`technical_error` 仅表示执行失败，必须修复或重试，不能作为质控结果交付；`uncertain` 不属于本族交付状态。

## 12. 引擎落地要求

1. 标准先写入版本化 Fact/Decision 合同，再修改 `phase_scope`；不得先改标签制造已完成假象。

3. 部分确定规则只能执行已列明子判定；未确认子判定不得影响最终状态。
4. 确定性存在性、时间和数值计算使用Python；语义判断仅接收最小必要上下文，并输出受控事实枚举。
