# 泸县 0609 质控点业务口径待确认清单

> **历史文档提示（2026-08-02）：** 本文件保留为客户确认过程记录。当前有效业务标准及剩余最小确认项，以 [`泸县0609质控点-业务标准基线-v1.md`](./泸县0609质控点-业务标准基线-v1.md) 为准；已被2026年版规范或院方补充口径确认的事项，不再按本清单重复询问。

> 文档用途：请医院质控、医务、药学、输血、检验、影像及信息部门共同确认。  
> 确认目标：将质控点中的“明确、规范、完整、阳性、重点、特殊、及时”等描述转化为可统一执行、可复核的医院口径。  
> 说明：本清单仅列出仍需院方解释或提供字典的内容；已有明确时限、文书存在性和适用条件的质控点不在本清单中。

## 一、为什么需要确认

同一条质控描述在不同医院、不同制度版本中可能有不同含义。例如：

- “阳性影像结果”具体包含哪些结果；
- “会诊意见明确”至少应写哪些内容；
- “输血前检查完整”具体包含哪些项目、结果在多长时间内有效；
- 哪些抗菌药属于“重点抗菌药”或“特殊使用级抗菌药”；
- 哪些操作属于“有创操作”。

如果没有统一口径，系统只能看到文书或数据存在，却无法可靠判断其内容是否满足贵院要求，容易产生误报或漏报。因此，下列项目需要院方给出制度、字典、字段清单或具体判定标准。

## 二、院方建议提供的材料

如已有院内制度，可直接提供制度名称、版本和附件，不必重新编写：

1. 病历书写与时限管理制度。
2. 会诊记录、麻醉访视、输血记录等文书模板及必填项说明。
3. 危急值项目和阈值清单。
4. 抗菌药物分级目录、重点监控目录及特殊使用级专家授权名单。
5. 化疗药物目录。
6. 输血前检查项目及有效期规定。
7. 手术分级、恶性肿瘤术式及淋巴结清扫适用范围。
8. 有创操作目录。
9. 医嘱、收费项目和血制品编码对照表。
10. 主诊断选择与诊断顺序管理规定。

## 五、建议的确认方式

院方可在每条质控点后按以下格式回复：

| 回复项          | 填写内容                                   |
| --------------- | ------------------------------------------ |
| 采用的院内制度  | 制度名称、版本、发布日期                   |
| 适用范围        | 适用患者、科室、诊断、手术、药品或事件     |
| 触发条件        | 什么情况下启动本条质控                     |
| 判定标准        | 满足什么条件算合规，什么条件算问题         |
| 数据来源        | 以哪张表、哪类文书、哪个字段或哪个时间为准 |
| 时间要求        | 起算时间、截止时间、允许偏差               |
| 例外情况        | 急诊、抢救、患者拒绝、数据补录等如何处理   |
| 合规示例        | 一至两个院方认可的记录示例                 |
| 不合规示例      | 一至两个院方认可的问题示例                 |
| 责任部门/确认人 | 负责解释并最终确认口径的部门和人员         |

| 病案科            | 主诊断、其他诊断及诊断顺序规则                         |
| 信息科            | 数据表、字段、编码映射、事件关联键和权威时间来源       |

## 七、确认后的处理原则

1. 院方确认的口径应标注制度版本和生效日期，后续制度变更时同步更新。
2. 同一质控点存在多部门口径时，以院方最终书面确认版本为准。
3. 无法从现有数据取得的字段，应明确属于“需补充数据接口”，不能直接判为病历问题。
4. 未完成业务定义的质控点不应以模糊关键词直接判定合规或不合规。
5. 每条规则上线前应至少使用合规、问题、不适用和资料缺失四类脱敏病例共同验收。
