## 一、范围与验收口径（先纠正一个错误认知）

- 客户规则 **72 条 = 65 条执行 + 7 条暂停**，**2160 = 30 例 × 72 条，全部需要验收**。

### B 组：执行中但此前无口径，新定标准（9 条）

这 9 条规则每轮都在执行、每个结果都计入 2160，但口径栏此前是空的。以下标准为我方新定。

#### B1 LX0609-010 CT/MRI 检查前病程记录

1. 窗口：以 CT/MRI **医嘱开立时间**为锚点，前 **24 小时内**的病程记录视为“检查前病程”；无医嘱时取检查报告时间。
2. 关联：一条病程可覆盖**同一医嘱组内**的多次检查；跨医嘱组的检查各自需要 24 小时内病程。
3. 内容：病程必须写明检查原因或临床指征（症状、体征、诊断依据之一）；仅写“完善检查”不算。
4. 急诊例外：医嘱来源标记为急诊，或检查发生在入院 24 小时内 → `not_applicable`。
5. 无医嘱且无报告时间 → `data_gap`。

依据：病历书写规范 + 项目组数据合同。可替换：是（窗口时长、急诊例外范围）。
实现前置：当前为 `needs_data_linkage`，需先接入 CT/MRI 医嘱与报告时间。

#### B2 LX0609-017 病程复制（相似度 >70%）

1. 相似度按**正文**计算，排除标题、签名与模板固定段。
2. 相似度 >70% 只作为**候选**，最终判定必须结合文书角色与患者特异事实：不同层级查房对病史、诊断依据的**必要复述豁免**；诊疗计划、患者特异症状体征、检查结果大段复用且缺少当日变化 → 判不符合。
3. “2 次以上”按 **≥2 份**记录构成一对即触发。
4. 同一天内的模板段落不计入相似度。

依据：客户规则文字 + R08 真实病例复核。可替换：否（已用真实病例冻结 C05 反例）。
说明：台账中唯一标为“待业务口径确认”的记录 C05/LX0609-017 即以本标准第 2 条为口径依据。

#### B3 LX0609-024 恶性肿瘤手术记录未书写淋巴结清扫情况

1. 触发：手术记录 + 出院诊断或病理诊断含恶性肿瘤（ICD-10 C00–C97）。
2. 要求：手术记录须写明区域淋巴结清扫/采样情况，或写明未清扫原因。
3. 不触发：活检、探查、姑息短路等明确不涉及淋巴清扫的术式（以手术记录所写术式为准）。
4. 既未写清扫也未说明原因 → 不符合。

依据：病历书写规范（手术记录应记载术中取材）+ 项目组判断。可替换：是（肿瘤编码范围与术式豁免清单）。

#### B4 LX0609-026 化疗记录与医嘱一致性

1. 化疗药识别以院方药品目录中的抗肿瘤药（ATC L01）为准，不使用关键词猜测。
2. 比对字段：药名、单次剂量、给药途径、给药频次、开始时间；**不比对结束时间**。
3. 时间差 ≤24 小时且剂量一致 → 视为一致；剂量不一致 → 不符合。
4. 病程完全未记录该次化疗 → 不符合。
5. 医嘱数据未接入 → `data_gap`。

依据：客户规则文字 + 项目组数据合同。可替换：是（字段集与容差）。
实现前置：`needs_data_linkage`，需接入化疗医嘱与药品目录。

#### B5 LX0609-037 麻醉访视记录填写

1. 范围：全麻、椎管内麻醉、神经阻滞等非局麻麻醉需术前 + 术后访视；局麻与表面麻醉不纳入。
2. 术前必填：麻醉方式、ASA 分级、气道评估、心肺听诊、禁食时间、术前用药、麻醉同意书签名与时间。
3. 术后必填：麻醉方式、手术时间、苏醒情况、生命体征、镇痛方案、并发症。
4. 判定：任一份访视缺失 → 不符合；必填项缺 ≥2 项 → 不符合；仅缺 1 项 → 提示类，不判不符合。

依据：病历书写基本规范与麻醉科质控要求 + 项目组判断（必填清单为项目组判断，可替换）。可替换：是（必填清单与缺项阈值）。

#### B6 LX0609-044 输血前评估记录

1. 触发：存在实际输血事件。
2. 评估至少包含：输血指征（含实验室指标值）、血制品选择、风险与预期效果告知。
3. 三项缺任一 → 不符合；仅写“同意输血” → 不符合。

依据：《医疗机构临床用血管理办法》 + 项目组判断。可替换：是（最低内容清单）。
实现前置：`needs_cross_document`，需固化评估记录字段抽取。

#### B7 LX0609-046 输血病程记录完整性

1. 输血前：指征与知情同意；输血中：血制品、剂量、开始时间、生命体征；输血后：疗效评价与不良反应。
2. 三段各缺一项即不符合；无不良反应时须写“无不良反应”或“未见输血反应”。

依据：《医疗机构临床用血管理办法》 + 项目组判断。可替换：是（字段清单）。
实现前置：`needs_cross_document`。

#### B8 LX0609-048 术中输血记录一致性

1. 比对对象：手术记录、麻醉记录、术后首次病程中的输血成分、数量与时间。
2. 以**麻醉记录**为术中输血的主要依据，手术记录与术后首次病程须与其一致。
3. 数量差异 >0 或时间差 >2 小时 → 不符合。

依据：客户规则文字 + 项目组判断。可替换：是（容差）。
实现前置：`needs_cross_document`，多文书字段抽取未完成。

#### B9 LX0609-050 入院 7 天诊断不明确但无疑难病例讨论

1. “诊断不明确”认定：首页/出院诊断栏为“待查”“原因不明”“诊断不明”，或入院后第 7 天病程仍出现“诊断待明确”“拟诊”“原因待查”。
2. 起算：以**入院时间**起算 7 个自然日。
3. 要求：第 7 天仍不明确时，应有疑难病例讨论记录、科内会诊或多学科会诊记录之一。
4. 已明确诊断，或患者 7 天内出院/转院 → `not_applicable`。

依据：疑难病例讨论制度 + 项目组判断。可替换：是（认定方式与起算点）。

## 四、依据分级与可替换性规则

| 级别       | 含义                                                                                       | 处理                                                       |

## 五、影响与验收

- 本汇编不改变任何执行链结构：不新增模型调用、不新增事实所有者、不新增配置开关。
- A 组为口径固化，不改变现有判定结果；B 组为新口径，实施后可能改变 010、017、024、026、037、044、046、048、050 的状态分布，须逐条做真实病例回归。
- 每条标准生效时，必须同时具备：真实病例回归证据、状态/原因码/客户展示事实/证据定位四项一致的核对记录、以及台账对应记录的更新。
- 回归范围按 2160 项口径执行，暂停规则按 D 组理由在报告中说明。
