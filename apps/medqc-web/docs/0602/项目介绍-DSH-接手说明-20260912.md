## 五、近期最重要的工程结论（先看这四条，能省掉几周弯路）

### 1. 023「判定对象抖动」已用“病例级事实冻结”解决（工程路线 D，已上线）

- 问题证据：同一病例、同一模型、3 轮重复执行，第一阶段抽出的**建议条数与原文会变**（C17 1/3/1、C25 8/8/9、C30 3/18/18），而 `recommendation_ref` 只是按数组顺序编号，所以 020/023 的判定对象每轮都不一样。
- 取舍证据：用确定性 Python 切分替代模型抽取**已被实测否决**（建议集合稳定 16/17，但 023 命中从 11/17 掉到 4/17，切出“医生签名”“化验值”等垃圾原子）；唯一可行的是把模型产出**按病例版本冻结**。
- 落地：`consultation_opinion_freeze.py` 按 `visit_id + 会诊文书内容指纹` 冻结第一阶段 payload（首次抽取并校验后原子落盘，后续复用且不调模型，内容变化即失效）。默认落点 `backend/data/luxian_0609_opinion_freeze`，可用 `LUXIAN_0609_OPINION_FREEZE_DIR` 覆盖，`reset_opinion_freeze()` 是重抽入口。
- 验收：17 例 × 3 轮建议集合一致 **12/17 → 17/17**；023 命中 11/17 → 12/17；round2-3 模型调用 97→64、Token 470,085→371,818；已关闭记录零回退。
- 落盘前**逐字落地校验**已补齐（schema v2，不可落地的摘录不写盘并按 `technical_error/model_invalid_output` 失败，避免把伪造摘录固化）。
- 已知局限：只治“判定对象不同”，**不治“模型判断本身不稳”**——冻结后 C21、C25 仍会翻，属第二阶段“哪句话算执行痕迹”的选择抖动。

### 2. 「事实冻结 + 判定分离」已冻结为可复用合同

见《LX0609 我方口径标准汇编》第五节：三步（专用提示词只抽事实 → 按病例版本冻结 → 判定在固定事实上重跑）、三条适用判据（判定对象由模型生成 / 跨文书语义关联 / 会被反复执行或复核）、五条强制配套（逐字落地校验、指纹+版本+重抽入口、不完整输入不冻结、并发首写者赢、结果可审计）。**不适用**读结构化字段即可判定的确定性规则（061、052、005 等）。

### 3. 抽取模型与判定模型可以不同（POC 已验证）

抽取固定 `qwen3.7-flash` 并冻结后，判定阶段换模型：判定 qwen → 023 命中 11/17、稳定 16/17；判定 `deepseek-flash` → 命中 **13/17**、稳定 15/17，判定调用还少 18%。结论：解耦成立、判定模型选型值钱，但换判定模型消灭不了抖动，且 deepseek 判定下**已关闭记录 C02 有 2/3 轮回退**，按“已关闭记录零回退”门槛不得直接切换。

### 4. R11（054/055/057）复用冻结是最低成本的下一步

它的抽取器已是单一受控所有者（严格 schema + 逐字落地校验 + 截断即 `data_gap/source_truncated`），只缺“冻结/失效”和“结果来源标识”。POC 实测：事实 3 轮一致 24/27 → **27/27**，模型调用 6→2、Token 3,907→1,317；但**最终状态本来就不抖（27/27）**，所以它的价值是“事实可复现 + 省调用”，不是修错判。

## 八、开发约束（来自 `AGENTS.md`，违反会被打回）

1. **最小闭环**：一个规则族 → 一个根因 → 最小修改 → 聚焦测试 → 真实病例复核 → 停。
2. **不新增事实所有者**：同一业务事实只能有一个权威所有者和一条主资料链；冻结、口径、状态映射都不得出现第二个来源。
3. **不新增平台/开关/抽象**，除非已记录至少两个已发生的独立问题并给出增量验收指标。
4. **巨型文件**：Python 文件越过 2000 行后，新增职责必须先说明为什么不能进独立模块；不得为了行数做转发壳。
5. 判定归执行器、文案归 Renderer、校验归 Finalizer、装配归 Aggregator；后续层不得改写状态与原因码。
6. 提交用中文 message；提交前跑 `check:encoding`（本仓库还对 staged 文件跑 prettier/lint-staged）。

## 九、已知坑（本会话踩过，务必先读）

1. **子代理任务正文送不到**：spawn/followup 的正文走 `encrypted_content`，本机会话挂在自定义 provider（DeepSeek）时无人解密，子代理只看到空的 `Payload:`。绕过办法：把任务书写成**磁盘文件**（例：`.tmp/0910-full-audit/tasks/*.md`），spawn 时用 `fork_turns:"all"` 继承上下文，并把文件路径写进**会话可见文本**；不要用 `model` 覆盖。
2. **并发槽位只有 4 个（含主 Agent）**，僵尸子代理会占满导致 `agent thread limit reached`；派发前先 `list_agents`，必要时中断闲置代理。
3. **冻结落点已被测试隔离**（`backend/tests/conftest.py` 自动 fixture）；本地手工跑要用 `LUXIAN_0609_OPINION_FREEZE_DIR` 指向临时目录，别写进仓库 `data/`。
4. **判定层抖动是真实存在的**：同一份冻结事实换模型/多轮重跑，023 仍会有 1–2 例翻转；任何“提升命中”的改动都必须过“已关闭记录零回退”门槛。
5. 全量 `backend/tests/unit` 很重（曾跑 35 分钟未完，疑似有依赖网络的用例）；按改动范围跑聚焦用例，最后整批回归时再统一跑。
