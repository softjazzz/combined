1. 对 `覆盖矩阵匹配` 不为空的规则，优先复核是否应补入对应 LX0609 的 `rule_ids`。
2. 对 `规则存在但未进入泸县0609目录` 的规则，确认是否属于客户第一批 49 条；不属于则不要纳入。
3. 对歧义映射，不能自动猜测，需要在样本候选中保留人工选择。
4. 映射补齐后重新导出 golden candidates，再补正式 golden cases。
