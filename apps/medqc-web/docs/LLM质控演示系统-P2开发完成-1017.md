## 🔍 技术细节

### 1. CSS 动画
```less
@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

### 2. 渐变背景
```less
background: linear-gradient(135deg, #f5f7fa 0%, #e8ecf1 100%);
```

### 3. 紫色渐变步骤
```less
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### 4. 自定义滚动条
```less
&::-webkit-scrollbar {
  width: 6px;
}

&::-webkit-scrollbar-track {
  background: #f0f0f0;
  border-radius: 3px;
}

&::-webkit-scrollbar-thumb {
  background: #bfbfbf;
  border-radius: 3px;
  
  &:hover {
    background: #999;
  }
}
```
