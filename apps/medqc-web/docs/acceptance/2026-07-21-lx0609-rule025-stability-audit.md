## 结论

`LX0609-025` 维持 **Shadow**，不得进入客户主链。

固定 20 例、45 条影子规则复测中，900 条安全 evidence 摘要均保持一致，
只有 `LX0609-025` 出现一次状态与原因码漂移。对同一脱敏证据快照的连续三次
单点复测依次得到：`data_gap → non_compliant → data_gap`。

因此不能把当前 3 条 `non_compliant` 候选当作已验收缺陷，也不能以合成

## 已排查的边界

- Python 归约是确定性的：
  - `explicit_no_implant` → `not_applicable`；
  - 未证明“本次实际永久植入” → `data_gap`；
  - 已证明实际永久植入且必填字段缺失 → `non_compliant`；
  - 字段不明 → `data_gap`；字段齐全 → `compliant`。
- 三次运行的 evidence 摘要相同，故不能把本次漂移归因于病例选择、证据顺序或
  Python 状态归约。
- 当前 typed evidence 只读取手术记录和手术表；旧路径中的 `implant_usage`
  尚未被证明可安全关联“本次手术、实际使用、永久植入物类别”。
- 默认模型参数是 `temperature=0.2`、`top_p=0.9`。另一个临时参数试验的三次
  结果虽均为 `data_gap`，但样本量不足、未绑定完整运行指纹，也没有人工真值，
  不能据此改变生产默认参数。

最强根因假设是：模型在“是否为本次实际永久植入”或“字段缺失/不明”的事实
枚举上发生波动。这个假设仍需受控复测证伪。

## 后续最小闭环
