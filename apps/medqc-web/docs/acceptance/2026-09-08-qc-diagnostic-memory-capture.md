# 模型实际尝试的内存采集接缝

## 已实现

- `qc_llm_client._perform_observed_attempt` 仅增加开始/结束旁路调用，实际 HTTP 请求之前冻结 payload，返回响应后、业务修改之前冻结响应。没有录制 headers、端点或客户端密钥。
- 新 `capture.py` 独立承担显式作用域、快照、尝试配对、容量与释放职责；不增加数据库、模型调用或文件存储。
- 默认 ContextVar 为空，不复制、不遍历请求；只有显式 `capture_scope` 才记录。尚未在客户任务入口启用。
- 同一个病例作用域按已有 logical_call_id + attempt_no 配对；记录既有 executor_key。已有观测上下文的任务/病例身份改变时拒绝继续录制，标记 partial。上下文缺失也明确记录，不能声明证据完整。
- 请求、响应以有界 typed values 冻结，返回独立副本供后续本地脱敏。原件不能通过历史诊断包接口导出；未实现模型原文的对外脱敏合同。
- 最多 256 个尝试，单请求/响应编码后最多 4 MiB，作用域保留编码内容最多 20 MiB。容量并非进程 RSS 上限；读取副本的额外内存由调用方负责。
- 默认有效期 30 分钟，操作/读取时检查过期；作用域退出立即释放持有引用，取消时同样执行 finally。没有后台定时擦除或安全内存清零保证；长时间无操作时以作用域退出释放为最终边界，启用客户采集前仍须结合任务超时约束。
- 不支持将整个并发病例批次放入同一个作用域；单病例授权、已读取材料、最终结果绑定及导出接线仍未完成。

## 验证

- 先运行缺失模块红测试，再运行真实客户端接缝红测试，分别验证模块及接线缺失；实现后采集、原模型客户端、LLM 观测聚焦测试合计 32 passed。
- 合成数据覆盖：两病例并发/重试；请求和响应冻结；作用域结束后迟到响应丢弃；重复/未完成尝试；不同病例上下文；容量超限；嵌套只读映射内密钥拒绝；默认关闭不检查任意对象；真实客户端返回对象、HTTP 调用次数保持不变；取消原样传播。
- 安装禁止 socket.connect/getaddrinfo/sqlite3.connect 的审计钩子后运行合成基准，没有外部 I/O。
- 本机微基准：默认关闭每次旁路约 0.14 微秒；100 KB 请求 + 10 KB 响应，开启 tracemalloc 时每次约 0.51 毫秒；100 次尝试保留编码内容 11,037,700 字节，tracemalloc 峰值 11,167,315 字节；退出后保留字节数为 0。
- 上述只是微基准，不代表真实临床批次新增非模型耗时低于 5%，也不代表真实模型准确率已验收。
- 诊断全套 + 原客户端/观测回归：240 passed，5.30 秒，2 条现有 Pydantic 弃用警告。编码检查通过并补查本批文件 UTF-8/no BOM/LF；全局 lint 0 errors、677 warnings。本批没有前端或共享 TS 边界变更，沿用上一批已通过的类型检查和 880 项全量前端测试，不重复运行。

## 下一接口边界

授权的单病例执行范围需要在原资料 session 创建后绑定材料，在最终结果可用时于作用域退出前完成本地脱敏。不得从当前数据库补采历史原件；不得将 `read_internal()` 的返回值直接写文件或返回 API。本批仅接好真实尝试录制接缝，不将完整诊断功能记为完成。
