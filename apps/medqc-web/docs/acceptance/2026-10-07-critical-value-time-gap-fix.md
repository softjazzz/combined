# 危急值处置时间缺口修复

日期：2026-10-07。针对独立审查 CV-01；未改 CV-Q1 的文书接受口径。

## 修复与范围

`_critical_value_disposition_from_row` 保留时间缺失/不可解析的处置行及关联键。危急值执行器先关联事件，再区分已确认及时/报告后处置、处置存在但时间未知、时间早于报告的冲突、确实没有处置。

同报告的处置时间缺失/非法：两条规则均为 `data_gap / authoritative_time_missing`；仅有报告前处置：两条均为 `data_gap / authoritative_time_conflict`。不会自动判合规，也不再把有记录写成未处置/确定超时。多事件保留逐事件结论，未受影响事件仍保留及时或已有处置事实；整条规则遇到时间缺口保守交付资料不足。

已确认及时处置可满足01；已确认报告后处置可满足02。未知时间记录不能把已确认及时记录反向污染为资料不足；已知超时记录与未知时间记录并存时，01不能证明最早处置已超时，02仍满足存在性。无处置且窗口已成熟仍不合规，不同报告不能借用处置。来源继续仅使用现有专用危急值表，不扩展病程文书。

危急值专属客户事实/发布校验新增两个逐事件 outcome：`authoritative_time_missing`、`authoritative_time_conflict`，仅允许资料不足状态。保留已关联处置行的证据引用；Renderer按这些已裁决事实写“已找到关联处置记录，但时间无法核对”，不重新推断。没有新增模型调用或公共抽象。
