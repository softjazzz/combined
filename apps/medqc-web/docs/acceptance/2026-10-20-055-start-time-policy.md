# 055 起算时间客户口径冻结（2026-10-20）

适用规则：`LX0609-05-01-03`。

客户允许 48～72 小时评价窗口按计划开始或开医嘱时间起算；实现沿用以下顺序：

1. 优先取抗菌药医嘱的计划开始时间 `planned_start_datetime`。
2. 计划开始时间缺失或为空时，回退开医嘱时间 `prescribed_datetime`。
3. 选中的时间不可解析时保持资料不足；非空但非法的计划时间不静默回退。

本规则不要求取得首次实际执行时间。`carried_datetime` 作为独立源证据保留在 native 与 snapshot 投影中，不参与055窗口起算，也不改变已有临床结论。

当前 `_antimicrobial_start_datetime` 的优先级已符合本口径，无需修改055执行程序。匿名合成回归覆盖计划时间优先和开医嘱时间回退；本轮冻结来源中，C04的5个窗口、C12与C13各1个窗口均匹配计划开始时间，三例保持 `non_compliant/threshold_exceeded`。
