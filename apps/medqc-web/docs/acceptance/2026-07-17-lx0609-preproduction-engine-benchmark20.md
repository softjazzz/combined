## 1. 本轮交付是什么

本轮建立了一个独立、只读、无持久化的 LX0609 准生产入口，并在提交
`ea3c4b125` 增加独立 FastAPI 接口
`POST /api/v1/qc/luxian-0609/preproduction/evaluate`。调用方显式传入：

- running/final 场景与就诊三坐标；
- 49 个客户规则 ID；
- 冻结的 `evaluation_as_of_date`。

服务端只用固定17列、三坐标绑定和 `LIMIT 1` 读取已持久化病例包，再调用独立 runner。入口不调用四川旧服务、任务 API、workspace API 或持久化 API。返回对象只有有序的客户结果 DTO 和聚合运行指标。开关 `LUXIAN_0609_PREPRODUCTION_API_ENABLED` 默认关闭；现有客户主链没有切换。

截至 `42d0ba621`，报告当时记录为49条规则已进入统一 `RuleDecision` 判定内核：

| 判定形态             | 规则数 |
| -------------------- | -----: |
| 统一 `RuleDecision`  |     49 |
| typed shadow adapter |      0 |
| legacy projection    |      0 |

该结论是历史快照。2026-07-21 在已提交干净 checkout 的复核发现，会诊
020–023 在当前预生产设置下未生成逐规则 `RuleDecision` trace，不能进入

当前版本的 Golden、语义稳定性和前端人工验收门。

## 2. 测试方法

- 同一批20份本地真实病历；同一49规则目录顺序。
- 样本由既有固定10例和稳定补充10例组成。
- 模型配置相同，并发为1，缓存关闭。
- 新旧路径均不写数据库、不创建任务、不修改客户结果。
- 统一冻结评价日为 `2026-07-17`。
- 补充10例来自相对完整的0426病例集合；该集合普遍缺首次病程记录。
- 因首次病程缺失，依赖该文书的 LX0609-002、LX0609-016 共40条判断不纳入临床准确性结论，但仍纳入范围、性能和技术错误统计。

## 7. 隐私和客户边界

最新准生产 DTO 已进行递归扫描：

- 不包含 institute/patient/visit 三坐标；
- 不包含病历正文、完整长文本或正文前缀；
- 不包含 prompt、raw response、SQL、异常文本；
- 不包含 `evidence_payload`、`fact_refs`、snapshot、documents、bundle；
- 不包含旧映射 ID 或 `mapped_rule_ids`、`primary_execution_rule_id`；
- 保留客户可读的安全 `evidence_items` 和受控来源名称。

真实 API 20例响应再次逐一扫描全部三坐标、病例正文24字符前缀和禁用内部字段，
命中均为0。关闭开关后，同一 checkout 的真实认证请求在120.636ms返回404；该
路径在认证存储、请求正文解析、病例读取、模型客户端和 runner 之前终止。开启、
关闭两个8002测试进程均已按PID停止，未触碰8001。

基础 settings 使用只读 overlay，不修改进程环境或持久化配置。基础设施异常会为所选规则返回安全 `technical_error`，不会回显异常。

## 8. 验收决定和剩余限制

### 有条件 GO

独立 API、默认关闭开关、20例真实请求、隐私检查和关闭回滚已经完成。前端人工试用
仍需满足：

1. 人工接受本报告的样本边界和 `data_gap` 增加；
2. 前端只消费准生产 DTO，不读取内部 trace；
3. 初始流量限定为内部人工验收，不回写客户正式结果；
4. 保留旧引擎作为一键回滚路径。

### 尚未完成

- 49条规则内核迁移已完成，当前没有 adapter 或 legacy projection；
- Golden 已独立接受900/980，剩余80条语义判断待第二次人工复核，尚未达到全规则发布门；
- LX0609-009 的“病情变化时是否及时记录”语义子结论仍可能为 `data_gap`；
- 002/016 在本20例缺首次病程记录，不能据此评价临床准确性；
- 最新修复后的语义规则3次稳定性、最新版本真实 HTTP 20例复跑和全规则随机样本准确率仍属于后续发布门。

因此：**49条规则迁移与准生产旁路已经完成，可以交给人工验收；Golden和最新稳定性门未完成前，不得自动替换正式客户主链。**
