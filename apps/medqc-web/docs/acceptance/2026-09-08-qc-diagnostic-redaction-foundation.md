# 诊断材料脱敏与文书引用重建：基础验收

本记录只覆盖 T2 的内部数据转换与 document ref 重建，不代表客户诊断包可外发，亦不代表 T2/T4 全部通过。原有质控执行、状态、存储和前端均未接入本批模块。

## 已实现的边界

- `typed_values.py`：只接受明确类型的 tagged JSON 编解码。保留 null、空串、缺字段、tuple/list、dict/只读映射、Decimal scale、UUID、日期/时间、offset/fold/ZoneInfo；拒绝自定义对象/时区回调、非法数字和超限结构。**它本身不脱敏，不能直接对外输出。**
- `sanitization.py`：一个病例/包使用一个局部身份字典和随机别名，全部材料与模型 JSON 共同转换。字段必须由可信调用方固定允许清单；未知字段、凭据、路径、不能可靠解析的 JSON/日期与残留身份硬性拒绝。
- 支持病例内一致的日期偏移，保留跨日间隔；检测 DST offset 变化、未知时间格式、部分日期及文本长度变化。报告只给计数与限制，不含原始身份字典、偏移量或旧值。
- `material_redaction.py`：使用既有 canonical/occurrence 算法重建 document refs，不新建摘要口径。新引用通过行对象对应旧引用，而不是直接配对两个排序后的引用列表；保留源状态参数、重复 occurrence、原行顺序及引用顺序。

## 已发生的反证与修复

1. 零宽字符、全角数字、带空格/横线手机号绕过替换：补规范化、格式识别及残留扫描。
2. 姓名标签吞掉后面的年龄和诊断：标签按临床字段边界分隔，无法确定身份边界时拒绝，不凭贪婪匹配截掉正文。
3. 混用斜线、点分、紧凑日期时只偏移一部分：补格式处理；无法识别的时间字段不再标时间等价。
4. 数字身份恰等于年份时破坏时间轴：拒绝歧义输入，不能先替换成数字别名再宣称时间等价。
5. 未标注字段里的 UUID、不同形式手机号映射不一致：统一类型/形式处理。
6. 全不可见身份、空白身份和非法 Unicode 产生空匹配或原异常：改为固定安全错误。
7. 对 canonical 排序后的文书做脱敏会改变原始资料顺序：保留原行顺序，只借权威排序计算引用。

这些测试全部使用人工构造身份、时间和文书，不读取客户资料；反证先失败，再修复。安全反例允许明确拒绝，不允许残留身份、吞掉临床信息或虚报等价；另有正向测试验证正常输入确实可转换，避免以全部拒绝冒充功能完成。

## 尚未通过的整体验收

- 每个真实来源/模型输出的固定允许清单尚待与 T3 采集合同对接，当前调用方参数不能直接暴露给客户端。
- document ref 重建不是 FactV2、snapshot hash、模型引文位置或逻辑调用匹配重建；这些仍须接既有合同完成后才能声明执行器回放。
- 自由文本自动识别不保证零遗漏；`automatic_export_allowed` 保持 false，必须再通过独立隐私扫描、规则相关等价验证和客户预览流程。
- 尚未用真实客户采集包逐字节做导出泄漏检查，亦未完成 018 字数/相似度、076/029 执行及会诊录制响应回放的完整验证。
- 仍需完成 T3 加密存储/旁路采集、T5 权限与导出、T6 安装包验收，不能据本批测试关闭整体目标。

## 运行方式

使用 `PYTHONPATH=backend` 和 `pytest --noconftest` 跑 `test_qc_diagnostic_*.py` 及诊断 replay 集成测试，避免全局 conftest 初始化 demo 数据库。引用算法导入依赖现有资料模块；这里只调用纯计算，不调用来源读取器。

提交前诊断专项与既有诊断 replay 集成测试合计 **191 passed，4.58 秒**。其中材料重建包含独立新进程测试，禁止 socket connect/DNS 和 SQLite connect；实际运行成功且未记录任何访问尝试。类型/脱敏/材料新增测试共 95 项，首批诊断回归 96 项。

`npm run check:encoding` 通过但扫描 0 文件，另逐字节验证本批 9 个文件 UTF-8/无 BOM/LF。`npm run lint -- --no-fix` 为 0 errors、652 条既有 UI warnings。未改前端、TS/API 合同或临床执行器，因此本批不重复全量前端 type-check/test:unit。不触碰用户已暂存/未暂存的 UI 修改，不推送或生成发布包。
