# LX0609 手术族精确证据引用前置核验

## 范围

本次只核验 `LX0609-025`、`034`、`036`、`039`、`040` 的正式执行器
`RuleDecision.fact_refs`。不修改 Aggregator、Finalizer、Renderer、任务入口、
API 或前端；旧的展示事实兼容字段也不作为本次客户证据依据。

## 结论

- `025` 的逐行文书坐标仅来自模型明确引用的 `surgery_record`；
  `daily_course_record` 只保留来源级快照引用供 Binding 验证，不会形成客户文书证据。
- `034`、`036` 只绑定其麻醉触发事实及实际读取的同意书或麻醉访视文书。
- `039` 绑定实施手术、抢救例外和术前讨论这三类实际参与判定的材料。多台手术而术前讨论为空时，
  现行口径逐台保留手术证据并输出缺失结论；没有稳定事件关联键的跨文书匹配仍按既有业务口径处理，
  本次不改变状态、原因码或关联算法。
- `040` 对四级手术仅绑定实际触发的手术行；对确定性或受控语义的 MDT 结论，只追加实际匹配的术前讨论/会诊文书。
- 非法引用通过 Binding 失败关闭为 `technical_error`；来源查询错误的执行器输出同样保持 `technical_error`，不会伪装为临床资料缺口。
