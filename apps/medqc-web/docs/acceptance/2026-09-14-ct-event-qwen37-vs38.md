# 011/012：qwen3.7-flash 与 qwen3.8-flash 同期对照

日期：2026-09-14。用户要求试验3.7-flash。结论：本轮3.7更快，但出现两项错误合规，不支持替换3.8；3.8仍有事件语义抖动，不能因终态全部正确而登记稳定性已收口。生产代码、schema与默认模型均未修改。

## 固定条件

沿用完整单事件E候选和此前冻结的6例14事件、28个规则事件参考答案，病例为C01/C03/C07/C11/C18/C24。参考答案在本轮调用前已经保存，本轮未更改。每个事件共用一次模型事实供011和012映射。

两个模型均开启思考256 Token，temperature=0.2、top_p=0.9，输出上限4096；使用普通JSON提示，不额外启用严格response_format，与上一轮E主试验一致。原材料仍来自同一Bundle资料链的冻结投影，不回读CDM。14个首答提示词均与旧E逐字一致，两模型之间也完全一致。

主协调检查客户端请求组装代码，并实测两个模型客户端的provider payload均为enable_thinking=true、thinking_budget=256，temperature/top_p一致。模型显式指定，无模型回退。输入、校验器、原生时间与终态映射保持相同。

同期重跑3.8控制组，不使用前一次运行的耗时作速度基线。按病例依次执行，两个模型先后顺序逐病例交替；单病例最多两个事件并发。一次无效输出最多恢复一次，失败继续计入固定28项分母。请求耗时求和与该病例事实阶段墙钟时间分开记录。

## 主协调逐原答与引用核实的差异

- **C01#4，011/012**：3.7首答和恢复答均为unknown，两条视图均记内部模型失败，不生成临床终态。3.8为absent，形成不合规。这是模型判断未知，不是JSON格式错误。
- **C07#1，012**：3.7原答absent，遗漏既有报告关联与医生处置，形成错误不合规；3.8保留present，合规。固定参考与上一轮主审相同。
- **C07#2，011**：3.7把D07-01-S3当成MRI结果记录。主协调从实际发送的提示词还原，该句仅为“医生签名:”标签，不含检查结果；引用编号合法，但语义完全不成立，产生错误合规。3.8为absent，不合规。
- **C18#2，011**：3.7在正确的超时病程之外加入D08-01-S6..S8。这三句属于另一份胸部CT，目标事件是头颈CTA。原生终态计算因此选到错误的较早文书而得到合规。主协调逐句核对实际提示词、record_spans、course_doc_refs与终态，并离线只去掉错误文书引用、保留其余事实，真实终态函数从合规变为不合规，确认语义串用导致错误合规，不能靠“引用在白名单内”放行。3.8只引用目标事件的超时病程，正确判不合规。
- **C18#1，012**：两模型本轮均答absent；固定参考为present且分析超时，所以两种语义的事件终态都为不合规。3.8上轮相同首答输入为present，本轮为absent，证明事件语义发生翻转。必须单列这一问题，不能用终态相同宣称稳定。

语义正确数与终态正确数不能互相替代：C18#1语义不符但终态一致；C18#2的3.7语义存在性为present虽与参考一致，错误的证据时间却改变终态。因此仍需逐项看报告关联与证据定位。

## 结论及边界

此次试验没有通过调整提示词、裁剪资料或更改参考答案来迎合3.7，也没有把失败转成资料不足。3.7速度优势不足以抵消已实测的错误合规，当前不推荐换为质控主模型。严格输出格式只能约束字段与枚举，不能保证“签名不是检查结果”或“该引用属于目标检查”等语义成立。

3.8只是在本轮对照中表现更好，其C18语义抖动仍在；完整独立样本、原开发保护集及多轮稳定性验收尚未完成。本轮不扩展新的修复方案、不部署生产。
