## 2. 两组各自的实际错误（已逐项核对）

   **这不是缺陷**：事件 1 资料不足、事件 2 合规时，整条规则不能宣称全部合规，整体 `data_gap`

   **不得通过调整优先级让一条合规掩盖另一条未完成判定**；因此规则汇总优先级本轮不改。
   明细展示是否保留了事件 2 的合规结果，本轮**未验证**，列为待核项。

只有 C 出现、且是**新增错误合规**的失败项（方案 §6 明令禁止）：

   `non_compliant`。** C 引用的是一份**精麻科查房记录的独立诊断列表**；该文书全文不含
