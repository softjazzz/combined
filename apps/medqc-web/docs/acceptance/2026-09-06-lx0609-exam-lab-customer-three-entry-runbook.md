# LX0609 检查检验规则族客户三入口验收清单

日期：2026-09-06

## 目的与边界

本清单用于在客户验收环境验证 `LX0609-010/011/012/014/015` 是否经三个真实业务入口
走同一条 Canonical 主链。不得用合成 fixture、历史任务结果或单元测试替代本验收。

`customer_evidence` 按去重后的证据坐标集合比较；数组顺序不表达优先级。坐标由
`source_type/source_document_id/field_path/record_time` 组成，数量、成员、文书定位必须一致。

## 部署前检查

1. 备份客户数据库。
2. 解压候选包，不复制旧版本的 `frontend/dist` 或后端代码到候选目录。
3. 将客户现用 `.env` 放入候选 `backend` 目录；不得把 `.env`、访问凭证或授权文件回传。
4. 在候选根目录执行只读预检：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\customer-db-preflight.ps1
   ```

5. 记录 `alembic current` 和 `alembic heads`。只有在已备份且确认版本落后时，才由授权
   操作员执行 `python -m alembic -c alembic.ini upgrade head`。
6. 停止旧版本前后端进程，确认启动脚本指向候选目录后再启动；不要让旧、新版本同时
   占用 3000/8001 端口。

## 真实病例覆盖矩阵

病例数量不是验收目标；以下资料形状均需覆盖，缺一项就继续补病例：

| 编号 | 必须覆盖的真实资料形状               |
| ---- | ------------------------------------ |
| M01  | 每条规则至少一份真实适用病例         |
| M02  | 无 CT/MRI、培养等触发事件            |
| M03  | 正常满足规则要求                     |
| M04  | 已证明违反规则要求                   |
| M05  | 有检查/检验医嘱但无正式报告          |
| M06  | 报告存在但事件关联不唯一             |
| M07  | 一次检查包含多个报告项目             |
| M08  | 同一次住院存在多次同类检查           |
| M09  | 培养阳性与全血细胞等普通检验同时存在 |

只在客户内部记录真实 `visit_id`。需要对外共享时使用临时病例别名，不复制姓名、证件号、
完整病历正文或整批质控调试信息。

## 三个入口

对同一病例、同一评价时间和同一组规则分别重新创建任务，不复用历史结果：

1. 单病历单规则入口；
2. 病历池批量质控入口；
3. 客户样本验证入口。

每个入口执行完成后，仅复制对应单条规则的脱敏调试信息，记录：

- `status` 与 `reason_code`；
- `metadata.executor_key`；
- `customer_display_facts`；
- `criterion_results`（如该规则存在）；
- `customer_evidence` 的坐标集合；
- 客户结论及处理建议；
- 是否出现 legacy、pack、bundle 或 LLM fallback；
- 任务是否产生 `technical_error`。

## 通过标准

同一病例同一规则的三个入口必须同时满足：

1. `metadata.executor_key=exam_lab`；
2. 未进入 legacy、pack、bundle 或 LLM fallback；
3. `status`、`reason_code`、客户事实及子结论一致；
4. 证据坐标集合和数量一致，且能够定位真实文书 ID、字段及时间；
5. 客户结论和处理建议一致；
6. 技术故障只表现为 `technical_error`，不得伪装成 `data_gap`、`uncertain` 或
   `not_applicable`；
7. 未触发事件或尚未成熟的观察窗口按已批准规则口径处理，不得被技术故障改变状态。

数组顺序差异不构成失败；证据缺失、增加、错误定位或坐标不同均构成失败。

## 完成条件

覆盖矩阵全部完成、三入口结果一致且没有异常 fallback 后，将本清单和主验收记录状态改为
`PASS`，记录候选包名、代码提交、客户环境版本和脱敏病例别名。完成前检查检验规则族收口
仍为 `BLOCKED`，不得自动进入下一规则族迁移。
