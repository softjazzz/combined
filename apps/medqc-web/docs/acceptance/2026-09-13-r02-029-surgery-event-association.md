# R02 LX0609-029 手术事件关联验收

## 权威口径

业务标准基线规定：有已实施手术的可靠触发事实时，应存在术前小结；治疗性操作和诊断性操作不触发。029 的判定依赖三个可核对事实：已实施传统手术、手术事件能够可靠关联、对应术前小结存在。

本次没有改变触发范围或合规标准，只修正客户 CDM 中“一份正式手术记录对应多行手术组件”以及“同码空壳记录”导致的事件关联失败。正式 `surgery_record` 仍是手术事件的权威文书，`mr_surgery` 用于核对组件日期与操作分类。

## 根因与最小修复

原关联器先比较两个来源的物理行数，再要求逐行、时间戳完全相同的一一匹配。客户数据把同台复合手术在 `mr_surgery` 中拆成多行，日期粒度也与正式记录不同，因此即使只有一份有完整手术经过的正式记录，也会返回 `data_gap / association_failed`。

修复后仍优先使用原严格一对一匹配；只有在以下条件全部满足时，才把多行组件收拢为一台事件：

1. 去除的时间壳必须与实质记录同码或完整名称相同，且自身没有手术经过或有效正文。
2. 去壳后只有一条有实质内容的正式手术记录。
3. 所有目录确认的传统手术组件都有时间，且与正式记录位于同一自然日。
4. 跨日、缺时间或存在两条实质正式记录时继续返回关联失败。
