# N-04 / N-06 最小修复与工程复验

基线：fa5fb788f（生产代码同 d081b3dca）；不含其他工作区改动。

## N-04 麻醉访视空标题

正式快照→执行器→归约→Finalizer，前缀空标签五例在修复前均误判合规。
修复只在 `_row_has_any` 判定文本是否有字段值：冒号后为空或占位符不计已填写。
独立复核又发现同一行空标签借用后一字段值、已填字段被后一空标签误伤，已补失败用例。
对紧连的已知访视字段按标签分段，保留对应字段值；一般未知标签按空白或标点分隔。
正常阴性、有效ASA、结构化签名、带/不带空格的多字段正常值均受保护。
不修改时间要求及多事件关联口径，不声称已穷尽自由文本模板。

## N-06 病理申请日期

去除“取材记录日期不得早于申请日期”的无依据限制；仍要求既有唯一标本或明确业务键与取材内容关联。
不将申请缺时间、泛称标本自动视为关联成功，仍为资料不足；这两项业务口径未关闭。
没有给原夹具注入病理号。新增正常案例使用无病理号手术正文，手术早于申请日。
