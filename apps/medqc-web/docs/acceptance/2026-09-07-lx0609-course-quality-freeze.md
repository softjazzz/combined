## 当前重复所有者：迁移前必须保留、迁移时再消除

这不是本提交要修复的业务口径，而是后续结构迁移必须显式保持的基线：

1. **007 展示事实二次投影**：执行器选择的区间末端文书 ID 会被聚合器的专属安全投影移除；客户结果仍保留时间、间隔和来源。迁移不能在“等价迁移”提交中顺便改变该客户 DTO。
2. **017 展示事实二次投影**：执行器携带的内部匹配引用不会进入客户展示事实；聚合器保留安全的来源、时间、相似度与匹配对。迁移后应由公共投影完成证据定位，但客户字段仍须等价。
3. **008/009 证据补全**：聚合器仍按规则号从展示事实的日期反查病程证据。该规则专属证据选择是后续迁移的明确目标，不能复制到每个执行器。
4. **016/017 规则专属事实校验**：聚合器仍校验复制关系、来源和可展示字段。后续应迁入完整的 `course_quality` 映射职责，而不是新增局部 fallback。
