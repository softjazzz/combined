# 人工缺陷可信文书锚点合同

- 人工补录可以显式选择本次受领病例的稳定文书、字段并填写完整摘录。证据是人工录入时点事实，不表示执行器输入或医学判定；原自由文本证据与 location 不自动升格。
- 文书 owner 为 `load_current_documents`，完整性和稳定标识复用 `capture_documents`，安全引用复用 `build_customer_safe_source_ref`。目录仅列可核验的选中文书，不声称病例全部文书可定位。缺源、合并投影、源截断、重复文书/字段及重复摘录失败关闭，不按名称选首文书。
- 创建在原任务/病历/run锁事务内核验来源并冻结全文至唯一 `manual_create` JSON。每份最多100000字符，捕获整体仍遵守原200份/2000000 UTF-8字节上限；超限拒绝，不截断。请求幂等核对完整锚点参数，历史运行身份不变。
- 普通任务列表及病例列表仅返回锚点元数据，不返回冻结全文；全局审核与批量报表不新增正文。点击单条锚点接口才核验持久账号机构、三坐标、场景、历史任务/run/job及结果Envelope，并重读当前完整文书。全文改变即使摘录仍在也明确不可定位；Workbench再核对全文，沿用既有唯一摘录高亮owner。
- 浏览器隔离文书读取和定位的病例/运行/账户迟到回执；连续点击不同缺陷仅接纳最后请求。人工审核与整改状态各自独立，不改质控结论。
- 本批仅住院运行/终末可信文书；门急诊owner尚未接通时显式拒绝锚点，不借住院资料。未改编码、评分、质控执行器或核心制度分类。
- 无新增表、迁移或业务库写入。本批聚焦合成测试不代表真实病例和浏览器验收；第28项因编码暂停仍保留部分实现。
