## 结论

本次运行证明 45 条 Shadow 规则可以在当前准生产旁路完成一次脱敏、无持久化的
20例复测，并生成逐规则安全 attestation。它**不是 Golden 签收，也不是客户主链
接入批准**。

会诊 020～023 被故意排除：其当前预生产开关默认关闭，若把它们混入同批49条运行，
会因缺少逐规则 trace 而使安全 attestation 失败。详见
[准生产接入清单](2026-07-21-lx0609-preproduction-admission-matrix.md)。

## 运行边界

- 评价日固定为 `2026-07-21`，同一 selector 顺序执行，缓存关闭。
- 每例只读取已持久化病例包；未创建任务、workspace、客户结果或数据库写入。
- 准生产 DTO 在候选构建前经过递归形状与敏感字段校验；候选文件没有三坐标、病历正文、
  提示词、原始模型响应、SQL 或密钥。
- 当前配置模型只在需要语义事实的规则上调用；本报告不输出病例内容或模型文本。

## 复核优先级

1. 先复核本批 107 条确定性输出：64 条 `compliant` 与 43 条 `non_compliant`。
   高风险语义点优先是 017、019、025、040、044、046；不得仅因模型输出而签收。
2. 对 444 条 `data_gap`，先核验缺失原因是否真实；不以正文猜测替代缺失来源。
   001、002、005、006、016、018、034～038 在本样本中全部或高度集中为
   `data_gap`，应先确认样本证据覆盖，而非立刻修改规则。
3. 349 条 `not_applicable` 只抽核触发缺失是否合理；其中 026、027 全部为
   `not_applicable`，应先核验触发合同后再判断是否需要扩大样本。
4. 语义规则在逐条签收后，以同 selector 至少再运行两次；比较状态和 evidence
   attestation hash 的稳定性，再运行正式 Golden Gate。

## 仍未覆盖的风险

- 20例不是随机总体；它不能给出49条规则的总体临床准确率。
- 009、010～015、017、024、025、028、033 等语义/来源敏感点仍需真实人工复核，
  合成 Golden 只能验证已知边界。
- 会诊 020～023 未纳入本批；020 继续暂缓，021～023 要先完成 episode 真实验收
  和 trace 合同。
- 当前没有 `accepted20-v1.json` 或三次同批运行资产，因此 Golden Gate 仍应为
  blocked，客户主链必须保持旧路径。
