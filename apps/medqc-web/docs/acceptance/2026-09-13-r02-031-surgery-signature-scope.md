# LX0609-031 手术记录签名适用范围修复验收

## 问题证据

LX0609-031 核对手术记录是否由手术者书写并签名。其适用性必须先确认当前住院存在传统手术；诊断性或治疗性操作不应仅因源表填写了手术级别而触发本规则。

0910 样本 C29 没有手术记录，`mr_surgery` 中有三条支气管镜相关记录。正式目录已能识别 `33.2700X001` 为诊断性操作，但缺少 `33.2200X003` 和 `33.2403`，旧逻辑因此回退到源表 `surgical_level=二级`，把两条操作误认成传统手术并产出 `data_gap`。

本地权威文件《手术操作分类代码国家临床版3.0（2025绩效手术分级目录）》明确列出：`33.2200X003 纤维支气管镜检查` 和 `33.2403 纤维支气管镜检查伴肺泡灌洗术` 均为诊断性操作。《医疗机构病历书写规范（2026年版）》也分别规定有创诊疗操作记录和手术记录，支持先区分操作类型再判断 031 是否适用。

## 最小修复

- 在现有手术/操作目录中补入上述两个精确编码，分类均为诊断性操作。
- 保留目录分类优先于源表手术级别的既有合同；不修改全局回退逻辑、规则执行器、聚合器或展示层。
- 增加精确编码测试，证明源表即使填写“二级”，目录仍阻止其触发传统手术规则。
- 增加 C29 三条支气管镜操作组合测试，冻结 `not_applicable/performed_event_absent`。
