# 检查检验模型失败隔离修复验收

## 已确认的问题与修复

基线为 `03602d777` 回退后的生产代码。主协调以两事件合成输入复现：011 跨事件错引持续出现时，两次调用后被写成 `data_gap / required_field_missing`，而非法枚举测试不能复现这条路径。原因是首答使用隔离解析器，整批恢复却使用允许 unknown 降级的公开解析器。

本次让首答和唯一一次恢复使用相同的严格隔离合同。可归属的引用错误只使相关规则失败，其他有效规则保留；资料齐全时的模型 unknown 进入恢复。恢复仍无效产生内部执行失败，不能用资料不足替代。原资料缺字段、报告时间缺失和住院截止时间缺失合同保持不变。

模型统计沿已有 FamilyUsageAttribution 和任务元数据传递。统计单位是本病例请求检查检验模型的规则，不是全部 72 条规则，也不是语义准确率。首答成功率、恢复成功率、最终模型失败率分别用独立计数计算；零分母为 null。首次调用异常而未恢复时也计入最终失败。
