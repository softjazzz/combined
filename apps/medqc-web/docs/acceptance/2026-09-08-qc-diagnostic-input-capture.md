## 范围与证据

原模型录制没有材料输入。安全 snapshot 的 facts 仅为摘要；材料仓的 source() 拒绝截断来源，而 bounded_rows() 不包含原读取上限。不能据这些接口拼造完整资料。

本批只接通授权单病例作用域中的 EvidenceReadSession 取材，不启用客户任务采集、不重跑病例、不改临床判定。

- execution.py 在既有 session 读取之后增加 7 行接线（1085 → 1092 行），不重新读取数据库。
- evidence_material.py 新增内部只读来源映射，包含 SnapshotSourceRows 的截断标记和 limit_rows；它不是安全 DTO 或对外接口。
- 独立 execution_inputs.py 承担完整的当次资料冻结/合同校验职责（44 行），没有移动或拆分引擎职责。先按严格类型冻结，再复用材料仓 create 校验既有来源摘要，不复制摘要算法。
- 使用 FactV2.to_dict() 捕获完整原事实，保留 snapshot 原引用和评价参数。评价上下文不属于临床 document_refs，不能擅自合并两者。
- 与模型尝试共享已有内存字节配额、单病例观察 context、过期与释放机制。重复资料采集拒绝覆盖；失败只标记诊断缺项。

## 验证

新测试先因 capture_execution_inputs 缺失而失败，再验证：

1. 关闭诊断不访问传入 session；原件不增加对外接口。
2. 保留 null、空字符串、重复行、原顺序、截断标记、读取上限、完整事实、评价日期及失败来源状态；不采集原始查询异常。
3. 修改内容、错误来源键、自定义对象无法冒充原快照；类型校验发生在既有 default=str 摘要计算之前。
4. 资料与模型共用限额，重复采集不覆盖，病例 context 变化拒绝串包，过期/关闭清空留存。
5. 正式 prepare 接缝在关闭、开启及配额失败时，每轮只有一次已有资料读取，传给引擎的是同一个 snapshot，返回结果一致。此项引擎使用替身，是接线/失败语义验证，不是临床正确性证明。
