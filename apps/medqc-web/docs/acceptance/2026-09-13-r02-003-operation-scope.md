# LX0609-003 诊疗操作适用范围复核验收

## 问题证据与根因

LX0609-003 核对每台已实施手术的手术记录是否在术后 24 小时内完成。正式目录要求手术时间和记录时间无法取得时返回数据不足；没有已实施传统手术时允许返回不适用。

0910 样本 C29 只有三条支气管镜诊断性操作。修复前目录缺少其中两个精确编码，统一手术适用性解析器回退到源表“二级”字段，把诊断性操作误认成传统手术，因此 003 旧快照为 `data_gap`。LX0609-031 的目录修复已补入 `33.2200X003` 和 `33.2403`，无需为 003 增加第二套分类逻辑。

C30 只有 `43.4105 内镜下胃息肉切除术`，现有权威目录已将其列为治疗性操作；旧结果和当前结果均为不适用。

## 实施与保护集合

- 本次不修改 003 执行器。正式路径继续使用 `resolve_surgery_applicability`，其目录分类优先于源表手术级别。
- C29 的旧数据不足结论已被权威目录推翻，不作为保护项；更正为 `not_applicable/performed_event_absent`。
- C30 为保护项，状态、原因码、客户展示事实和证据均保持 `not_applicable/performed_event_absent`。
- 源资料核对确认 C29、C30 的 `surgery_record` 均为空，`mr_surgery` 来源完整；当前目录能将全部记录识别为非传统手术操作。
