## 1. 术式关联：受限规范化（提交 `695000c2a`）

- 只改关联比较值，原始引文及其原文校验不变。
- 规范化只做两件事，且都由原文证明：去掉引文开头的标签冒号；引文末尾若是下一个固定模板标签（如“拟施麻醉方式”）的开头部分，且原文中紧接其后的正是该标签其余部分，才去掉这段残留。
- 引文在原文中出现不唯一，或末尾不构成标签残留时，原样返回；不做任意删字，也不改“单台手术遇术式冲突不兜底”的既有规则。
- 保护用例：侧别不同（右/左侧疝修补）、部位不同（T11/T12）、术式范围不同（楔形切除/肺叶切除，即 C04）、同名两台手术，规范化后均仍为无法归属；原文后面不是标签时不删字。

回放结果：C02、C09、C10 两份小结都关联到实施手术，待确认项消失，确认缺少仍为“术前诊断、术者术前查看”。C04 的核心小结仍无法归属（计划与实施术式范围不同），符合预期。

## 2. 共享抽取失败隔离（本轮第二个提交）

按影响范围区分校验错误：

| 错误                               | 范围          | 处理                                              |
| ---------------------------------- | ------------- | ------------------------------------------------- |
| `documents` 不是数组、条目不是对象 | 整体结构      | 整份响应拒绝，两条规则资料不足（原因码不变）      |
| 文书不在本病例输入中、同一文书重复 | 病例/文书身份 | 整份响应拒绝                                      |
| 某份文书字段集合不符               | 文书级        | 仅该文书所属规则失败（`failure_scope=document`）  |
| 规则所需文书缺失                   | 文书级        | 仅该规则失败                                      |
| 字段值或引文未通过原文校验         | 字段级        | 仅该规则失败（`failure_scope=field`，列出字段名） |

- 失败规则返回资料不足（`required_field_missing`，客户原因“自动抽取未通过原文核验”），新增事实类型 `preop_fact_extraction_invalid`，只含失败范围和字段名，不含引文、不含文书明细；保存合同只接受资料不足状态，夹带引文等额外字段即拒绝。
- 不把失败字段改写为 unknown，失败规则不会被判合规或不合规。
- 本模块的抽取不含事件归属字段；事件关联在通过校验的事实上由 Python 确定。
- 公开证据只引用文书本身，不使用模型引文；无效引文不进入任何公开事实。

回放结果：

| 病例 | 04-01-04                                         | 04-01-05                                           | 调用次数 |
| ---- | ------------------------------------------------ | -------------------------------------------------- | -------- |
| C02  | 不合规（缺术前诊断、术者查看；两份均已关联）     | 不合规（缺具体讨论意见）                           | 1        |
| C09  | 不合规（同上）                                   | 合规                                               | 1        |
| C10  | 不合规（同上）                                   | 合规                                               | 1        |
| C04  | **不合规**（同上；核心小结因范围不同列为待确认） | **资料不足**：讨论记录“术前准备”引文未通过原文核验 | 1        |

与冻结预期对照：8 个结果中 7 个一致；C04 的 04-01-05 预期为不合规，现为资料不足——这是如实表达抽取失败，不是判对，按失败计。
