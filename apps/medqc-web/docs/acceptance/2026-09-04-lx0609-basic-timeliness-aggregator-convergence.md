# LX0609 基础时限规则族聚合器职责收口验收

## 范围

- 规则族：`basic_timeliness`；
- 规则：`LX0609-001/002/004/005/006`；
- 执行器：`basic_timeliness`；
- 本阶段只迁移既有客户安全事实校验、客户证据投影和客户文案组织职责；
- 未修改规则适用性、状态、原因码、Prompt、Canonical 合同、API、保存或前端。

## 职责变化

迁移前，结果聚合器直接按规则号承担以下职责：

1. 基础时限展示事实结构校验；
2. 时间差、超时值和权威时间冲突复算；
3. `004` 抢救事件逐次结构校验及内部文书 ID 剔除；
4. `004` 抢救记录和抢救医嘱的客户证据生成；
5. `005/006` 查房文书客户证据来源选择；
6. Reduced Decision 反查证据时的规则专属来源过滤；
7. 基础时限超时文案生成。

迁移后：

- `basic_timeliness_customer_projection.py` 统一负责该规则族的客户安全事实校验和证据投影；
- `customer_renderer.py` 负责原有超时文案组织；
- 聚合器只通过稳定函数调用完成装配，不再包含该规则族的规则号字面量或专属业务分支；
- 执行器仍只产生 `RuleDecision`、受控事实和 `fact_refs`，未复制客户证据 DTO 拼装逻辑。

## 行为等价证据

冻结用例覆盖五条规则的：

- 目录顺序；
- `status` 与 `reason_code`；
- 客户结论；
- `customer_display_facts`；
- 客户证据的来源类型、文书 ID、字段路径和记录时间；
- LLM 调用数和 Token 均为零。

本阶段回归结果：

- 基础时限架构冻结：2/2 通过；
- 基础时限执行器：116/116 通过；
- 结果聚合器：376/376 通过；
- 客户 Renderer：375/375 通过；
- 合计：869/869 通过，耗时 4.10 秒。

另外增加架构守卫，禁止五条规则的规则号字面量重新进入结果聚合器。

## 尚未迁移及剩余风险

- 其余 65 条规则相关的事实校验、状态解释和证据投影仍有部分留在聚合器；
- `005` 在“日常查房与最高级别查房同时存在”的特定历史结果形状中，存在既有证据来源标签可能不准确的问题。本次为行为等价迁移，未顺带改变口径，应另立最小修复任务；
- 会诊规则族的模型结构非法结果目前仍可能映射为 `uncertain`，与批准的技术失败语义红线不一致，未混入本阶段；
- 三种业务入口实际执行路径一致性及两条扩展合同验证属于第三阶段验收内容。
