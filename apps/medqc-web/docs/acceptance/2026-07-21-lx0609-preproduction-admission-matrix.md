## 进入“可接入”前的共同门槛

1. 对该规则有 accepted Golden，覆盖其实际输出方向及边界；语义规则还需真实模型稳定性和预算证据。
2. 真实抽样人工复核的 `non_compliant`、`data_gap/not_applicable` 原因符合口径；
   不以合成病例替代真实准确率结论。
3. 统一旁路正式入口保证所选客户规则 exactly-once、旧映射不派发、客户 DTO 无正文、坐标、提示词或原始模型输出。
4. 同输入稳定性、P95、LLM 调用/token 和开关关闭回滚均通过；任何来源 `unavailable/error` 不得产生确定缺陷。
