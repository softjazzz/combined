## 责任边界

执行器在原选择点保留实际 row/source_key，不用文书 ID 或时间二次反查。材料仓复用原 document_refs 算法，并验证引用、来源及快照。Binding 只接受规则声明允许来源；公共 evidence enrichment 模块解析坐标，既有 enrich 方法补字段、时间及文书摘要。聚合器只调用通用投影，未新增规则号分支。

新增引用仍是已有材料仓的 document_refs，没有新增摘要类型、DTO、Resolver、Bundle、状态机或注册中心。旧 source/fact refs 仍可使用原 Binding 调用；仅逐文书引用要求提供现有材料仓。主 prepare 入口增加这一透传参数，数据库、API、Canonical 和前端合同不变。

## 安全边界

- 缺 ID、同来源同 ID 多行：不给出可疑定位，不借用其他行。
- 多条选中引用不能全部形成唯一坐标：不以部分坐标冒充完整选择。
- 无材料、跨规则来源、跨快照、篡改材料、伪造引用、截断材料：不放宽引用校验。
- 引用失败保持 technical_error / snapshot_mismatch，不转为资料不足或不适用。
- 主审核发现并补正：执行器引用绑定失败时还会追加正向客户事实；现在不再产生这些事实，避免技术失败展示“已确认”。四条规则均有注入异常测试。
- 正常旧 source ref 不扫描逐文书材料，已有兼容路径未删除。
