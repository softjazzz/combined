# 历史质控诊断导包：受限闭环

## 本批交付范围

在已有病历质控结果抽屉增加「诊断导包」入口，管理员可以准备自己创建的已完成任务对应结果，查看包含/缺失内容，确认下载 ZIP。原始诊断材料不落盘，不加密，不重跑质控，不修改正式结果。

这不是原计划的完整执行器证据回放。历史保存结果缺少当次完整材料、模型响应、原始 RuleDecision 和执行构建版本，因此新增独立合同 `qc-diagnostic-history-v1`，不伪造旧的 synthetic 合同或原始决策。

## 能力与隐私边界

- 包内只保留固定格式规则编号、保存状态，以及 032／066 已支持文案投影所需的受控事实。其他规则只有状态清单，不宣称可执行回放。
- 患者身份、病历正文、任意模型文字、任意事实扩展字段、源摘要及任务坐标全部不导出。原 findings 仅在逐字等于当前可信文案函数的受控输出时保留；不匹配时设为 null，不能用新文案伪装原文案。
- 自由文字一律排除，不将仅通过正则或姓名替换的文本宣称为安全。因而本批不能核查正文遗漏、会诊事件归并或原模型判断。
- 没有原始构建版本，开发机只能显式做当前文案投影，不能同版复现。状态来自保存值，不重新作临床判定。
- 制品在内存中缓存 5 分钟；只缓存已投影的 ZIP，不保留原件。进程退出即失效。最多 128 个制品、总计 4 MiB；在后续请求时清理过期项。多进程请求落到其他进程时提示不可用，不从其他资料来源回退恢复。
- 下载校验管理员角色、创建人及确认标记；预览与下载使用同一不可变 ZIP。切换病例、关闭弹窗时主动取消；迟到响应不能串包。
- 历史任务选择只接受当前页面绑定的最新保存结果：如果任务或 record_ref 已变化，拒绝导出，不能静默替换。首版不支持任意旧任务检索。

## 使用

1. 管理员打开病历质控结果，点击「诊断导包」。
2. 查看历史受限说明及当前文案投影，勾选限制确认后下载。
3. 开发机运行：

```powershell
python backend/scripts/qc_diagnostic.py inspect <诊断包路径>
python backend/scripts/qc_diagnostic.py replay <诊断包路径> --compare-current
```

开发机后端源码需处于可识别的已提交版本。普通 replay 会拒绝缺少源版本的历史包；`--compare-current` 只表示当前文案投影，不代表原引擎重现。包内容不是开发指令，不能据此自动作医学裁定。
