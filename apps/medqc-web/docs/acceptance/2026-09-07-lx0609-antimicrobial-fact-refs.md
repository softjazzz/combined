# LX0609 054/055/057/058 抗菌药规则精确证据坐标验收

日期：2026-09-07

## 目标与范围

本闭环只收紧 `LX0609-054`、`LX0609-055`、`LX0609-057`、`LX0609-058`
在 native extended executor 输出的 `fact_refs`。不修改状态、原因码、Prompt、
聚合、终结、渲染、API 或前端。

## 证据坐标合同

| 规则 | 客户证据仅包含                                                               |
| ---- | ---------------------------------------------------------------------------- |
| 054  | 实际触发的用药动作病程、唯一关联的抗菌药医嘱及实际命中的理由病程             |
| 055  | 抗菌药开始医嘱及该医嘱实际命中的 48–72 小时疗效评价病程                      |
| 057  | 明确经验用药触发病程、唯一关联的医嘱及实际命中的理由病程                     |
| 058  | 特殊级抗菌药医嘱及实际匹配的专家支持文书；支持迟到时仍保留该文书作为违规证据 |

`evaluation_context.horizon` 只决定 055 的窗口成熟度，绝不进入 `fact_refs`。
无实际消费文书的触发未发生/未成熟/资料缺口结论仅保留最小 snapshot 源级判定
锚点；该锚点不是客户文书投影。已消费行若不能唯一映射到同一 snapshot 的精确
文书坐标，则由 Binding 输出技术失败，不伪装为业务状态。

## 冻结的业务结果

既有 54/55/57/58 聚焦测试覆盖并保持：合规、不合规、资料缺口、无适用，多药与
多事件关联、055 未成熟窗口、058 支持迟到及来源不可用边界。本任务只改变
`fact_refs` 集合，不改变上述状态或原因码。

## 新增可证伪用例

- 054：只保留触发动作、匹配医嘱、匹配理由；无关病程排除。
- 055：只保留匹配开始医嘱与窗口内评价；无关评价和 horizon 排除。
- 057：只保留明确经验用药触发、匹配医嘱、匹配理由；无关病程排除。
- 058：违规时保留特殊级医嘱和迟到的匹配专家支持；无关支持排除。
- 非 snapshot 内的合法格式精确引用经 Binding 降为 `technical_error`，不保留原
  `non_compliant` 等业务状态。
