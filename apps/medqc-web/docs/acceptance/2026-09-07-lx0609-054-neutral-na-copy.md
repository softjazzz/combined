# LX0609-054 不适用文案修复验收

## 目标

054 已按“存在具体使用或调整动作才适用”的口径执行。普通抗菌药医嘱但未发现可核验动作时，结果为 `not_applicable / trigger_absent_complete`；客户文案不得错误表述为“未发现抗菌药物医嘱”。

## 变更边界

- 仅调整 `customer_renderer.py` 中 054 的不适用声明式文案。
- 不修改规则状态、原因码、执行器、事实、证据、聚合器、Finalizer、API 或前端。

## 回归

py -3.10 -m pytest backend/tests/unit/test_luxian_0609_customer_renderer.py -k "054 and neutral" -q
py -3.10 -m pytest backend/tests/unit/test_luxian_0609_customer_renderer.py -k "054 or antimicrobial" -q

验收点：有抗菌药医嘱但无已确认使用或调整动作时，结果仍为不适用，标题为“本次未发现需要核对理由的抗菌药物使用或调整动作”。
