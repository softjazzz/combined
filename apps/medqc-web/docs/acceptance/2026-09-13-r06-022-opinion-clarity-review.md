# LX0609-022 会诊意见明确性复核

## 口径与判断方法

LX0609-022 判断每次会诊意见是否针对当前病情给出明确诊断、处理、治疗、检查或随访意见。仅有“必要时检查/治疗”“酌情处理”“协助诊治”等没有对象、条件或方案的泛化表述，不能作为明确意见；同一病例存在多次会诊时，应逐次判断，任一次意见模糊即不能把整份病例标为合规。

申请时间、会诊时间、科别和签名等完整性事实可用于文书核查和定位，但 022 当前客户质控点是“会诊意见不明确”，不得用这些结构化字段缺失遮蔽已经能够完成的意见明确性判断。

## 两例复核结论

- C20：神经内科意见给出癫痫诊断、抗癫痫药物治疗和专科随访，诊疗对象与处理方向均明确，维持 `compliant/requirement_satisfied`。
- C23：第一次呼吸内科会诊给出诊断、检查、抗感染方案和复查安排，意见明确；第二次心内科会诊仅重复“暂无特殊处理/无特殊处理”，没有诊断结论、具体处理方案或随访条件，该次意见为 `vague`。病例整体维持 `non_compliant/requirement_violated`。

两例均直接回看本地 0910 客户 CDM 原表，并与正式 Bundle/Evidence 链路返回的客户展示事实和文书定位交叉验证。C23 的客户事实明确保留两个 episode，分别为 `clear` 和 `vague`，没有因一份明确意见覆盖另一份模糊意见。
