# V3.6 第54项核心制度专题报表

## 实现合同

- 入口：现有病历质量分析页面的“18项核心制度”标签，无新页面。制度目录唯一来源仍为 `medical_core_system_catalog`；显式归属唯一来源仍为 `resolve_rule_set_version` 的冻结版本条目。
- 范围复用病历质量报表当前病历池：运行为当前在院，终末为已出院但归档未核验。完成日期过滤最新可展示 ready Canonical 结果；不回溯某日期的历史最新结果，不声称全院历史病例覆盖。
- 每制度分母：窗口内实际返回至少一个、且冻结版本明确归属该制度的质控点的三坐标去重病例。分子：同集合至少一个 `is_confirmed_issue=True` 的病例。不重复判医学状态。标签及CSV均注明“已配置质控点范围的问题率”，不称全院制度合规率。
- 同病例多点只计一例；同规则不同冻结版本分开显示质控点。`core_system_ids=null` / 缺字段 / 版本缺失为未知；`[]`为明确非核心。无归属返回点的制度，病例数、问题数、率均为null，界面显示无配置数据；有归属点但无确认问题才是0。
- 分类读取故障或来源坏回执503，不回退当前版本、不伪造零。版本不存在仅归属未知。结果不可用或缺可信完成时间只列当前候选未知覆盖，不能按完成日期归属，不进制度分母；空返回点同样不能证明制度覆盖。
- 候选全集取自既有完整批读，5000例上限在分页前；原文18项与制度汇总、冻结点详情、病例明细下钻及分页复用同一集合。不同冻结版本至多解析一次，无逐病例回退查询。
- 持久账号、失活状态与角色为授权事实：仅admin/qc_manager；非admin限持久机构，三坐标在结果批读之前裁剪。科室筛选须配机构，防同名跨院混淆。
- 通用范围筛选：运行/终末、机构、科室、主治医师、完成时间起止；明细下钻筛选：制度、质控点、仅问题病例，不改变范围内18制度汇总。界面分别标明汇总范围及明细筛选。CSV使用应用后的同一筛选，导出完整筛选集合而非当前页，包含18制度范围汇总、未知计数、筛选后的完整病例三坐标、冻结运行/结果/规则集版本；防公式、no-store、脱敏导出审计。
- 参考全文保存国家卫生健康委员会2018-04-18《医疗质量安全核心制度要点》的18制度定义与基本要求，来源为官方公开文书（资源可离线读取）。页面显示“2018版参考原文，不代表最新院方政策”，全文不只提供外链。
