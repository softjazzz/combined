# 现代缺陷催办撤回与单缺陷处理入口

本批补齐整改 owner 的撤回催办及既有缺陷列表入口，不提高 PRD 23 整项覆盖状态。

- 撤回必须引用同一整改的有效催办事件，当前整改须为待整改或驳回；医生提交已回应此前催办，后续驳回不复活旧提醒。
- 持久有效账号与院科授权、当前版本 CAS、撤回引用唯一约束及同事务历史共同保护重复请求与跨轮串账。催办和撤回不修改整改状态，也不改缺陷、申诉、任务或病历审核。
- 缺陷列表通过既有病例抽屉下钻。处理范围完整匹配机构、患者、就诊、场景、缺陷类型与标识、job、Envelope；自动缺陷列表传递冻结 job/Envelope，最新结果换轮时拒绝把旧缺陷挂到新结果。人工缺陷身份沿用唯一 defect_id 及派发候选 owner。
- 同一处理区保留派发入口与已派发任务，任务可查看全部状态、提交、验收通过、驳回、催办及逐条撤回；病例时间线保留撤回与原提醒引用。
