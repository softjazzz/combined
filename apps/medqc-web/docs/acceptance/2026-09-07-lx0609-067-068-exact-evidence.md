# LX0609-067/068 精确病程证据绑定验收

## 目标

在出院文书族结构迁移前，移除 `customer_display_facts` 中仅供旧聚合器使用的
`source_document_refs`。067/068 的执行器只将已经参与判定的 `(source_key,
document_id)` 映射为同一 Evidence Snapshot 的 `fact_refs`；公共证据投影据此生成
客户证据。

## 绑定边界

- 只复用 `Luxian0609EvidenceMaterialStore.document_rows()`；不新建 Resolver，
  不按日期、标题或正文再次选择文书。
- 每一个已选 `(source_key, document_id)` 必须在该来源的材料行中**恰好命中一行**。
  无 ID、无匹配或重复 ID 都 fail-closed：不生成逐文书事实引用，也不展示客户证据；
  仅保留本次实际消费来源的 snapshot ref，以满足 Binding 的证据消费合同。
- 证据坐标不可得不会改变既有业务 `status` 或 `reason_code`，也不会把正常资料
  缺口伪装为 `technical_error`。
- `customer_display_facts` 不保留私有文书 ID；客户证据的唯一所有者为公共
  `fact_refs → Binding → projector` 链路。
