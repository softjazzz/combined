# 医嘱号显示与同名医嘱区分

用户核对C20三条血常规后，要求在表格中显示来源医嘱序号以示区别。

## 实现

- 医嘱项目后增加“医嘱号”列，显示完整来源`order_id`，支持悬停查看完整值。
- 文书列表、摘要、详情及前端归一化独立传递该字段；只读查看、质控原文对照和编辑副本使用同一来源值。
- 不用表格行号、排序位置或临时文书ID替代来源医嘱号；源字段未知时显示“－”。
- 调整列宽及空状态跨列数，保留类型、状态、关键词筛选及原有排序。

## 真实C20核验

保存的领域Bundle中已有来源医嘱号，无需重同步或刷新Bundle。三条血常规的`order_id`分别为`2649133||68`、`2649133||91`、`2649133||112`，均经后端列表及详情装配、前端文书服务、只读表格组件验证显示完整；按检验类型和“血常规”筛选仍保留三条。

新增前端回归修复前失败，修复后通过。医嘱表格7项、文书服务29项、客户样本页面76项共112项前端相关回归，以及后端医嘱装配及EMR45项通过。另有真实三条医嘱回放，私有资料仅在`.tmp/0910-full-audit/1021-order-id-private/`保存，不提交。

本次不修改医嘱、同步来源、数据库结构或质控结果，不合并或删除同名医嘱，不调用模型。后端重新加载字段投影，前端开发服务自动更新；未打包部署客户机。
