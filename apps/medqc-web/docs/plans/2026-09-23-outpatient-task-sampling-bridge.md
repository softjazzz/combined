## 固定合同

1. `outpatient` 候选从完整来源查询；源查询失败 503，不以合法空池掩盖。日期非法/倒置、三坐标残缺、显式 `record_refs` 不存在或不属筛选范围为 422。多文书同病例只取一个候选，同 `visit_id` 不同机构/患者不合并。不得静默 10000 条截断。
2. 抽样仍支持 all/count/percentage，但每一步搬运完整三坐标。持久化事务锁任务，核对 `record_refs` 快照，现代关联按三坐标去重并原子写入；重放从已保存行返回稳定身份。只有门急诊在本批接通；`running/final` 保持 409。
3. 新关联的旧 `record_id` 只能是非临床的兼容占位值，不能用于旧查询或质控执行。旧任务和全 NULL 三坐标行保持既有合同。现代任务的演示 `re-analyze` 返回 409，不报告真实启动，直到 workspace job/规则集/结果关联完整落地。
4. 业务库无迁移授权时不执行真实写入。隔离数据和模拟 PostgreSQL SQL 只能证明实现合同，不能证明医院门急诊正样本、真实并发事务或执行闭环。
