# V3.6 评分标准 Excel 导入导出合同

## 1. 范围与权威所有者

本批补齐 PRD 6.1“规则导入/导出”在**新评分标准主链**上的能力：导入导出评分标准、等级档位、项目组和扣分条目。评分标准的字段校验、规则归属和落库仍由 `scoring_standard_service` 负责。

规则集版本只作为评分条目的受控引用：工作簿必须携带导出时的 `rule_set_key` 与 `rule_set_version`，导入时必须与当前适用版本一致，且每个 `rule_id` 必须属于该版本全集。本批不通过 Excel 新增规则 ID、修改规则状态、修改执行条件或导入执行器；规则集版本生命周期仍归 `rule_set_version_service`，质控执行器不在本批范围。

因此，本批完成的是评分规则配置的 Excel 主链。是否还要求规则集版本的 active/paused/offline 状态独立导入导出，需产品另行确认，不能仅凭本批自动把 PRD #62 宣称为整项完整。

## 2. 工作簿合同

仅接受 `.xlsx`，固定包含以下三个工作表，名称、表头和字段均严格校验，未知工作表或未知列拒绝：

1. `评分标准`：单行，包含 `模板版本`、`场景`、`规则集键`、`规则集版本`、`标准名称`、`满分`、`单否档位`。
2. `等级档位`：包含 `档位名称`、`最低分`、`最高分`；沿用现有连续、无重叠、全覆盖和档位数不固定的合同。
3. `评分条目`：包含 `项目组`、`组封顶分`、`组排序`、`规则ID`、`单项扣分`、`一票否决`、`启用`。同组的封顶分和排序必须一致。

导出文件携带当前适用规则集版本，文件名不含患者数据。公式、宏、外部链接和非标工作表均拒绝；单元格仅接收文字、数字、布尔值或空值。

## 3. 导入语义与事务

- 写权限限定 `admin`、`qc_manager`；导出保持登录可读，与评分标准详情权限一致。
- 导入始终创建新的 `draft`，不覆盖同名标准，不修改 `active`/`archived`，不自动启用、不自动设默认。
- 解析和整文件预检完成后才开启数据库事务。任一工作表或任一行失败时不写库，并返回逐条问题：`sheet`、`row`、`field`、`code`、`message`。
- 成功时，标准、项目组和条目在同一事务写入，详情 DTO 也在该事务内回读；回读失败则整笔回滚。
- 规则集版本在解析后、写入前再次读取并比对。模板版本落后或超前均以 `rule_set_version_mismatch` 拒绝，要求重新导出，避免把过期规则归属静默写入新草稿。
- 同名冲突为 409；合同/行校验为 422；上传后的网络结果未知不得显示“未写入”，前端提示用户刷新列表按标准名核对后再决定是否重试。

## 4. 资源与安全边界

- 文件上限 2 MiB，压缩包条目上限 32，解压后总大小上限 8 MiB，单个 XML 条目上限 4 MiB。
- 工作表最大行数沿用领域上限：1 条标准、20 个档位、200 个项目组、1000 个评分条目。
- ZIP 路径穿越、加密文件、宏、公式、外部链接、隐藏的额外数据表均失败关闭。
- 错误日志不记录工作簿原文；接口错误沿用评分服务脱敏 503。

## 5. 接口与前端

- `GET /api/v1/scoring/standards/{standard_id}/export`：导出该标准的 `.xlsx`。
- `POST /api/v1/scoring/standards/import`：multipart 上传，成功返回新草稿详情；失败返回逐行问题。
- 评分标准页工具栏提供“导入标准”；每行提供“导出”。导入失败抽屉展示工作表、行号、字段和原因；未知结果单独提示，不伪装为确定失败。

## 6. 验收

- 导出后原样导入能创建内容等价的新草稿（名称需改为未占用名称）。
- 规则集版本不一致、规则 ID 越界、重复规则、组定义冲突、档位断档、公式、外链、超限和未知列均不写入，并返回可定位问题。
- 写入中或事务内回读失败时，标准及子表均回滚。
- 普通登录用户可导出但不能导入；未登录不可访问。
- 既有 `active`/`archived` 标准、默认标准、历史质控结果与规则集版本均不改变。
