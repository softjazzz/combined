# 06-01-04 重复检查定位与局部补核

## 问题与改动

真实材料先导中，重复 CT 的后次病程被误挂到前次事件。引文校验成功拦截，但原批次重发以及候选升级原样重发都没有恢复；一个事件的失败还拖累了其他已核对事件。

- 解析器分别报告引文缺失、过长、不属于当前报告，不裁剪引文来通过校验。
- 引句明确包含其他报告独有结果且没有本报告独有结果时，要求重新定位，不自动改判为缺失。仍使用全部报告比较，不因失败范围缩小而制造独有句。
- 保留逐配对通过的结果，只补核失败/遗漏配对。成功配对、事件与文书引用不重排。重复编号不能保留第一个答案冒充成功。
- 同模型补核和候选升级都只携带客观错误位置、字段和原因，不携带候选结论或上次应答作为事实。
- 一个事件只有候选全部覆盖且输入完整，才能固定否定；已绑定正面引文仍可证明存在。不完整标记保留且阻止整族冻结。
- 每批两次尝试、专项八次逻辑调用和外部 HTTP 上限不变。取消继续传播，技术错误不变成临床缺失。
- 冻结验证版本升级到 `exam-record-pair-recovery-v3`；旧冻结不删除，新逻辑不复用旧键。

## 定向证据

固定合成保护覆盖合法报告片段掩盖另一事件引句、成功配对保留、仅失败范围重试、重复编号、错误分类和 Gateway 候选升级。加入 `dual-model-exam` 隔离 CI 入口。

本地私有 C01 原应答离线重放：两条路径仍拒绝旧错误答案，但不完整范围缩为 E002；E001/E003的已验证证据保留。显式修正的固定补核应答可恢复完整，不能据此声称真实模型会自行纠错。

既有九事件的十组 Native→Binding→Finalizer→Aggregator→Canonical 内存 SQLite 保存读取回放，以及两组 C01 显式修正应答的完整保存/热冻结回放，分别保留真实旧答与合成修正来源。主抽取是明确标注的固定夹具，不是新跑整份病历。

公开定向保护集241通过、2项需要显式私有录制文件而跳过；另有私有6项通过（其中2项循环验证上述12组正式链）。公开集合使用严格 `offline` 调度测试入口，包含 `dual-model-exam`、既有结果记录核验和前缀适配保护；私有材料不提交。相关Ruff、staged编码及只读ESLint检查通过。未运行全量前端类型/单测或全后端回归，因为本次没有前端修改。

## 边界

没有新增模型调用、业务数据库连接/写入、历史结果覆盖、服务重启、集成分支修改或部署。未扩大真实样本范围。真实补核能否改善模型判断尚需另行授权验证；未启用35B替换。
