- 浅色光晕底（`--mq-bg-mesh`）+ 半透明白色玻璃卡；只有一种品牌蓝 `#0A6CFF`，**不用紫色**；红/橙/绿只表示数据状态。

## 4. 交互上的变化（需要让用户/测试知道）

1. **病历池**：点击一行只切换右侧预览；「查看病历」进入原全屏详情，「质控此病历」走原质控流程。阶段队列（生成首页/首页质控/结算清单质控）保持原来的点击进详情。
2. **自定义质控点**：批量执行视图下四个步骤改为分段切换、一次只显示一步（原来六块平铺）；规则设计视图不变。
3. **系统配置**：页签改为页头右侧分段控件；「执行前确认」由系统弹框改为页面内弹窗，并新增病历类型/范围/日期摘要（数据均为页面已有）。
4. **质控结果筛选**：选中项由「纯蓝底白字」改为白色浮起（按设计规范）。

## 5. 验证情况

- 全量前端单测 1124 项中 1121 通过；3 项失败均为本机美国中部时区导致（`QCOverviewView` 时间断言、`date-utils` 两项），改版前即失败，**用户要求不处理**。之后新增/修改页面的相关单测全部通过。
- lint、`vue-tsc` 类型检查、编码检查通过（类型检查偶发内存不足崩溃，加 `NODE_OPTIONS=--max-old-space-size=8192` 可跑通）。
- 每页在 1440 / 1180 宽度截图核对；病历池预览切换、进入详情、自定义质控点步骤切换在浏览器中实际点击验证。

## 6. 未验证 / 限制（接手时请优先补）

1. **真实质控结果**：本地 `latest-result` 均返回「交付合同不完整」。结果卡片是用 Playwright 拦截接口注入样例数据核对的，需在有真实结果的环境复看（长证据、多问题病历）。
2. **需实施账号的区域**：系统配置「模型性能」页签、数据同步高级设置——演示账号看不到，未截图。
3. **无数据状态**：统计分析图表、数据同步「检查通过/告警」状态、规则批量结果抽屉，仅单测兜底。
