# 2026-10-03 业务助手 M2 参考修改草稿（D04）

## 结论

医生视图对已查看的“不合规”保存问题可生成参考补充草稿：模型只起草，Python 校验来源；草稿卡标明不替代正式保存建议、复制不等于整改完成、不写入 EMR。真实 3 轮问答迭代后，末轮 2 次工具、3 次模型、12.2 秒完成，草稿只针对缺项且事实均有来源。

## 职责边界

- 事实来源只有两类：序号 0 为正式保存结论原文，1 起为前 5 条保存证据摘录（每条截断 300 字）。不读取当前文书全文。
- `business_drafts.validate_segments`：fact 段必须引用来源，文中数值（时间、剂量、次数）必须出现在所引来源；placeholder 段只可出现正式建议或来源已有的数值（如“24小时”时限），否则 422。限制 1–6 段。
- 仅医生视图、仅 `non_compliant`；资料不足等状态拒绝起草。未查看问题 404，版本变化 409；回读按同一分段重新校验。
- 卡片附正式建议原文；前端“生成参考补充文字”仅在医生视图的不合规问题上出现，“复制参考草稿”后提示复制不等于整改完成。

## 运行时改进（通用）

- 工具 4xx 时把后端自身的简短中文原因（≤200字）交给模型改写；5xx 不透传。
- 用户选中来源时，工具参数可写 `@selected`，由运行时替换为本轮所选来源；未选择时原样交后端拒绝。用于避免模型抄写长标识出错。
