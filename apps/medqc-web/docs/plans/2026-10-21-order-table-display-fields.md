# 医嘱表格字段空白修复

## 真实缺陷

用户反馈客户样本验证“查看病历”的医嘱表格只显示时间、类型、项目及状态，规格、剂量、频次、用法、数量及下达医生大面积为空。

前端`manual-case-sample-service.ts`在文书列表及详情响应归一化时漏接上述六项；后端Bundle文书已包含相关展示字段。不是所有空白都代表源库或同步缺失。

在同一真实C20的55条医嘱上，通过只读加载已保存的领域Bundle与正式文书装配函数核对：

| 展示字段 | 后端已有非空值条数 |
| -------- | -----------------: |
| 规格     |                  9 |
| 剂量     |                 13 |
| 频次     |                 24 |
| 用法     |                 13 |
| 数量     |                 41 |
| 下达医生 |                 55 |

未提供的值继续留空，护理、治疗等非药品医嘱不虚构剂量或用法；计划结束不当作已核实的实际停止时间。

## 改动

- 列表与按需详情共用六项展示字段读取，保留已有类型边界及缺字段回退。
- 真实回放同时发现详情再次渲染会把已组合的剂量、数量重复加单位。后端优先保留已规范化展示值，只有原始数值才追加单位。
- 不改同步数据源、表结构、质控判断或历史结果，不刷新Bundle，不发起模型调用。

- 真实55条医嘱经过正式后端列表、详情装配，再回放前端服务归一化与表格行构建，六项展示值全部保留一致。回放材料仅置于`.tmp/0910-full-audit/1021-order-display-private/`，不提交。
