# PR14复审：死亡记录与阶段小结冻结边界修复

## 范围与根因

固定修复前版本为`8ac8c8638`，PR仍为Draft，评审Base仍为`418e865d2`。仅处理主Agent确认的两项问题，不据此批准业务集成或部署。

- P1／09659：死亡记录原来从全部候选取最后完成版本，未来版本会改变当前结论。现在由执行器先按快照`created_at`排除已知未来的死亡及出院文书，再识别终末类型、收集死亡锚点、选择版本和核对24小时。边界相等保留，微秒不丢失，显式时区归医院时区；未知时刻不当作未来排除，日期精度不足不补零点。
- P2／09299：阶段小结原来先验证正文，未来空正文会把确定缺失变为资料不足。现在先排除已知超过评价上界的材料，再验证正文和版本冲突。范围覆盖阶段小结及交接班、转科替代；未知时间仍保留原资料不足语义，30天周期和日期区间合同不变。
- 两执行器交付实际消费的原始行，Native复用已有精确绑定器，不再按来源加文书ID把未来同ID版本重新绑入。绑定器、Finalizer、Renderer和保存层未新增临床判定。
- 公共证据投影仍拒绝同来源同ID的多版本歧义定位，此种情况允许不展示公共文书坐标；不能宣称加入同ID未来版本后公共证据展示完全相同。临床状态、原因和事实保持，未来正文不泄漏到所选证据。
