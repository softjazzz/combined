# 核心制度显式归属合同

固定名称取自国家卫生健康委员会2018年《医疗质量安全核心制度要点》：
https://www.nhc.gov.cn/yzygj/c100068/201804/42ab2552298047679cd6ec733f233862.shtml
解读及18项清单：https://www.nhc.gov.cn/zwgk/jdjd/201804/5dfb30387c74412194c7f05b878d4f87.shtml

`CORE-01`至`CORE-18`是按官方清单次序定义的项目内部ID，不是官方编码。
字典唯一owner为`medical_core_system_catalog`，API只读提供；不预填任何规则归属。

管理员在规则版本草稿显式配置`core_system_ids`。缺省/null表示未知，`[]`明确非核心，非空数组表示所选制度；只接受字典ID，不允许重复。
配置由既有版本发布owner写入`entries_json`并纳入摘要。旧entry不自动补字段，历史摘要不变；复制、启停和Excel V3保留字段，V1/V2保持缺省未知。

病例核心制度分区只消费结果DTO冻结的规则集键/版本，并与同病例同作业确认缺陷集合取交集。
未配置显示未知；部分分类展示已配置条目并提示未知项，不把未知计为0；分类来源故障独立失败，不回退到当前版本。
文书定位沿用确认缺陷的可信证据入口，身份和job一致校验保持不变。

本批只交付第28项核心制度分区配置与消费能力，不包含第54项制度全文、问题率及专题报表。院方实际规则归属和业务库部署未执行。
