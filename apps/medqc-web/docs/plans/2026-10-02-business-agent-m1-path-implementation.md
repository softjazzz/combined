## 设计与实现

选择复用正式读取与已有会话卡片，未另建知识目录、统计缓存或任务执行链。相比仅加快捷问句，该方案补齐无规则编号时的真实检索能力；相比重建页面及流程，改动限定在既有抽屉、业务工具和DSH模型投影。

- 新增 `search_rules`：用权威目录做大小写不敏感的关键词匹配，空格多词全部匹配，稳定按规则ID分页；最多每页10项。没有额外Embedding，不推断同义词；空白/超限拒绝，无命中明确为空，不扩为全目录。候选不绑定引用，选定后 `read_rule` 读取口径及可打开详情。
- `read_saved_issue` 透传保存任务、规则版本和结果时间，并说明历史正文未读取。`read_rule` 明确当前目录版本及历史正文不可用；不同版本标识体系不直接比较字符串推断规则变化。
- 当前目录的注册状态、发布阶段、发布范围、已发布/待发布子项及原因保留在模型输入和规则详情。空子项标为未单列，不能推断医学判据缺失，也不把注册状态当全部启用。
- 管理下钻记录病例引用首次真实查询来源，“返回同一汇总”只滚动和聚焦原轮次，不发送聊天或刷新统计。排除无工具追问混合回填的 `prior_turns`，缺原始历史时不猜汇总；上下文、会话或原轮次消失时清理定位。
- 保存问题有已读规则引用时直接打开；否则通过“查询这条规则”携正式规则编号和保存问题引用发起新问答，显式说明会查询。规则详情提示当前目录与历史依据的边界。

提醒、整改台账和反馈办理仍未接入。既有通知列表只按收件人过滤，未对助手病例范围建立映射；整改列表/详情只有登录鉴权，缺当前机构/科室的范围过滤，不能直接开放给助手。页面和模型指令明确不可用，不将未读取报告为零或已处理。PRD第11节允许消息未接通不阻断前两条路径，但不得宣称消息查询或全部M1完成。本轮没有新增M2复检、分派、催办或数据库写入。
