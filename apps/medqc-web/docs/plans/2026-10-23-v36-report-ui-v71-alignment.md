# V5 报表 V7.1 视觉对齐

## 问题与范围

用户指出新报表没有遵循 V7.1。核实后确认：gap-drilldown 分支此前缺少 `tokens-v2.css`、`mq-components.css`、`workstationTheme.ts` 和 MqIcon 组件；旧报表接进 V5 路由不等于完成 UI 迁移。上批业务联调通过不能作为设计规范验收。

本轮以 `D:/LLM/LX888/apps/medqc-web/docs/0418/UI/WorkstationV4-医疗浅色-DESIGN.md` 的 V7.1 为依据，定向复用该工作区的基础 Token、公共类、主题和图标及其测试。不整分支合并，不修改来源工作区，不引入引擎或其他业务功能。同步本分支的规范文档，避免后续继续依赖旧技能参数。平台要求字距保持 0，不复制负字距。

## 实施

- 全局注册命名隔离的 MQ Token 与公共类，保证旧链接直接进入复用报表时也能加载样式；Ant Design 主题仅通过工作台内的 ConfigProvider 生效，不修改旧 Dashboard 的全局主题。
- 工作台移除旧顶栏与面包屑，将既有版本状态和账号菜单放到侧栏底部，品牌与导航复用 MqIcon / MqIconTile。保留 gap 分支已有的菜单清单、权限、统计分组、三阶段启动与登录退出行为，不用另一分支的业务导航替代。
- 原顶栏通知弹层也迁至侧栏底部，保留原占位内容，不新增通知接口；其徽标数字不是本轮核实的持久业务数据，不作为站内通知完成证据。
- 桌面低于 1280px 自动折叠到 72px，仍可手动展开；小于 768px 保留本分支原有覆盖式侧栏与遮罩、选择后关闭，不让侧栏占据手机主内容宽度。
- 病历质量分析和首页报表组合公共页头、玻璃卡、胶囊按钮、输入框与表格。病历质量与核心制度一级切换移到页头分段，保留原测试标识；不可用分数使用较小文本，不强塞进大数字样式。
- 核心制度与整改两个内嵌面板的私有 CSS 移至独立文件，使用 Token、公用表格/按钮/输入框，当前页面内的抽屉保留自适应宽度和足够的根层级。
- 公共页面网格采用 `minmax(0, 1fr)` 并约束子项最小宽度，防止宽表把整页撑出窄窗口；表格仍可在自身区域横向滚动。
