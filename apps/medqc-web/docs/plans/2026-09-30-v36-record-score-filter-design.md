# V3.6 PRD21 病历列表评分筛选合同

## 1. 范围与原文边界

PRD21 原文为“查询：周期、评分标准、病历信息”，验收要求按手册查询条件检索完整运行病历和缺陷。本批补齐 V5 运行/终末病历列表的评分标准、计分状态、评分等级和分数区间筛选；周期及病历信息沿用现有日期、科室、主管医师和关键字筛选。

门急诊列表和缺陷视图不在本批范围。PRD21 是否整项完成仍由主线账本按门急诊与完整缺陷检索证据复核，本分支不更新进度账本。

## 2. 唯一事实来源

- 评分只消费 `scoring_service`。查询层不重判质控状态、不自行扣分、不拼装第二套等级规则。
- 不传 `standard_id` 时使用场景默认标准；显式选择时只允许当前场景 `active` 且规则集为 LX0609 的标准。
- 显式选择不修改默认标准配置。草稿、归档、跨场景、其他规则集和不存在的标准均返回 422。
- 工作站选项只返回 `id/name/version_seq/is_default/grades`，不复用或放宽评分标准管理接口权限。

## 3. 查询参数与语义

- `standard_id`：可选 UUID；运行和终末固定场景可用，混合场景拒绝。
- `score_status`：`scored`、`no_standard`、`unavailable`。
- `grade`：评分标准中的等级名称，精确匹配。
- `score_min`、`score_max`：闭区间；最小值大于最大值返回 422。
- 多个评分条件之间为 AND。`grade` 和分数区间只命中 `scored`；未配置标准不伪造 0 分或通过。
- `unavailable` 是单病例评分不可用的明确状态；没有 ready 质控结果的病例不冒充 `unavailable`。

## 4. 完整集合、分页与失败语义

评分筛选在日期、科室、医生、关键字、住院范围、统计下钻和审核状态筛选后的完整真实病例集合上执行，再分页。`total`、`totalPages` 和 `qc_summary` 均基于评分过滤后的集合。

同步评分候选超过 5000 例时返回 422，业务码 `range_too_large`，不得截断前 5000 例后伪装完整。显式评分筛选时，标准或结果批量读取失败返回脱敏 503；单病例因结果变化、范围上下文或计分异常产生的 `unavailable` 保留为可筛选事实。未带评分筛选时继续允许本页评分降级为未知，不阻断病历列表。

## 5. 前端与模板

运行/终末 V5 筛选区提供评分标准、计分状态、评分等级和分数区间控件。字段写入 URL，浏览器前进/后退可恢复；查询、重置、默认模板、另存模板和更新模板共用同一快照。

模板白名单新增 `standard_id/score_status/grade/score_min/score_max`，逐项校验 UUID、枚举、有限数值及区间顺序。未知或损坏模板保持“内容不可用”，不当作空筛选应用。

## 6. 权限与验收

接口继续使用现有工作站认证与数据范围，不增加公开入口，不赋予评分标准管理权限。自动化至少覆盖：完整集合先过滤再分页、`total/qc_summary` 一致、三种计分状态、等级与闭区间、整体读取失败 503、单病例 `unavailable`、5000 上限、草稿/归档/跨场景标准拒绝，以及 URL/模板往返。
