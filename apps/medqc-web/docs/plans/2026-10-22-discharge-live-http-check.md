# 1022六例出院取数字段的运行中HTTP核查

用户要求经运行中后端实际接口核对，不调用模型、不重跑质控。现有文书展示接口省略原始JSON，不能用于证明规则白名单，故增加管理员只读入口：

`GET /api/v1/qc/diagnostics/source-fields/discharge/{pool_id}?row_no=3&row_no=4`

每次仅接受样本集内1至6个不重复正整数行号，不接受患者坐标或原文。沿用现有认证与管理员权限，返回no-store，只输出字段是否可读、JSON字符数、逐层同值校验和时间用途，不输出姓名、文书正文、JSON原值或签署时间原值。失配/不可用分别返回404/503，错误不携带源数据。

接口在服务进程内调用真实原生读取、快照读取、EvidenceReadSession材料和执行器材料入口，与PG目标行比较。未执行规则判定或创建任务，不构造模型客户端。原始范围及目标字段查询使用只读事务，规则来源读取只执行现有SELECT。签署时间及JSON先从时间基线移除，再比较统一文书时间及出院完成时间，防止两侧同时误用签署时间而错误通过。
