# 医嘱计划结束与实际停止分列展示

用户要求在已有医嘱查看表格中显示已同步的计划结束时间，明确区别于实际停止，并以C22定向验证。

## 实现

- 医嘱文书装配增加`planned_end_datetime`展示投影，原生质控读取口径不变。
- 文书目录、摘要、详情渲染增加独立`order_planned_end_time`/`planned_end_time`，不填入实际停止字段。
- 前端服务保留新字段，只读医嘱表格及编辑副本医嘱表格增加“计划结束时间”，原列明确为“实际停止时间”。
- 有明确时区的计划时间按北京时间显示，无时区值保持医院源钟表时间；计划结束不代表实际已停止。
- 移除前端把撤销时间作为实际停止时间的回退，防止不同事件混用。
