## 验收发现与修复

当前内置浏览器视口宽约 434 CSS 像素。质量、首页、人员报表原抽屉固定宽 900 / 900 / 880 像素，左边界跑出视口，标题、病例信息和关闭按钮不可见；V5 移动导航按钮还覆盖默认层级的关闭按钮。

本轮仅将这三个下钻抽屉宽度改为 `min(原宽度, 100vw)`，并以 Drawer 的 `rootStyle` 将其根层级设为 1100，高于移动导航。沿用既有表格内部横向滚动，不改后端、统计与导出合同或共享布局。

实际回归三个抽屉：左边界 0、右边界约 434.4，处于视口内（亚像素差小于 1）；通过 DOM 命中检查确认关闭按钮位于最上层，正常点击后关闭。数据和病例下钻未变化。既有文件按仓库强制 Prettier 钩子格式化；生产组件除抽屉两项属性外无语义变化。
