## 权威与授权

1. 提醒由正式整改/申诉事件 owner 在同一事务写入，使用事件 ID 派生稳定消息 ID；写入失败时业务状态和事件一起回滚。消息文案读取该次事件意见，不推测医学结论。
2. 收件人为整改受领医生或申诉本人。现代消息在分页、计数、概览、已读更新前统一核对持久用户、医生角色、机构、冻结科室、对象归属和三坐标。旧 DRG/质控通知继续按原收件人读取。
3. 已读接口修复原来仅凭消息 ID 更新的断点，加入收件人及对象授权条件；其他账号看不到医生消息，也不能标为已读。
4. 现代消息携带可信 `interaction_target`，不按同号就诊匹配旧病历；缺失或非法目标拒绝跳转，实际详情/操作再次走各自后端授权。嵌入某条缺陷的待办不消费全局消息参数。
5. 未读数读取服务器全量计数，不以当前30条列表代替；切换账号清空旧消息并丢弃旧响应。消息读取或已读失败不伪造零值/成功，也不继续不确定的现代对象跳转。
6. “全部已读”只更新通知回执，不表示整改完成、申诉通过或原缺陷消除。没有增加医生对未派发缺陷、全院质控结果的发现权限。
