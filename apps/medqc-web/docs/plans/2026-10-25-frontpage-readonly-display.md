# 客户样本病案首页只读展示

## 范围与设计

用户要求在独立分支补齐1022已有21份病案首页展示，接入 `mr_diagnosis`，空字段如实显示未返回；用C11定向验证，不改集成分支、不写业务库、不调用模型或重跑质控。

选择只在当前文书查看链增加独立首页投影，按同一机构、患者、就诊读取 `mr`、`mr_diagnosis`、`mr_surgery`、`mr_cost`。没有扩大公共文书组装器或规则输入白名单，没有刷新持久Bundle，也没有改旧首页API、旧任务或事实冻结。已有表单不能直接套入：其旧读取链使用空的 `diagnosis`，无法展示本批首页诊断。新组件复用当前文书页的版式和字段模型，适配桌面及窄屏，表格横向滚动限定在内容区域。

## 实现边界

- `bundles/frontpage_view.py`：只读全字段来源；首页与费用主记录重复、明细超过1000行或SQL失败直接报错，不能任取首行或把失败当成空数据。没有首页则不凭其他文书造一份首页。
- 当前查看响应把原空首页条目替换为结构化可读条目。基础、住院出院、签署归档、费用以及诊断/手术分别展示；附纯文本与分节回退以兼容旧客户端。记录/提交时钟保持空值，签署归档时间仅显示于自己的字段。
- 前端边界归一化新可选投影，既有接口应答不受影响。只在首页文书且有该投影时使用新组件；空值显示未返回，0/false保留原值，不推断代码含义；源字符串使用文本插值，不执行HTML。
- 除明确列出的显示字段外，不把患者三坐标、内部更新时间或JSON结构当作临床首页正文。缺失信息不从病程推断，不代表医院未填写。
