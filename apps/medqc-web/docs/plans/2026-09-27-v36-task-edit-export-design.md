## 编辑

- 新独立服务和`/api/v1/task-edits/{id}`接口；GET返回当前配置、冻结字段、configuration_version、editable_fields。
- 单次空草稿可完整替换名称、截止时间、日期范围、科室筛选、完整三坐标引用、抽样方法/配置、分配方法/配置。没有持久化owner的任务说明不增加。
- 已抽样、已分配或处理中先支持名称与截止时间；已完成、已取消不可写。已抽样任务重新选择病例/重抽样等待产品口径，不能把本批称为全部编辑范围完成。
- 场景、规则集及创建冻结版本不可经此接口修改；旧record_ids、执行状态、结果和创建人不可写。
- 读取/写入分别检查QC_TASKS.READ/UPDATE，再核对稳定创建人或管理员对象权限。行锁、状态/关联守卫和configuration_version CAS共同保护；同事务完成更新与回读，失败不留下半次配置。
- 新迁移65仅新增配置编辑版本字段，精确核对qc/public两套基线，不执行迁移。配置版本不冒充所有任务生命周期的统一版本。
- 成功审计仅记录任务ID、版本和字段名；现有audit_event是日志，不宣称事务级变更事件表。
- 前端新编辑抽屉按editable_fields展示表单。详情失败不回退假默认，冻结字段只读；账号/任务切换失效旧请求。写入回执严格核对ID和版本，5xx/网络/坏200按未知结果阻止盲目重试。

## 导出

- 独立`GET /api/v1/task-exports`，避免被旧任务详情动态路由捕获。
- 固定全部任务管理权限，复用实际列表的scene/status/keyword语义；不能由前端过滤或仅导当前页。
- 同一只读查询读取最多5001行，5000为硬上限；超限显式拒绝，不静默截断。稳定排序created_at/id，参数非法或数据库异常明确失败。
- CSV内存响应、UTF-8 BOM、中文列名、下载文件名、no-store；所有文本列进行公式注入防护。
- 白名单：编号、名称、场景、类型、状态、进度、总病历、已完成、创建人、创建时间、截止时间、规则集、规则版本、抽样方法、分配方式。不含病例身份/原文、配置JSON、模型输入、内部队列字段。
- 前端下载锁与错误反馈，账号/筛选变化不下载过时响应；审计不记录任务原文或关键词内容。
