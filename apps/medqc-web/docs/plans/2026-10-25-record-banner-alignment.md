# 查看病历与查看结果的病历信息栏统一

独立分支 `codex/record-banner-alignment-20261025`，基于 `0536ec391`。只改客户样本验证前端，不改业务集成线、后端合同、数据库或质控结果。

## 改动

- 抽出 `MedicalRecordContextBanner.vue`，由查看病历和查看结果共用同一模板、头像选择及样式：患者、科室、病历编号、住院起止时间。部分时间缺失时只显示已有字段，不造日期。
- 两个入口共用既有 `resolveRecordResultFocus` 装配函数，补传API已有的性别和年龄给统一头像逻辑。只展示业务病历编号，不把患者/机构/就诊三坐标扩展到banner。
- 结果页现有banner的生效样式收敛到共享组件；移除只针对该banner的重复CSS覆盖，不改公共主题或其他Dashboard样式。窄窗允许信息换行。
- 查看病历使用同样的信息条，保留“查看病历”和只读标识；查看结果的质控结束/完成时间及导出/诊断操作仍保留。查看病历不为展示banner额外读取质控结果，也不显示未授权的质控时间。
- 副本编辑保留原页头和编辑/保存流程；文书读取、目录、医嘱筛选及记录时间回退不变。顶部同一病历上下文来自列表的同一入口，文书工具栏仍使用原有文书取数逻辑。
