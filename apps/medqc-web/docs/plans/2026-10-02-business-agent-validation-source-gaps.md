# 2026-10-02 业务助手M06验收记录与M09来源缺口整合

## 结论

M06“规则验收记录/入口”与M09“保存来源缺口安全投影”已接入业务工具、来源绑定回读、运行时模型投影和管理者来源详情。真实共享库只读读取已有验收正例和资料不足正例；尚未做新的真实模型问答或浏览器操作验收，不能据此宣称模型解释质量通过。

反馈表迁移44→45已按用户授权执行；实名反馈真实写入、防重和越权复验仍待完成，见[反馈激活](2026-10-02-business-agent-feedback-activation.md)。

## 职责边界

- 验收阶段、覆盖计数和保存结论由既有 `RuleValidationService`/`derive_stage` 所有；`business_rule_validation.read_rule_validation` 只做只读注入和白名单投影，不重判阶段，不建表，缺表503、未知规则404、Canonical缺失保持409。
- 来源缺口由正式保存结果所有；`business_source_gaps` 只保留已核实的原因、来源、字段代码和可用性枚举。未知内容被过滤时明确提示“未纳入”，空列表不证明来源齐全，不推断同步成功/失败或医生漏写。
- 仅资料不足或保存了缺口字段的问题附带缺口说明；其他结论不附带，避免模型据此重判。保存结论、建议、原因代码与原值一致。
- 前端：验收记录沿用 `kind=rule`，以 `id=rule-validation:{rule_id}` 区分。按钮为“查看验收记录”，说明为“已保存的规则验收摘要”，不显示“当前规则目录口径”；保存问题的“查看对应规则”不会指向验收记录。受控链接仅管理视图、合法编号且路径逐字匹配时显示。
