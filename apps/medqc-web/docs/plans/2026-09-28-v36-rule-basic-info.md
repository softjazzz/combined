# V3.6 新建质控点基础信息

## 范围

- PRD66仅要求名称、大类、类型、文书并保存草稿。现新建页整体禁用；已有custom_qc用户草稿表、列表、规则编码和同owner读取可以复用。
- 基础草稿仍以custom_qc draft为唯一所有者，不新增表或执行器。64未上线目录聚合、67条件编排、68测试及发布不在本批，不因基础信息完成宣称这些能力交付。
- 文书采用现有支持目录，不使用患者文书，不把70任意导入模板静默映射到执行文书。大类/类型沿现有UI提供候选，但PRD未定义封闭枚举，允许非空自定义值。

## 合同

- 新`/api/v1/custom-qc/workspace/draft-basic-info`：POST四必填`name/category/rule_type/document_type`；GET `/options`返回`documents[{value,label}]`；GET `/{id}`回读；PATCH `/{id}`提交四字段及`expected_updated_at`。
- 名称最长100字符，大类/类型各100，均trim后非空；文书必须属于现有支持目录，未知值422，不走默认文书回退。
- 沿用admin/qc_manager及created_by隔离。创建强制draft，不调用测试、发布或写正式规则；category/rule_type存入受控`check_logic.basic_info`并投影为明确响应字段，旧接口DTO不增必填。
- PATCH只允许同owner草稿并校验CAS，不能改status/published_rule_id/prompt/条件；基础变化清除旧测试证明，不复用旧测试授权新版本。存储错误脱敏，不伪造成功回读。
- 前端仅基础信息表单与同owner草稿列表、分页、回读编辑；保存成功显示真实草稿回执，不提供假的下一步。账号/角色/卸载后旧请求无效，冲突要求重读，提交结果未知不引导盲重试。
- 本批编辑对象为带`basic_info.version=1`的基础信息草稿；既有缺字段草稿在列表只读并明确不可编辑，不猜测旧文书或补齐历史定义。文书变更重新派生对应文书域，保留无关配置。

## 验证

覆盖创建/回读/编辑、必填与长度、未知文书、跨owner、已发布拒绝、CAS冲突、保留无关字段及清测试证明；前端覆盖真实请求、选择目录、失败与迟到响应。主协调集中类型、Lint、编码及聚焦测试并提交。

不执行真实数据库写入、迁移或质控作业。代码完成、隔离库、业务部署、真实病例和浏览器分别记录。
