# 术前抽取受控原文片段：有限修复方案

基线：`edc8c4212`。用户已同意先解决 C04 剩余引用问题，再用有限真实样本复验，不扩展引擎框架。

## 问题与方案

上一轮 C04 的简要病情被模型改写，术前准备由非连续原文拼接后返回；现有严格引文校验正确拒绝，但因此无法完成医学判定。选择原文片段可以消除自由抄写风险，不能证明模型选择的内容支持相应医学字段。

考虑三种方式：继续自由引文仍依赖逐字生成；模型返回字符坐标容易出现边界或编码计数错误；同文书原文片段编号由 Python 还原文本更适合本次最小修复。采用第三种，并保留关联所需术式短引文例外。

- 一般内容字段返回同文书单一片段编号，present 由 Python 取回原文；不接受多编号拼接，不让模型提供替代正文。
- `planned_procedure` 直接参与已有手术事件关联，继续使用原有严格短引文方式，避免整句包含诊断、术式、麻醉而改变关联行为。本轮不重写关联判据。
- 全部受控文书材料按顺序提供；分片保留完整原文与标点，不为控制长度截断材料后声称完成缺失核查，不按 C04 特定句子分片。
- 片段编号仅为本次同文书输入内的定位，不是新的存储事实、签章或公开合同。转换为旧三态事实后进入既有执行、归约、发布、保存及读取链。
- missing 仍须完整核查声明；unknown 仍不是缺失。旧合法短引文和三态引用兼容，旧无效引文不自动修复。不存在编号、跨文书及不合法形状遵循既有规则级抽取失败隔离。
