# 病历池参考稿落地

用户批准浅蓝侧栏、黑色排版、医疗科技蓝操作与轻量列表的参考稿。

现状证据：1440px 下筛选强制单行，搜索与日期被压缩；多层面板占用空间，表格对比度不足。

范围：病历池列表布局和独立视觉样式、共用表格的 recordPoolMode 分支及聚焦测试。保留全部菜单、日期/科室/医生/住院筛选、排序、状态核验、分页、选择事件、任务状态与请求合同。不得把图中的模拟菜单和数据写入产品。不改变业务数量差异。

实现：两行自适应筛选；标题右侧核验；平整表格、可读文字、淡蓝选中行；通过既有事件清除选择。小屏换行，不隐藏功能。

验收：1280/1440/1920 宽度检查；搜索及日期可读；选择和清除、筛选和详情入口聚焦回归；编码、lint、类型检查。浏览器不发起真实批量任务和状态刷新写操作。

风险：页面与表格已有未提交用户修改，必须保留并隔离本次提交；共享样式必须限定病历池，不影响运行/终末/参考首页队列。
