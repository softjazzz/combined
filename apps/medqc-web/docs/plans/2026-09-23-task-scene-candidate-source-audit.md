# 三场景任务候选来源只读核查

## 业务合同

- `running` 是入院后至归档前，包含在院和出院未归档；`final` 必须同时出院且完成归档。依据 V3.6 PRD 第 3.2、3.3 节。任务的 `scene` 只是创建意图，不能证明某份病历属于该场景。
- 任务候选及关联的身份必须是 `institute_id/patient_id/visit_id` 三坐标；旧 `medical_records.id`、单独的 `visit_id` 和旧 registry 的 `visit_type` 均不能代替。
