## 执行顺序

1. 五线并行只读核对原PRD与真实调用链，返回完整动作清单、缺口证据和文件归属，避免重复调查。
2. 主协调确认每批业务合同和互不冲突的文件所有权，将精确文件与验收反例追加本计划后开始实现；共享模块只指定一个owner。
3. 每个业务点先添加聚焦反例，再实现并复跑测试。Python测试隔离真实数据库；Node聚焦测试单worker且轮流占用窗口，主协调独占全量门禁。
4. 主协调检查权限、身份、状态owner、原子性、历史兼容和请求竞态；再执行相关pytest/Ruff、`npm run check:encoding`、只读ESLint、`npm run type-check`、`npm run test:unit -- --maxWorkers=2 --minWorkers=2`。
5. 按独立业务点中文提交，提交前检查暂存清单，仅提交本任务代码与长期结论。更新80项清单和滚动计划；未达整项合同不计数。
6. 达到新增10项时，逐项重新审计合同、当前代码、测试、提交与四层证据，全部证实后才完成Goal。
