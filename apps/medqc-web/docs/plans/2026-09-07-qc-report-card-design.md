# 质控问题报告卡精修

用户已确认按问题报告阅读顺序调整现有卡片。

- 范围：SingleRecordQcResultPanel 及对应测试，不改变后端合同、判定、证据与反馈提交。
- 标题：规则元信息与状态左右分列，问题标题作为主要视觉层级，去除圆形详情箭头及蓝色侧线。
- 正文：展开详情时显示完整判定说明，不重复提供说明展开入口。
- 事实：保留字段和值，去除内层卡片边框及重复辅助说明。
- 证据与建议：保留原生折叠交互和原文定位，增加清楚的展开标记。
- 操作：移到详情之后，复制明确标注为调试信息，不改变脱敏导出。
- 验收：标题、状态、证据和复制回归；说明展开与底部 DOM 顺序测试；窄栏浏览器检查；类型与前端回归。

本次在已有展示模块内修改，不新增独立职责或抽象层。
