# 任务人员筛选与抽样来源合同

本批范围为 PRD40 临床医生筛选与 PRD41 质控医师、质控员两类分组。手册来源见 `2026-09-30-v36-sampling-manual-and-remediation-contract.md`。不修改质控引擎、人员权限或分配结果。

## 来源与边界

- 临床医生沿用工作台的病案首页 `mr.attending_physician_sign` 精确签名事实，筛选引用为机构与签名；按完整三坐标批量读取。它不是应用账号，也不是质控医师。签名缺失的病例不命中医生筛选，来源异常明确失败。
- 质控医师抽样只读取病案首页 `mr.QC_physician_sign`，按机构与源签名分组。该分组不保证同院同名签名代表唯一员工，不授予账号权限；界面称“质控医师签名”。不使用临床医师字段替代。
- 质控员分组复用原质控员分配的最近审核人 owner：`qc_record_reviews` 按三坐标关联，以 `created_at DESC, id DESC` 选最近 `reviewer_id`。查询范围、排序与原质控员分配相同；没有另加场景、审核阶段或账号角色推断。界面称“最近审核质控员”，这是平台实现口径，手册未明示“最近”规则。
- 质控人员分组的候选缺少签名或最近审核人时，整个抽样明确拒绝；数据源故障明确不可用。不制造“未分类”组，不取当前受领人作为历史质控员。

## 抽样与兼容

两类分组各支持固定份数、比例加每组上限，机构之间不合并。同既有科室算法：不足额取全部，比例向下取整，非空组至少一份，再应用上限。这是实现约定，不是手册原文。筛选先于分组抽样，每个病例仅进入一个源分组，不重复抽取。

配置延续既有 `sampling_method/sampling_config`，创建、编辑、模板、定时计划消费同一合同；保存与回放延续整个抽样配置快照和指定三坐标固定集合校验。指定病例不允许上述分组，也不允许评分或临床医生二次筛选。

## 实测与余缺

2026-10-01 业务库只读聚合：`cdm.mr_customize` 共35行，危重/疑难标志均为空；`public.mr_customize` 为空。源字典将 `criticalcare_record_sign/difficult_record_sign` 标为 enum，引用 `indicator_theroshold_code`，但未给出阳性编码。病历类型筛选、抽样及分配仍需确认阳性映射与双阳性归组口径，不能由空值推导“普通”。

病案首页主医院287行的质控医师签名均为空，另一个机构仅一行非空；本批没有声称真实业务病例可完成质控医师分组验收。只读聚合不包含患者原文，本批无数据库写入、迁移执行、部署或浏览器验收。

PRD40、41、42仍未整项完成，病历类型能力缺口保留。
