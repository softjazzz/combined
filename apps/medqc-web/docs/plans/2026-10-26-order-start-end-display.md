# 客户样本医嘱起止时间展示

本批在独立的 registration-department 分支完善“查看病历”和“查看结果”的医嘱时间，不修改集成分支、同步状态或规则判定，不更新既有质控结果。

- 开始时间优先取同一医嘱的 `planned_start_datetime`，缺少时沿用已有开嘱时间；表头说明该回退。
- 计划结束时间单独展示，不填充实际停止时间。实际停止时间缺失时显示“未返回”，取消/执行时间也不能冒充停止时间。
- 独立保存、来源字段及摘要读取补齐计划开始时间。原文书记录时间、提交时间和排序时钟保持原有含义。
- 显式时区按北京时间展示到秒，无时区值保留源端钟表时间。新旧医嘱来源字段均兼容。
- 查看结果的医嘱总览固定显示三列时间，避免实际停止全空时整列被隐藏；关键词可检索计划结束时间。

定向验证：前端四文件48项通过；后端两文件47项通过；完整类型检查通过；变更文件ESLint无错误。Ruff有5项已有诊断，与HEAD逐项比较无新增。未运行全量测试，不调用模型、不重跑质控；C11现有两条病危医嘱作为本机运行接口和页面核对目标。无需数据库迁移或补数，历史Bundle缺少新字段时如实回退已有开嘱时间，不读取当前值冒充历史快照。
