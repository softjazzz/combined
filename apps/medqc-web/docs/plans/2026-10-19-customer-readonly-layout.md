# 客户样本只读病历弹窗高度修复

用户在780×1140视口反馈查看病历底部大片空白。浏览器测量确认外层已全屏，但Spin及内容容器不伸展，阅读组件仍受680px高度上限约束；Ant Modal默认内边距还让正文超出视口。

只在客户样本只读全屏模式调整布局：外层使用100dvh并清除默认内边距，Spin、内容及阅读组件沿flex链分配剩余空间，覆盖普通对照组件的固定高度。正文内部滚动，标题及底部关闭栏保留；移除无法命中Teleport弹窗的旧只读规则。沿用项目现有视觉样式，不改共享阅读组件或数据接口。

实际浏览器回读：正文可视高度从约608px增至890px，内容与关闭栏之间无多余空白，关闭栏底边与视口底边一致。End键可滚动正文，关闭栏位置不变，随后Home恢复阅读起点。截图仅保留底部区域，位于私有排查目录，不提交临床内容。

验证：不自动修文件的全量ESLint检查0错误（1361项现有警告），npm run type-check通过；医院时区下npm run test:unit -- --maxWorkers=2 --minWorkers=1通过147文件、1334项用例。提交前执行暂存文件编码检查。未启动质控、调用真实模型、改动病历或后端判定。当前集成工作树前端开发服务已热更新；客户交付包尚未重新构建。
