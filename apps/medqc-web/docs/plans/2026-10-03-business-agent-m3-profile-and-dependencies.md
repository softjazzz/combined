# 2026-10-03 业务助手 M3 同病例画像面板入口（D07）与外部依赖

## 结论

病历详情页的业务助手在医生视图提供“打开本病例画像面板”：Drawer 仅在宿主声明 `panels=['profile']` 时显示入口，发出三坐标；`RecordDetailWorkspace` 只转发与当前详情病例三坐标完全一致的请求并关闭抽屉；`WorkstationV4View` 再次核对后调用既有 `openAiProfilePanel`。画像组件只在用户点击“分析”时调用模型，打开面板不自动分析。首页助手没有完整病历对象，不提供该入口。

组件测试覆盖：未声明不显示、管理视图不显示、三坐标不一致不转发、一致时转发。未做浏览器验收：病历详情页依赖主应用病历/文书接口，独立只读 8003 未挂载，按约定不改动主 3000/8001。
