## 冻结的三条主验收路径：如获批准最多六轮

仅使用已有 admin 测试账号、明确授权病例及科室。本计划不授权调用；必须取得主协调明确额度后执行。最多六轮，医生两轮、管理两轮、规则两轮；失败、超时、取消均占一轮，不补跑。无新增真实 Embedding 专项测试；问答按工具实际检索计数。全部真实问句与原生事件存私有目录，不追加问句尾缀。

D2完成后用只读接口及按钮打开保存依据→当前文书，唯一定位才高亮，局部定位说明范围；打开相应规则详情及规范引用，逐项回读来源。R2后同样打开规则详情和已取得的规范引用。这些点击不得触发“查询这条规则”新问答：若本轮未读取规则，记失败或未完成，不消耗第七轮补查。

六轮可证明三条代表性路径，不代表所有问法、实际医院角色或完整客户规范验收。规则搜索双视图可见性、歧义/无命中、状态类别、缺历史版本、提醒/台账边界、A→B→A、迟到响应、停止/恢复、多个汇总来源与恢复后锚点等反例全部使用本地受控测试；浏览器恢复可回看既有会话，不新增真实聊天。提醒读取依赖未接通，仍不得称M1整体完成。

返回原汇总的受控多轮案例必须覆盖：统计A→统计B→零工具解释轮回填此前引用→点击回填的A病例，返回A原统计轮；不能把带有旧statistics引用的解释轮当成汇总所有者。重新打开或恢复后再从原病例卡下钻也应可定位，返回本身不查询。刷新统计仅在明确发起新查询时发生，本六轮计划不额外刷新。

## 最小无真实调用回归集

- 后端：自然词唯一候选、多候选、无命中、非法参数；两视图工具可见；当前目录状态和部分范围原样搬运；单问题保存版本已知/缺失，历史正文不可用；结果变更409及越权403保留。
- 运行时：搜索候选完整投影；当前与保存版本进入模型输入且语义分开；提醒/台账未接通必须明确表达能力边界；旧工具投影与规范引用验证不回退。
- 前端：从指定统计轮次下钻、返回同一轮；多个汇总分别返回；恢复后的轮次定位；切范围清理旧定位；返回不调用模型或业务刷新。
- 文案反例：询问提醒/台账时不得“当前没有”“已催办”“已写入”；状态不可用不报零；历史版本缺失不称与当前相同；部分实施不称全部启用。

提醒/台账的受控无数据测试只证明失败表达，不代表查询能力已接通。真实答复仅靠提示词不足以保证，需要后续已授权真实轮次观察。

## 交付记录与未验边界

每条路径分别记录通过、失败或未执行，附代码版本、规则目录/保存版本、模型配置、工具数、Token、耗时、HTTP失败类别及新增真实调用计数。尚无新问答结果时仅可标“功能补齐待真实验收”。当前客户完整规范、实际医院角色授权、旧503/401根因、自由跨期覆盖比较及消息数据接通均不得被三路径局部通过覆盖。

PRD第12节“提交反馈”若依赖既有反馈入口，应另记只读M1与既有入口接续情况；本轮不新增反馈写入、重检、任务、分派、催办、改病历或规则发布。这些不得被悄悄纳入本次开发或称已完成。
