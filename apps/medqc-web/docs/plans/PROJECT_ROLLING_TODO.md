1. 开始前补充问题证据、根因假设、文件范围和验收条件。
2. 开发中更新状态和最新进展；被实测推翻的假设必须留下更正记录。
3. 完成后填写验证证据和提交号，再移动到“完成记录”。
4. 暂缓项目保留重新启动条件，不因暂时不处理而删除。
5. 新发现的问题使用下一个连续编号，不复用已关闭编号。

状态词表：

- `待处理`：已有证据，尚未开始。
- `调查中`：正在只读定位，根因尚未确认。
- `进行中`：方案和范围已经明确，正在实施。
- `待验证`：代码已修改，需要真实病例、接口、浏览器或发布包验证。
- `暂缓`：已记录，但当前不实施；必须写明重新启动条件。
- `阻塞`：缺少外部输入、数据或决策，当前无法继续。
- `已完成`：验收通过且已有提交或长期产物。

优先级词表：

- `P0`：阻止客户使用、结果读取或发布。
- `P1`：明显影响准确性、性能、排障或演示体验。
