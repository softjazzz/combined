# 文书记录时间缺失时采用提交时间

用户确认记录时间缺失时允许用提交时间代替，并指出仅修页面不能解决质控无法纳入的问题。本次在集成分支 `codex/business-agent-integration` 同时修复会诊规则时间投影和查看病历时间展示，不修改同步取源策略。

## 已确认断点与修复

- PG中C02四份新增会诊的 `submit_datetime` 完整，`record_time` 为空。原生/快照证据白名单已允许读取提交时间，但会诊执行器 `_documents` 仍只取 `record_time`，投影时丢失可用时间。改用既有权威时间选择函数，优先记录时间，再提交时间；会诊 `_row_time` 与病程共用同一字段优先级。
- 文书组装器已经解析提交时间，但Bundle目录 `_inventory_entry` 没有传递 `submit_time`。补齐目录及轻量摘要SQL投影，并在全文/摘要/单文书元数据中保留提交时间和来源。
- 查看病历在记录时间缺失时以提交时间作为展示值，保留 `record_time_source=source_submit_time`，前端时间标签显示“提交时间”。有记录时间仍优先，既有其他类型的展示兼容路径保留。

这是文书记录时间的受控回退，不把提交时间填进源表 `record_time`、`request_time` 或 `consultation_time`。会诊申请/完成业务时效规则仍要求其对应业务时间；仅有提交时间不能证明实际申请或完成发生时间。两种文书时间均缺失时不从同步更新时间或正文残缺日期推算。
