- CR-011缺判据，CR-018与既有子规则重叠且总开关语义未定义，两者以paused/executable=false展示，不能开启。与既有非编码pending条目口径一致，不假称18条医学规则都已实现。
- CR-001至004、013、017可与既有确定性检查对应；其余已有语义提示的条目仅做ID、启用集合和输出白名单接线，不新增医学文本或扩大检查范围。009/014既有子集覆盖不得冒称新判据。
- 每次执行冻结版本及启用集合；关闭、下线、删除项不进入相应检查或结果。未知模型ID不得猜归属；沿既有失败合同，不增加LLM调用上限。
