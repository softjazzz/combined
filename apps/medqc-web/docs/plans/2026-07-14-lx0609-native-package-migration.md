# LX0609 独立规则包统一入口与迁移清单

## 目标

先完成 49 个 `LX0609-*` 客户规则的统一包入口，再按规则族替换内部兼容执行器。
外部调用、任务范围和客户结果只使用 `LX0609-*`；`SC-*`、`LX-*`、`CL-*`、
`LXE-*` 仅允许作为尚未迁移规则的包内兼容依赖。

本阶段不同时重做 45 个规则的临床口径。统一入口必须保持现有开关和结果行为，
后续每迁移一个规则族，再用同病例 A/B、人工复核、耗时和 token 证明收益。

## 统一入口契约

1. 调用方只提交 `LX0609-*` 客户 ID；其他 ID 在独立包入口直接拒绝。
2. 包入口按规则目录顺序生成一次执行计划，分成：
   - `native_sync_rule_ids`：确定性原生执行；
   - `native_async_rule_ids`：需要裁剪语义调用的原生执行；
   - `compatibility_rule_ids`：尚未迁移的客户规则；
   - `compatibility_execution_rule_ids`：仅包内可见的旧执行依赖。
3. `execution.py` 只消费包计划，不再自行识别 029/030/032/040 特例。
4. 现有原生开关仍是规则级回滚机制；关闭后对应点回到包内兼容路径。
5. 结果、审计和客户 DTO 不输出旧映射 ID。

## 按规则族迁移顺序

| 批次 | 规则族         | 选择原因                                         | 第一阶段验收重点                                  |
| ---- | -------------- | ------------------------------------------------ | ------------------------------------------------- |
| 1    | 基础时限       | 以文书存在和时间计算为主，适合先验证批量迁移模板 | 5 点旧执行派发为 0；时间边界与缺源状态一致        |
| 2    | 会诊质量       | 仅 4 点，范围小，可验证单次语义子族调用          | 同病例状态差异逐条复核；调用数不按规则倍增        |
| 3    | 检查检验       | 共用报告时间、阳性结果和病程记录依赖             | 结构化时间优先；报告 unavailable 不误判缺陷       |
| 4    | 输血           | 共享输血适用事实和文书族，可批量复用事实         | 未输血不得进入；父子/重复缺陷正确抑制             |
| 5    | 查房病程       | 时间轴、复制病历和病情变化语义混合               | 017 不滥报待复核；病危病重时间窗准确              |
| 6    | 肿瘤病理       | 需要手术、病理、化疗跨来源关联                   | 019 送检事实不误报；恶性关联必须是本次就诊        |
| 7    | 手术麻醉剩余点 | 依赖最多且已有明确数据缺口，最后收口             | 保留 029/030/032；040 单独开关；缺源优先 data_gap |

迁移顺序不等于临床重要性排序。手术麻醉仍是高风险规则族，但其 024/025/028
等点已确认缺少可靠上游事实；先完成其他族的接口迁移，可以避免把“独立包迁移”
和“临床事实补齐”绑成一个长期大任务。

## 已完成迁移批次

### 批次 1：基础时限（001/002/004/005/006）

- 五点统一由 `basic_timeliness` 原生执行器一次计算，不调用模型；正式入口不再派发
  `SC-002/CL-081/SC-021/SC-054/SC-048/SC-049/CL-080`。
- 001/002/005/006 复用既有结构化时间计算；004 仅接受明确标注的“抢救结束时间”，
  缺少明确结束时间或文书记录时间时返回 `data_gap`，不从“抢救结束”等泛文本猜测。
- 10 份同病例正式入口 A/B 共 50 个判定，迁移前后状态一致 50/50，错误 0，token 0；
  旧链 p50 约 24.98 秒，原生 p50 约 0.63 秒。
- 004 真实抢救病例三类代表样本（合规、超时、资料不足）迁移前后 3/3 一致；
  原生耗时约 0.12–0.24 秒，旧链约 2.06–10.90 秒。
- 只读核对发现 3/15 个抢救病例的已持久化 bundle 与当前源表证据存在时间快照漂移；
  该问题同时影响迁移前后正式入口，属于 bundle 新鲜度风险，不通过改变规则状态掩盖。
- `LUXIAN_0609_NATIVE_BASIC_TIMELINESS_ENABLED=false` 可整族回退兼容执行。

### 批次 2：会诊质量（020/021/022/023）

- 四点统一由 `consultation_quality` 原生执行器按病例一次调用裁剪语义模型，正式入口不再派发
  `LX-017/CL-250/SC-068/LX-015/SC-069/CL-248/CL-071`。
- 单病例最多完整分析 12 张会诊单，并优先保留每日/上级病程中的会诊关联段；超过预算不静默
  丢文书，而是保守返回 `data_gap`。该预算覆盖本地 214 个会诊就诊中的 212 个；另有 18 个就诊
  的会诊相关后续病程超过每来源 3 条预算，020/023 同样保守返回 `data_gap`，021/022 不受影响。
- 021 只判断申请段，022 只判断会诊意见段；同一会诊行先确定性分段，禁止用会诊医师意见
  反推申请目的明确。
- 020/023 共用逐文书执行链接：模型只提出会诊单与后续病程的受控引用，Python 再校验来源、
  明确会诊执行措辞和时间先后。会诊单内“已遵嘱”不能替代后续病程，申请会诊的病程也不能
  冒充执行记录。
- 020 检查每张会诊单是否有后续执行记录；023 只评价已有执行记录是否具体。完全无执行记录时
  020 为 `non_compliant`、023 为 `not_applicable`；时间或来源无法证明时保守返回 `data_gap`。
- 10 份真实会诊病例完成逐例内容复核和多轮稳定性检查；正式入口 40 个判定只调用模型 10 次，
  7 条旧规则派发为 0，目录顺序、模型调用次数和 token 归因正确。最终回归总 token 为 28,681，
  模型调用 10 次，p50 约 2.15 秒、p95 约 3.36 秒。
- 最新一轮人工复核一致 38/40；2 个差异都集中在 021“会诊目的是否明确”，且重复运行出现过
  1 例状态波动，列入迁移后准确性优化。020/023 的来源、逐文书链接和时间边界 20/20 符合人工
  复核，022 为 10/10；结果中未出现正文、prompt 或旧映射诊断字段。
- `LUXIAN_0609_NATIVE_CONSULTATION_ENABLED=false` 可整族回退兼容执行。

### 批次 3：检查检验（010/011/012/014/015）

- 五点统一由 `exam_lab` 原生执行器接管，正式入口开启时不再派发
  `LXE-23/SC-114/LXE-24/LX-031`，客户结果只保留所选 LX0609 ID 和目录顺序。
- 本批次目标是先解除旧规则映射依赖，不把数据补齐和临床准确率优化混入迁移。门控只接受
  `current_visit_ct_mri_exam` 或 `current_visit_culture_or_ast` 的明确结构化事实，并校验批准来源和
  当前就诊绑定；病历中泛出现
  “CT/MRI/培养/药敏”等文字不能代替事实，也不会触发模型。
- 事实未出现时返回迁移前兼容的 `not_applicable` 且模型调用为 0；投影不存在、模型异常或输出
  无效时保守返回 `data_gap`，不得折叠为不适用或确定缺陷。
- 事实命中后，每条所选客户规则最多调用一次自身 `custom_prompt`；模型只接收检查/检验来源及
  首程、日常、上级、抢救病程的有界裁剪，不接收全文或完整 evidence JSON。输出只采用
  `is_compliant`，原文证据、prompt、raw response 和旧映射诊断字段不进入客户结果。
- 同一病例批量一次调用的 POC 虽然连续三次均可解析，但状态稳定性和逐规则一致率均为
  93.33%，未达到 95%，因此未接入。明确触发的既有合成样本逐规则调用合同稳定，但不作为
  临床准确率证据。
- 20 份真实候选病例的当前正式投影均没有上述结构化事实；迁移后 100 个判定全部保持
  `not_applicable`，模型调用、token、旧规则派发、顺序错误均为 0。上游结构化检查/培养事实
  接入后，仍须另做真实阳性/阴性人工复核。
- `LUXIAN_0609_NATIVE_EXAM_LAB_ENABLED=false` 可整族回退兼容执行。

## 每个规则族的退出条件

- 正式公共入口只返回所选 `LX0609-*`，旧执行规则派发数为 0。
- 同一批真实病例完成迁移前后 A/B；差异必须逐条人工归因，不能只看单测。
- 已知正确的结果不得退化；已知旧链误判可采用经人工确认的原生结果。
- 优先按病例与语义子族合并 LLM；若同输入稳定性未达到 95%，不得为减少调用强行批量，
  可在严格适用性门控后逐规则调用，并明确记录性能债务。
- `not_applicable`、`data_gap`、`non_compliant`、`technical_error` 边界不互相替代。
- 客户结果不包含旧映射 ID、完整正文、prompt/raw response、坐标或异常文本。
- 规则族开关关闭后可恢复迁移前兼容执行。
