## 唯一配置及行为

规则总表的 `release_scope` 默认为 `default`。仅以下五条配置为 `acceptance_only`：

- LX0609-06-01-01
- LX0609-06-01-03
- LX0609-06-02-01
- LX0609-06-03-02
- LX0609-09-01-02

`acceptance_only` 必须属于已注册且正式判据可执行的规则；不以“定义待确认”或资料不足表示待验收。

1. 病历池、单病历和客户样本默认任务均排除五条，默认交付74条，其中64条执行、10条按既有暂停合同交付。不为排除项输出失败或未执行结果。
2. 普通批任务入口显式传五条时返回422，诊断采集不例外。客户样本可以逐条显式选择，执行该选择，不附带其他待验收规则。
3. 选择器展示待验收标签；全选及规则族勾选不自动选择待验收规则。任务保存派生的待验收ID快照用于摘要展示，不能用该快照决定执行范围。
4. 新任务冻结执行与交付范围；分族父子任务分别冻结各自范围。Worker读取已保存范围，不回退到当前目录。
5. 旧任务缺少交付范围时，只从原任务保存的执行、暂停和门控规则列表恢复；无法恢复时拒绝重试并提示新建。失败规则重试须为原范围子集。旧任务中原本包含五条的仍按原计划重试。
6. 不从可执行目录移除五条，不改变历史结果读取、反馈与导出合同。

## 实施中发现的默认入口问题

原普通默认入口取全部阶段目录，其中包含未注册的06-03-01，导致选择校验失败；样本默认暂停列表也会把该规则带给Worker。现以已有客户可选目录作为普通默认范围，并将样本暂停列表限制在本次交付范围内。没有改变06-03-01本身的配置。
