## 准入原则

- 原始 `status` 全部保留，页面和报告使用新增 `display_status` / `can_show_as_defect`。
- 技术异常只进入内部诊断，不进入医生缺陷清单。
- 数据缺口不包装成医生病历缺陷。
- 跨文书/时间链规则缺对照证据时进入待复核，不直接确认为缺陷。
