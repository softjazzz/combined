# 大模型API接入指南

本指南将帮助您配置和使用真实的大模型API来进行智能病历导入。

## 🚀 快速开始

### 1. 打开API配置界面

在智能病历导入页面，点击右上角的 **"API配置"** 按钮。

### 2. 选择API服务商

系统支持以下大模型API：

- **OpenAI GPT-4** - 最强大的通用大模型
- **百度文心一言** - 中文理解能力强
- **阿里通义千问** - 企业级可靠性
- **腾讯混元** - 医疗垂直能力强
- **智谱ChatGLM** - 开源友好
- **本地部署模型** - 数据完全私有
- **模拟模式** - 开发测试用

## 📋 详细配置步骤

### OpenAI GPT-4 配置

1. **获取API密钥**
   - 访问 [OpenAI官网](https://platform.openai.com/)
   - 注册账号并创建API密钥
   - 确保账户有足够的余额

2. **配置步骤**
   ```
   API服务商: OpenAI GPT-4
   API密钥: sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

3. **注意事项**
   - 需要海外网络环境
   - 注意API调用费用
   - 考虑数据隐私问题

### 百度文心一言配置

1. **获取API密钥**
   - 访问 [百度智能云](https://cloud.baidu.com/)
   - 开通文心一言服务
   - 获取API Key和Secret Key

2. **配置步骤**
   ```
   API服务商: 百度文心一言
   API密钥: 您的Access Token
   ```

3. **优势**
   - 国内网络稳定
   - 中文理解优秀
   - 数据安全合规

### 阿里通义千问配置

1. **获取API密钥**
   - 访问 [阿里云控制台](https://dashscope.console.aliyun.com/)
   - 开通通义千问服务
   - 获取API Key

2. **配置步骤**
   ```
   API服务商: 阿里通义千问
   API密钥: sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

### 本地部署模型配置

1. **部署本地模型**
   ```bash
   # 使用Docker部署
   docker run -d -p 8000:8000 \
     --name medical-llm \
     medical-llm:latest
   ```

2. **配置步骤**
   ```
   API服务商: 本地部署模型
   自定义端点: http://localhost:8000/v1/chat/completions
   ```

3. **优势**
   - 数据完全私有
   - 无网络依赖
   - 可定制化

## 🧪 测试连接

配置完成后，点击 **"测试连接"** 按钮验证配置是否正确：

- ✅ **连接成功** - 显示响应时间，可以开始使用
- ❌ **连接失败** - 检查API密钥和网络连接

## 💡 使用建议

### 开发环境
- 推荐使用 **模拟模式** 进行开发测试
- 无需API密钥，响应快速
- 返回预设的测试数据

### 生产环境
- 推荐使用 **百度文心一言** 或 **阿里通义千问**
- 国内网络稳定，数据安全
- 企业级服务保障

### 医疗场景
- 推荐使用 **本地部署模型**
- 数据完全私有，符合医疗数据安全要求
- 可针对医疗场景进行定制优化

## 🚨 注意事项

### 数据安全
- 医疗数据属于敏感信息，选择API时需考虑数据安全
- 推荐使用国内服务商或本地部署
- 确保API服务商符合医疗数据保护法规

### 成本控制
- 大模型API按Token计费，注意控制成本
- 可设置每日调用限额
- 监控API使用情况

### 性能优化
- 合理设置并发数量
- 使用缓存减少重复调用
- 优化提示词长度

## 🔍 故障排除

### 常见问题

1. **API密钥无效**
   - 检查密钥是否正确
   - 确认账户状态正常
   - 验证服务是否已开通

2. **网络连接失败**
   - 检查网络连接
   - 确认防火墙设置
   - 尝试使用代理

3. **解析结果不准确**
   - 优化提示词
   - 调整置信度阈值
   - 增加示例数据

4. **响应速度慢**
   - 选择更快的API服务
   - 优化提示词长度
   - 使用本地部署
