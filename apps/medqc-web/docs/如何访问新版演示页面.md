# 如何访问 LLM 质控演示新版页面

## 🎯 问题说明

您当前访问的是**旧版本**的演示页面，而不是新开发的 P0-P2 版本。

---

## 📍 两个版本的区别

### 旧版本（LLM质控演示增强版）
- **路径**：`/dashboard/llm-qc-demo-enhanced`
- **菜单名称**：LLM质控演示增强版
- **图标颜色**：紫色到蓝色渐变
- **特点**：原有的演示系统

### 新版本（LLM质控演示新版）✨
- **路径**：`/dashboard/llm-qc-demo-new`
- **菜单名称**：LLM质控演示新版
- **图标颜色**：靛蓝到紫色渐变
- **特点**：P0-P2 重构后的新系统，包含：
  - ✅ 控制面板（紫色渐变，固定在顶部）
  - ✅ 通知管理（右侧边栏）
  - ✅ 申诉管理（右侧边栏）
  - ✅ 底部折叠面板（统计、日志、性能监控）
  - ✅ 步骤式演示流程

---

## 🚀 如何访问新版本

### 方法 1：从菜单进入（推荐）

1. **登录系统**
2. **在左侧菜单中找到**：
   - 向下滚动菜单
   - 找到 "LLM质控演示增强版"（紫蓝渐变图标）
   - **在它下方**应该有 "LLM质控演示新版"（靛蓝紫渐变图标）
3. **点击 "LLM质控演示新版"**

### 方法 2：直接访问 URL

在浏览器地址栏输入：
```
http://43.163.116.243:3000/#/dashboard/llm-qc-demo-new
```

## 🔍 如何确认您在新版本页面

### 新版本的特征

1. **顶部有紫色渐变控制面板**：
   - 包含 "开始演示"、"暂停"、"停止"、"重播" 按钮
   - 包含 "上一步"、"下一步" 按钮
   - 包含步骤选择下拉框
   - 右侧有进度圆环和"更多"菜单

2. **右侧有标签页侧边栏**：
   - "通知管理" 标签页（带徽标）
   - "申诉管理" 标签页（带徽标）

3. **底部有三个折叠面板**：
   - "统计与进度"（带徽标）
   - "演示日志"（带徽标）
   - "性能监控"

4. **页面标题**：
   - 浏览器标签页显示："LLM质控演示新版（测试） - 大模型病案质控系统"

### 旧版本的特征

1. **没有顶部紫色控制面板**
2. **没有右侧标签页侧边栏**
3. **没有底部折叠面板**
4. **页面标题**：
   - 浏览器标签页显示："LLM质控演示增强版 - 大模型病案质控系统"

## 🐛 如果菜单中没有"LLM质控演示新版"

### 可能的原因

1. **浏览器缓存问题**：
   - 按 Ctrl+Shift+R（Windows）或 Cmd+Shift+R（Mac）强制刷新
   - 或清除浏览器缓存

2. **权限问题**：
   - 确认您使用 admin 账号登录
   - 只有 admin 角色才能看到这个菜单项

3. **前端代码未更新**：
   - 检查 Vite 开发服务器是否正常运行
   - 检查控制台是否有错误

---

## 📝 测试步骤

一旦进入新版本页面，请按照以下步骤测试：

1. **确认页面布局**：
   - ✅ 顶部有紫色控制面板
   - ✅ 右侧有标签页侧边栏
   - ✅ 底部有折叠面板

2. **测试控制面板**：
   - 点击 "上一步"、"下一步" 按钮
   - 使用步骤选择下拉框
   - 点击 "更多" 菜单

3. **测试侧边栏**：
   - 切换 "通知管理" 和 "申诉管理" 标签页
   - 查看通知列表
   - 查看申诉列表

4. **测试底部面板**：
   - 展开/折叠 "统计与进度" 面板
   - 展开/折叠 "演示日志" 面板
   - 展开/折叠 "性能监控" 面板
