# 客户机交付包编译打包指南

本文用于在开发机上生成客户机可部署的 MedQC Web 交付包。默认输出到 `D:\LLM\LX888\release`，并排除 ICD 向量索引、embedding、运行日志、本地密钥和临时数据。

## 适用目录

在开发机进入项目目录：

```powershell
Set-Location -LiteralPath "D:\LLM\LX888\apps\medqc-web"
```

## 常规构建

优先使用项目标准构建：

```powershell
npm run build
```

构建成功后，确认前端产物存在：

```powershell
Test-Path ".\dist\index.html"
```

## 备用构建方式

如果 `npm run build` 在本机出现 `src/components.d.ts` 写入失败，可临时关闭组件声明文件生成。该方式只影响本次 release 构建，不修改正式配置文件。

```powershell
$repo = (Resolve-Path .).Path -replace '\\','/'
$src = Get-Content -LiteralPath .\vite.config.mjs -Raw
$tmp = '.\vite.config.release-no-dts.mjs'

$content = $src `
  -replace "const __dirname = dirname\(fileURLToPath\(import\.meta\.url\)\)", "const __dirname = '$repo'" `
  -replace "dts: 'src/components\.d\.ts',", "dts: false,"

Set-Content -LiteralPath $tmp -Value $content -Encoding UTF8

npx vite build --mode customer --config $tmp --configLoader native

$exit = $LASTEXITCODE
Remove-Item -LiteralPath $tmp -Force -ErrorAction SilentlyContinue

if ($exit -ne 0) {
  throw "前端构建失败"
}
```

## 打包到 release 目录

前端构建成功后执行打包脚本：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass `
  -File scripts\package-customer-release.ps1 `
  -OutputRoot "D:\LLM\LX888\release" `
  -SkipBuild
```

脚本会生成：

```text
D:\LLM\LX888\release\medqc-web-customer-YYYYMMDD-HHMMSS
D:\LLM\LX888\release\medqc-web-customer-YYYYMMDD-HHMMSS.zip
```

`-SkipBuild` 表示直接使用当前 `dist` 目录，避免打包脚本再次触发前端构建。

## 排除内容

打包脚本会排除以下内容：

- `backend\.env`
- `backend\data\vector`
- `backend\data\manual_qc_runs`
- `backend\data\sample_pool_uploads`
- 本地 SQLite/demo DB 文件
- 后端测试目录、缓存、临时脚本、运行日志
- ICD 向量索引和向量构建脚本
- `.pyc`、`.pkl`、`.log`、`.faiss`、`.index` 等运行或向量相关文件
- 大部分前端字体，仅保留 Source Han Sans SC Regular/Medium

## 检查最新压缩包

打包后检查最新 zip：

```powershell
$zip = Get-ChildItem "D:\LLM\LX888\release" -Filter "medqc-web-customer-*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

$zip.FullName
```

检查压缩包中是否误带向量或 embedding 文件：

```powershell
Add-Type -AssemblyName System.IO.Compression.FileSystem
$archive = [System.IO.Compression.ZipFile]::OpenRead($zip.FullName)

$archive.Entries |
  Where-Object {
    $_.FullName -match 'vector|embedding|faiss|\.npy$|\.index$|\.bin$|backend/data/vector'
  } |
  Select-Object FullName

$archive.Dispose()
```

如果没有输出，说明没有发现上述向量相关文件。

## 最短命令

常规情况下只需要：

```powershell
Set-Location -LiteralPath "D:\LLM\LX888\apps\medqc-web"
npm run build
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\package-customer-release.ps1 -OutputRoot "D:\LLM\LX888\release" -SkipBuild
```

如果 `npm run build` 失败且错误与 `src/components.d.ts` 写入有关，改用本文的“备用构建方式”后再执行打包脚本。
