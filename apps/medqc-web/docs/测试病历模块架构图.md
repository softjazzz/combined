# 测试病历模块架构图

## 系统整体架构

```
医疗质控系统
├── 用户认证模块
```

## 测试病历模块内部架构

```
测试病历模块
├── 📁 前端组件 (Frontend Components)
│   ├── 🏠 主页面 (TestMedicalRecordsView.vue)
│   ├── 📝 病历编辑器 (RecordEditor.vue)
│   ├── 📋 病历列表 (RecordList.vue)
│   ├── 🎭 模板选择器 (TemplateSelector.vue)
│   ├── 🎬 场景管理器 (ScenarioManager.vue)
│   ├── ⚡ 测试执行器 (TestExecutor.vue)
│   ├── 📊 结果分析器 (ResultAnalyzer.vue)
│   └── 🔄 批量操作 (BatchOperations.vue)
│
├── 📁 后端服务 (Backend Services)
│   ├── 🔌 API控制器 (Controllers)
│   │   ├── TestRecordsController
│   │   ├── TestScenariosController
│   │   ├── TemplatesController
│   │   └── TestExecutionsController
│   │
│   ├── 💼 业务服务 (Services)
│   │   ├── TestRecordService
│   │   ├── ScenarioService
│   │   ├── TemplateService
│   │   ├── TestExecutionService
│   │   └── ResultAnalysisService
│   │
│   └── 🗄️ 数据访问层 (Data Access)
│       ├── TestRecordRepository
│       ├── ScenarioRepository
│       ├── TemplateRepository
│       └── ExecutionRepository
│
├── 📁 数据库设计 (Database Schema)
│   ├── 📄 test_medical_records (测试病历表)
│   ├── 📄 test_scenarios (测试场景表)
│   ├── 📄 scenario_records (场景病历关联表)
│   ├── 📄 test_executions (测试执行记录表)
│   └── 📄 medical_record_templates (病历模板表)
│
└── 📁 集成接口 (Integration APIs)
    ├── 🔗 质控规则模块集成
    ├── 🔗 AI分析引擎集成
    ├── 🔗 用户认证集成
    └── 🔗 文件存储集成
```
