## 🔧 环境要求

### 前端环境
- **Node.js**: >= 18.0.0
- **pnpm**: >= 8.0.0
- **操作系统**: Linux/macOS/Windows

### 后端环境
- **Python**: >= 3.10
- **虚拟环境**: venv 或 conda
- **数据库**: Supabase (PostgreSQL)

## 🚀 快速启动

### 开发启动脚本
```bash
# 在项目根目录执行
cd /home/ubuntu/coding/health-qc-monorepo

# 启动前端 (端口 3000，仅开发使用)
pnpm dev:medqc  # 仅开发使用

# 启动后端 (端口 8001) - 新终端窗口
cd apps/medqc-web/backend
export JWT_SECRET=dev-secret
pwsh ./start_dev_backend.ps1 -Port 8001
```

## 🌐 端口配置

| 服务 | 端口 | 用途 | 访问地址 |
|------|------|------|----------|
| **前端** | 3000 | Vue 3 开发服务器 | http://localhost:3000 |
| **后端** | 8001 | FastAPI 服务器 | http://localhost:8001 |
| **API文档** | 8001 | Swagger UI | http://localhost:8001/docs |
| **健康检查** | 8001 | 服务状态 | http://localhost:8001/api/v1/health |

### 重要说明
- ⚠️ **后端必须使用 8001 端口**，不是 8000
- 前端代码中的 API 调用配置指向 8001 端口
- 如果使用错误端口，前后端无法正常通信
- Windows 环境优先使用 `start_dev_backend.ps1`，不要直接跑裸 `uvicorn ... --reload`
- 前端生产不使用 `pnpm dev` 或 `pnpm dev:medqc`

## ❗ 常见问题

### 1. 后端启动失败

#### 问题：`python: command not found`
```bash
# 解决方案：确保 Python 环境可用后，通过启动脚本启动
cd /home/ubuntu/coding/health-qc-monorepo/apps/medqc-web/backend
pwsh ./start_dev_backend.ps1 -Port 8001
```

#### 问题：`ModuleNotFoundError: No module named 'fastapi'`
```bash
# 解决方案：确保后端 Python 环境中已安装依赖
pip install -r requirements.txt
```

#### 问题：JWT_SECRET 未设置
```bash
# 解决方案：设置环境变量
export JWT_SECRET=dev-secret
```

### 2. 前端启动失败

#### 问题：端口被占用
```bash
# 查找占用进程
lsof -i :3000

# 杀死占用进程
kill -9 <PID>
```

#### 问题：依赖安装失败
```bash
# 清理缓存重新安装
rm -rf node_modules
pnpm install
```

### 3. 前后端通信问题

#### 问题：API 调用失败
- 确认后端在 **8001 端口** 运行
- 检查前端 API 配置是否指向正确端口
- 确认后端健康检查通过

#### 问题：CORS 错误
- 后端已配置 CORS，通常不会出现此问题
- 如果出现，检查后端 CORS 配置

### 4. Supabase 连接问题

#### 警告：`Supabase 客户端初始化失败`
```
2025-09-16 11:04:44,133 - app.core.supabase_client - WARNING - Supabase 客户端初始化失败: 'dict' object has no attribute 'headers'
```
- 这是正常警告，系统会自动回退到 REST 兼容客户端
- 不影响功能使用

## 🎯 开发建议

1. **使用多个终端窗口**：前端和后端分别在独立终端运行
2. **保持服务运行**：开发期间保持前后端服务持续运行
3. **定期检查健康状态**：使用健康检查接口监控服务状态
4. **查看日志**：遇到问题时及时查看控制台日志
5. **环境变量**：确保每次启动后端时都设置了 JWT_SECRET
