## 🛠️ 工具和检查机制

### 1. 自动化检查工具
```bash
# 运行工作规则检查
npm run check-work-rules

# 代码质量检查
npm run lint
npm run type-check

# 格式化代码
npm run format
```

### 2. 检查结果解读
- **错误 (Error)**: 必须修复的严重问题
- **警告 (Warning)**: 建议修复的重要问题  
- **建议 (Info)**: 可选的优化建议

### 3. 质量评分系统
- **90-100分**: 优秀，符合所有规则要求
- **70-89分**: 良好，需要修复部分警告
- **50-69分**: 一般，存在较多问题
- **0-49分**: 需要改进，问题较多

## 🎯 规则执行指南

### 1. 日常开发流程

### 2. 问题解决流程

3. **修复问题**: 按照规则要求修复
4. **验证修复**: 重新运行检查确认
