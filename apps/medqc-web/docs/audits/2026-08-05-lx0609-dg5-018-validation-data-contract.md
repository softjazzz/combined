# DG-5：LX0609-018 验证数据合同闭环

## 结论

DG-5 已完成“资料合同”闭环，未修改 LX0609-018 执行器、Prompt、Canonical Envelope、API 或前端。

修复前，v3 中受影响的 32 份病例没有当前住院的 `admission_record`，因此 LX0609-018 在资料读取阶段统一返回 `data_gap`。本次仅在 v3 合成数据生成器中补齐当前住院入院记录、主诉和可接受的第一诊断，并确保主诉语境与第一诊断的主要临床方向一致。

资料补齐后，LX0609-018 不再因 `admission_record/chief_complaint` 缺失而产生 `data_gap`。真实的主诉与第一诊断不一致仍按规则输出不合规或待确认，没有为了减少数据不足而强行改判。
