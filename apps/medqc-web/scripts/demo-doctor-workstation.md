# 医生工作站演示指南

## 快速启动

### 1. 启动开发服务器
```bash
npm run dev
```

### 2. 访问演示页面
打开浏览器访问：`http://localhost:5173/demo`

## 演示流程

### 第一步：功能介绍
1. 点击"功能介绍"按钮查看核心功能特性
2. 了解智能病历编辑、实时质控分析等功能

### 第二步：选择演示场景
选择以下任一场景开始演示：

#### 完整病历演示
- **目的**：展示高质量病历的评分效果
- **特点**：评分90+，等级A，无严重问题
- **演示要点**：
  - 查看完整的病历内容
  - 观察高质量评分结果
  - 了解标准化病历格式

#### 不完整病历演示
- **目的**：展示缺失信息的识别和提示
- **特点**：评分45，等级C，存在完整性问题
- **演示要点**：
  - 查看不完整的病历内容
  - 观察质控系统如何识别缺失信息
  - 查看完整性改进建议

#### 数据不一致演示
- **目的**：展示逻辑一致性验证功能
- **特点**：评分65，等级B，存在一致性问题
- **演示要点**：
  - 查看前后不一致的数据
  - 观察一致性检查结果
  - 了解逻辑验证机制

#### 诊断不合理演示
- **目的**：展示合理性判断功能
- **特点**：评分30，等级C，存在合理性问题
- **演示要点**：
  - 查看不合理的诊断内容
  - 观察合理性分析结果
  - 了解专业判断建议

### 第三步：体验核心功能

#### 病历编辑功能
1. **文本编辑**：
   - 在编辑器中修改病历内容
   - 使用工具栏进行格式化
   - 观察自动保存功能

2. **模板插入**：
   - 点击"主诉"、"现病史"等模板按钮
   - 观察标准化内容的插入
   - 体验快速录入功能

3. **特殊符号**：
   - 点击特殊符号按钮
   - 插入医学符号和常用符号
   - 提升录入效率

#### 质控分析功能
1. **实时分析**：
   - 修改病历内容后点击"质控分析"
   - 观察分析过程和结果更新
   - 查看评分变化

2. **结果查看**：
   - 查看右侧质控分析面板
   - 观察评分仪表盘和等级评定
   - 了解详细的检查结果

3. **问题定位**：
   - 查看具体的质控问题
   - 了解问题所在位置
   - 查看严重程度分类

4. **改进建议**：
   - 查看系统提供的改进建议
   - 点击"应用建议"按钮
   - 观察建议应用效果

### 第四步：切换场景对比
1. 点击"切换场景"按钮
2. 选择不同的演示场景
3. 对比不同场景的质控效果
4. 理解质控系统的全面性

## 演示要点说明

### 智能化特性
- **自动保存**：编辑过程中自动保存草稿
- **实时反馈**：即时的质控分析和评分
- **智能建议**：基于AI的改进建议
- **可视化展示**：直观的评分和问题展示

### 质控维度
- **完整性**：检查必填字段和内容完整性
- **一致性**：验证数据前后逻辑一致性
- **合理性**：判断诊断与症状的匹配度
- **准确性**：检查数据格式和范围
- **及时性**：验证记录时间的及时性

### 用户体验
- **直观操作**：简洁明了的用户界面
- **快速响应**：流畅的交互体验
- **智能提示**：贴心的操作指导
- **专业展示**：医疗行业标准的展示效果

## 技术亮点

### 前端技术
- **Vue 3 Composition API**：现代化的组件开发
- **TypeScript**：类型安全的代码编写
- **响应式设计**：适配不同屏幕尺寸
- **组件化架构**：可复用的模块化设计

### 功能特性
- **富文本编辑器**：专业的病历编辑体验
- **实时质控引擎**：即时的质量检查
- **可视化组件**：直观的数据展示
- **模板系统**：标准化的内容管理

### 性能优化
- **防抖机制**：优化自动保存性能
- **懒加载**：按需加载组件和资源
- **缓存策略**：提升数据访问效率
- **响应式更新**：精确的数据更新
