## 📝 技术实现细节

### 统一响应格式

**成功响应**:
```python
return success_response(
    data={...},
    message="操作成功",
    trace_id=get_trace_id(request)
)
```

**分页响应**:
```python
return paginated_response(
    items=[...],
    total=100,
    page=1,
    page_size=10,
    message="获取列表成功",
    trace_id=get_trace_id(request)
)
```

**错误响应**:
```python
raise HTTPException(
    status_code=StatusCode.NOT_FOUND,
    detail="资源未找到"
)
```
