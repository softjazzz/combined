# 医疗质控系统运行病历模块产品需求文档（PRD）

## 1. 产品概述

### 1.1 产品背景
运行病历是指从患者入院到病历归档前的病历，运行病历质控（也称环节质控）是对这类病历进行的质量控制。本模块旨在为质控人员提供高效的运行病历质控管理工具。

### 1.2 产品目标
- 提供全面的运行病历查询和筛选功能
- 支持缺陷和病历的批量操作管理
- 实现高效的质控流程和状态管理
- 提供详细的病历质控详情查看功能

### 1.3 目标用户
- 医院质控管理员
- 质控专员
- 临床质控人员

## 2. 功能需求详述

### 2.1 查询功能

#### 2.1.1 时间周期查询
**功能描述：** 支持按不同时间维度查询运行病历数据

**输入参数：**
- 全部：查询所有时间范围的数据
- 近7日：查询最近7天的数据
- 月：查询当前月份的数据
- 季度：查询当前季度的数据
- 年：查询当前年度的数据
- 自定义周期：用户自定义开始和结束时间

**业务逻辑：**
1. 默认选择"全部"
2. 选择时间周期后，系统自动刷新列表数据
3. 自定义周期需要验证开始时间不能晚于结束时间
4. 时间范围最大不超过1年

**输出结果：** 符合时间条件的病历/缺陷列表

#### 2.1.2 评分标准查询
**功能描述：** 按照不同的评分标准筛选病历数据

**输入参数：**
- 评分标准下拉列表（从系统配置中获取）

**业务逻辑：**
1. 下拉框显示所有可用的评分标准
2. 支持单选，默认为"全部"
3. 选择后立即生效，刷新列表数据

**输出结果：** 符合评分标准的病历/缺陷列表

#### 2.1.3 病历信息查询
**功能描述：** 支持按病历关键信息进行精确查询

**输入参数：**
- 查询类型：登记号、流水号、病案号、患者姓名、临床医生姓名
- 查询内容：用户输入的查询关键词

**业务逻辑：**
1. 支持模糊匹配和精确匹配
2. 输入内容不能为空
3. 支持回车键快速查询
4. 查询结果实时显示匹配数量

**输出结果：** 符合查询条件的病历/缺陷列表

### 2.2 筛选功能

#### 2.2.1 新建筛选
**功能描述：** 创建新的筛选条件，支持生成快捷模板

**输入参数：**
- 基础设置：是否生成快捷模板（默认"是"）
- 快捷模板名称（当选择生成模板时必填）
- 各种筛选条件（支持多选）

**业务逻辑：**
1. 弹出筛选配置弹窗
2. 基础设置默认选择"生成快捷模板"
3. 生成模板时，模板名称为必填项，不能重复
4. 筛选条件支持单选和多选
5. 提交后立即生效并刷新列表
6. 如果选择生成模板，保存到快捷筛选中

**操作按钮：**
- 提交：应用筛选条件
- 清空：清空所有筛选条件
- 取消：关闭弹窗，不应用筛选

**输出结果：** 
- 应用筛选条件后的列表数据
- 生成的快捷筛选模板（如果选择）

#### 2.2.2 快捷筛选
**功能描述：** 使用已保存的筛选模板快速筛选

**输入参数：**
- 已保存的快捷筛选模板

**业务逻辑：**
1. 显示所有已保存的快捷筛选模板
2. 点击模板名称立即应用筛选条件
3. 支持对模板进行"修改"和"删除"操作
4. 删除操作需要确认提示

**模板管理：**
- 修改模板：可以修改筛选条件和模板名称
- 删除模板：删除后不可恢复，需要确认

**输出结果：** 应用模板筛选条件后的列表数据

#### 2.2.3 修改筛选
**功能描述：** 修改当前的筛选条件

**输入参数：**
- 当前筛选条件
- 新的筛选条件配置

**业务逻辑：**
1. 弹出筛选配置弹窗，显示当前筛选条件
2. 用户可以修改任意筛选条件
3. 支持"提交"、"提交并保存为模板"两种操作

**操作按钮：**
- 提交：仅应用当前筛选
- 提交并保存为模板：应用筛选并保存为新模板
- 清空：清空所有筛选条件
- 取消：关闭弹窗

**输出结果：** 修改后的筛选条件和对应的列表数据

#### 2.2.4 重置筛选
**功能描述：** 恢复到默认筛选条件

**默认筛选条件：**
- 缺陷列表页：缺陷状态为"临床申诉，待整改"
- 病历列表页：审核状态为"待审核，待复审"

**业务逻辑：**
1. 一键重置到默认筛选条件
2. 立即刷新列表数据
3. 清空当前的自定义筛选条件

**输出结果：** 应用默认筛选条件后的列表数据

### 2.3 缺陷列表页功能

#### 2.3.1 导出全部列表
**功能描述：** 导出当前筛选条件下的缺陷列表数据

**输入参数：**
- 当前筛选和查询条件

**业务逻辑：**
1. 最多导出前1万条缺陷数据
2. 导出格式为Excel文件
3. 包含所有列表字段信息
4. 导出过程显示进度提示
5. 导出完成后提供下载链接

**数据限制：**
- 最大导出数量：10,000条
- 超出限制时提示用户缩小查询范围

**输出结果：** Excel格式的缺陷列表文件

#### 2.3.2 批量操作
**功能描述：** 对选中的缺陷进行批量催办操作

**输入参数：**
- 选中的缺陷列表（通过勾选框选择）

**业务逻辑：**
1. 勾选缺陷后，"批量催办"按钮高亮可用
2. 支持全选和单选
3. 批量操作前需要确认提示
4. 操作过程显示进度条
5. 操作完成后显示成功/失败统计

**操作限制：**
- 只能对"待整改"状态的缺陷进行催办
- 已催办的缺陷不能重复催办

**输出结果：** 
- 批量操作结果统计
- 更新缺陷状态

#### 2.3.3 查看详情
**功能描述：** 查看单个缺陷的详细信息和电子病历

**触发方式：**
- 点击缺陷登记号、流水号、病案号
- 点击操作列的"详情"按钮

**详情页面内容：**

**病历基本信息：**
- 登记号、流水号、病案号
- 患者姓名、科室
- 病历评分（支持修改评分标准）

**电子病历查看：**
- 左侧：单据类别选择
- 中间：病历内容显示
- 右侧：缺陷分类（全部、单否、人工、核心、编码）
- 支持结构化查看

**质控操作：**
- 查看操作记录
- 病历催办
- 新增质控意见
- 重新质控
- 审核存疑
- 审核通过

**业务逻辑：**
1. 点击缺陷可高亮显示并定位到病历位置
2. 评分标准修改立即生效
3. 所有操作记录可追溯

#### 2.3.4 催办/撤回催办
**功能描述：** 对单个缺陷进行催办或撤回催办操作

**催办功能：**
- 适用状态：待整改的缺陷
- 操作结果：医生端收到催办通知
- 状态变更：缺陷状态更新为"已催办"

**撤回催办功能：**
- 适用状态：已催办的缺陷
- 操作结果：取消催办通知
- 状态变更：缺陷状态恢复为"待整改"

**业务逻辑：**
1. 根据缺陷当前状态显示对应按钮
2. 操作前需要确认提示
3. 操作后立即更新列表状态
4. 记录操作日志

#### 2.3.5 标记为已整改/查看整改
**功能描述：** 管理缺陷的整改状态和查看整改详情

**查看整改功能：**
- 适用状态：缺陷状态为"已整改"
- 功能：进入整改详情界面
- 显示内容：整改前后内容对比，整改字段高亮显示

**标记为已整改功能：**
- 适用条件：质控方式为"人工质控"
- 操作权限：质控人员手工标记
- 状态变更：缺陷状态更新为"已整改"

**业务逻辑：**
1. 根据质控方式和缺陷状态显示对应功能
2. 整改对比界面支持字段级别的差异显示
3. 标记操作需要记录操作人和操作时间

#### 2.3.6 自定义列显示
**功能描述：** 用户可以自定义缺陷列表的显示列

**输入参数：**
- 可选择的列字段列表
- 用户选择的显示列

**业务逻辑：**
1. 点击列表右侧的设置按钮打开配置弹窗
2. 左侧显示所有可选字段，右侧显示已选字段
3. 支持拖拽调整列的显示顺序
4. 配置保存到用户个人设置中
5. 支持恢复默认配置

**列表功能：**
- 排序：支持升序、降序、取消排序
- 筛选：支持按列内容筛选关键字

**输出结果：**
- 个性化的列表显示配置
- 优化的列表查看体验

### 2.4 病历列表页功能

#### 2.4.1 导出质控详情
**功能描述：** 导出运行病历的质控详情列表

**输入参数：**
- 当前筛选和查询条件

**业务逻辑：**
1. 导出当前筛选条件下的质控详情数据
2. 最多导出前1万条记录
3. 包含病历基本信息和质控详细信息
4. Excel格式导出

**导出内容：**
- 病历基本信息
- 质控结果详情
- 缺陷统计信息
- 质控时间和人员信息

#### 2.4.2 导出全部列表
**功能描述：** 导出运行病历列表数据

**输入参数：**
- 当前筛选和查询条件

**业务逻辑：**
1. 导出当前筛选条件下的病历列表
2. 最多导出前1万条记录
3. 包含病历列表的所有显示字段
4. Excel格式导出

**数据限制：**
- 最大导出数量：10,000条
- 导出格式：Excel (.xlsx)

#### 2.4.3 批量操作
**功能描述：** 对选中病历进行批量操作

**支持的批量操作：**
- 批量重新质控
- 批量通过
- 批量催办

**输入参数：**
- 选中的病历列表

**业务逻辑：**
1. 勾选病历后，对应的批量操作按钮高亮
2. 批量重新质控：重新执行质控规则
3. 批量通过：将病历状态更新为"审核通过"
4. 批量催办：向医生端发送催办通知

**操作限制：**
- 批量通过：仅适用于"待审核"状态的病历
- 批量催办：不能对已催办的病历重复催办
- 批量重新质控：需要确认操作，可能覆盖现有质控结果

#### 2.4.4 查看详情
**功能描述：** 查看病历详细信息，支持病历间切换

**触发方式：**
- 点击病历登记号、流水号、病案号
- 点击操作列的"详情"按钮

**详情页面功能：**
- 病历基本信息显示
- 电子病历查看
- 质控操作功能
- 上个病历/下个病历切换

**切换逻辑：**
1. 按照当前列表的排序顺序进行切换
2. 到达列表边界时按钮置灰
3. 切换时保持筛选条件不变

#### 2.4.5 催办/撤回催办
**功能描述：** 对单个病历进行催办管理

**催办功能：**
- 向医生端发送催办通知
- 更新病历催办状态
- 记录催办时间和操作人

**撤回催办功能：**
- 取消催办通知
- 恢复病历原始状态
- 记录撤回操作

**业务逻辑：**
1. 根据病历当前催办状态显示对应按钮
2. 催办通知包含病历基本信息和催办原因
3. 操作记录可追溯查询

#### 2.4.6 通过/审核存疑
**功能描述：** 对待审核病历进行审核决策

**通过功能：**
- 适用状态：待审核的病历
- 操作结果：病历状态更新为"审核通过"
- 业务影响：病历进入下一个流程环节

**审核存疑功能：**
- 适用状态：待审核的病历
- 输入参数：审核存疑信息（必填）
- 操作结果：病历状态更新为"审核存疑"
- 通知机制：医生端收到存疑通知

**业务逻辑：**
1. 仅对"待审核"状态的病历显示操作按钮
2. 审核存疑需要填写存疑原因
3. 操作后立即更新病历状态
4. 所有审核操作记录可追溯

#### 2.4.7 自定义列显示
**功能描述：** 个性化配置病历列表显示列

**功能特性：**
- 自定义显示列选择
- 列排序功能（升序、降序、取消排序）
- 列筛选功能（关键字筛选）
- 配置保存到个人设置

**操作方式：**
1. 点击列表右侧设置按钮
2. 在弹窗中选择要显示的列
3. 拖拽调整列的显示顺序
4. 确认保存配置

## 3. 用户权限和操作限制

### 3.1 用户角色权限
- **质控管理员**：拥有所有功能权限
- **质控专员**：拥有查看、筛选、催办、标记整改权限
- **临床质控人员**：拥有查看、筛选权限

### 3.2 操作限制
- 导出功能：单次最多1万条记录
- 批量操作：单次最多选择500条记录
- 筛选模板：每个用户最多保存20个模板
- 自定义列：最多显示15列

### 3.3 数据权限
- 按科室权限控制数据可见性
- 按时间范围限制历史数据访问
- 敏感操作需要二次确认

## 4. 数据格式和接口规范

### 4.1 导出数据格式
- 文件格式：Excel (.xlsx)
- 字符编码：UTF-8
- 日期格式：YYYY-MM-DD HH:mm:ss
- 数值格式：保留2位小数

### 4.2 状态定义
**缺陷状态：**
- 待整改
- 已催办
- 已整改
- 临床申诉

**审核状态：**
- 待审核
- 待复审
- 审核通过
- 审核存疑

### 4.3 业务规则
- 病历质控流程不可逆转
- 催办操作有时间间隔限制（24小时内不能重复催办）
- 批量操作需要事务性保证
- 所有关键操作必须记录日志

## 5. 性能要求

### 5.1 响应时间
- 列表查询：≤ 3秒
- 详情页面加载：≤ 2秒
- 导出操作：≤ 30秒
- 批量操作：≤ 60秒

### 5.2 并发要求
- 支持100个用户同时在线操作
- 支持10个用户同时进行导出操作

### 5.3 数据量要求
- 单次查询最多返回1万条记录
- 支持百万级别的历史数据查询

## 6. 异常处理

### 6.1 网络异常
- 操作超时自动重试
- 网络中断时保存用户操作状态
- 提供离线提示和恢复机制

### 6.2 数据异常
- 数据不一致时提供刷新机制
- 并发操作冲突时提示用户
- 数据导出失败时提供重试选项

### 6.3 权限异常
- 权限不足时提供明确提示
- 会话过期时自动跳转登录页
- 操作被拒绝时记录日志
