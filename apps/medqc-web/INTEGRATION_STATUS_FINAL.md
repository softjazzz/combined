## 🚀 **立即可用的部署方案**

### 📋 **一键部署** (推荐)
```bash
# 运行快速部署脚本
./tools/deployment/quick_deploy.sh
```

### 📋 **手动部署**
```bash
# 1. 安装前端依赖
pnpm install  # 或 npm install

# 2. 安装后端依赖
cd production_system && pip install -r requirements.txt

# 3. 配置环境变量
cp .env.example .env  # 并填入正确配置

# 4. 初始化数据库
# 在 Supabase SQL Editor 中执行 database/setup/ 下的脚本

# 5. 启动服务
pnpm dev  # 前端
python production_system/main.py  # 后端
```
