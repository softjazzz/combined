## 常驻约束

- 默认范围为本仓库；用中文沟通、注释和提交，文本用 UTF-8 无 BOM、LF。跨会话任务先读 `docs/plans/PROJECT_ROLLING_TODO.md` 的当前焦点及专题接续卡，不重读全部历史。
- 修改前核对真实调用链、问题证据和验收标准；以 1–2 个业务点做最小闭环。主协调 Agent 亲自审查关键 diff、模型输入、结果、调用量和真实病例证据；子代理结论须独立复核，多 Agent 只并发处理边界清晰的工作。

- 兼容路径留在旧入口；新主链不依赖旧 payload。比较同输入的状态、原因、事实、证据、LLM 调用/Token 和耗时。大文件继续扩张或结构拆分时，先说明职责边界并单独验证行为等价；普通 DTO/Prompt/trace 不重复加 digest。
