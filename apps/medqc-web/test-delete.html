医疗记录删除功能测试

测试步骤：

  1. 打开浏览器开发者工具 (F12)
  2. 访问 医疗记录管理页面
  3. 选择一条测试记录（如 TEST20250828003）点击删除
  4. 观察控制台输出和页面反应

预期行为：

  • ✓ 点击删除按钮后显示确认对话框
  • ✓ 确认删除后调用 Supabase API
  • ✓ 删除成功后显示成功消息
  • ✓ 列表自动刷新，删除的记录消失
  • ✓ 如果删除失败，显示错误消息

调试信息：

如果删除功能仍有问题，请检查浏览器控制台的以下信息：

  • Network 标签：是否有对 Supabase 的 DELETE 请求
  • Console 标签：是否有 JavaScript 错误
  • 删除前后的记录数量：页面顶部统计数字是否更新
