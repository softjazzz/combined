# 智慧医保临床实时质控系统 - 规则管理页面重新设计总结

## 🎯 项目概述

本次重新设计了智慧医保临床实时质控系统中的规则管理页面UI，主要目标是：
- 使用现代化的设计语言和组件
- 提升用户体验和界面美观度
- 保持技术栈的一致性（完全使用Tailwind CSS）
- 符合医保质控系统的业务需求

## 🛠️ 技术栈

- **前端框架**: Vue 3 + TypeScript
- **UI组件库**: Ant Design Vue 4.x
- **样式框架**: Tailwind CSS（完全替换自定义CSS）
- **状态管理**: Pinia
- **数据库**: Supabase (PostgreSQL)
- **构建工具**: Vite

## 数据模型

### 核心表结构

```sql
-- 规则主表
yibao_rules (
  id, code, name, description, rule_type, 
  category_id, severity, enabled, version, 
  metadata, created_at, updated_at
)

-- 规则触发器
yibao_rule_triggers (
  id, rule_id, event_type, priority, description
)

-- 规则条件
yibao_rule_conditions (
  id, rule_id, priority, expression_json
)

-- 规则动作
yibao_rule_actions (
  id, rule_id, action_type, message_template
)
```

### 规则类型

- `drug_age` - 年龄限制
- `drug_gender` - 性别限制  
- `visit_type` - 就诊方式
- `hospital_level` - 机构级别
- `duration` - 疗程限制
- `surgery_pricing` - 手术折价

### 严重级别

- `info` - 信息提示
- `warn` - 警告
- `block` - 阻断
