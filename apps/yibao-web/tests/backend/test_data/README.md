# 🧪 Yibao医保质控系统测试数据集

## 📋 概述

本目录包含为Yibao智慧医保临床实时质控系统生成的完整测试数据集，用于验证1173条医保规则的正确性和系统功能的稳定性。

## 📁 文件结构

```
test_data/
├── README.md                          # 本文档
├── medical_records_generator.py       # 医疗病历数据生成器
├── rule_test_cases.py                 # 规则测试用例生成器
├── test_runner.py                     # 测试执行器
├── validate_test_data.py              # 测试数据验证器
├── test_medical_records.json          # 生成的医疗病历数据(50条)
├── rule_test_cases.json               # 生成的规则测试用例(100条)
└── validation_report_*.json           # 数据验证报告
```

## 🎯 测试数据特点

### 医疗病历数据 (test_medical_records.json)
- **总记录数**: 50条
- **数据完整性**: 100%有效
- **覆盖场景**: 7种主要测试场景
- **数据分布**:
  - 年龄分布: 涵盖新生儿到老年人各年龄段
  - 性别分布: 男女比例均衡
  - 医保类型: 城镇职工、城镇居民、新农合、自费等
  - 就诊类型: 门诊、急诊、住院、体检

### 规则测试用例 (rule_test_cases.json)
- **总用例数**: 100条
- **规则覆盖**: 50条医保规则
- **测试类型**:
  - `trigger`: 触发规则的测试用例 (50条)
  - `pass`: 不触发规则的测试用例 (50条)
  - `boundary`: 边界条件测试用例
- **期望结果分布**:
  - `pass`: 正常通过
  - `info`: 信息提示
  - `warn`: 警告提醒
  - `block`: 拦截阻止

## 🏥 测试场景覆盖

### 1. 药品性别限制测试
- **场景**: 女性患者使用限男性药品
- **规则类型**: `drug_gender`
- **期望结果**: `block`
- **示例**: 女性患者使用阿帕他胺片

### 2. 药品年龄限制测试
- **场景**: 未成年人使用成人专用药品
- **规则类型**: `drug_age`
- **期望结果**: `warn`
- **示例**: 16岁患者使用成人专用药品

### 3. 儿童专用药品测试
- **场景**: 成人使用儿童专用药品
- **规则类型**: `drug_children`
- **期望结果**: `block`
- **示例**: 25岁患者使用儿童专用药品

### 4. 医保类型限制测试
- **场景**: 自费患者使用特定药品
- **规则类型**: `drug_insurance_type`
- **期望结果**: `info`
- **示例**: 自费患者使用疤痕止痒软化膏

### 5. 就诊方式限制测试
- **场景**: 门诊患者使用住院专用药品
- **规则类型**: `visit_type`
- **期望结果**: `warn`
- **示例**: 门诊开具住院专用药品

### 6. 住院天数超限测试
- **场景**: 住院天数超过限制
- **规则类型**: `duration`
- **期望结果**: `warn`
- **示例**: 住院35天超过30天限制

### 7. 正常通过测试
- **场景**: 正常医疗行为
- **规则类型**: `normal`
- **期望结果**: `pass`
- **示例**: 符合所有规则的正常处方

## 🚀 使用方法

### 1. 生成新的测试数据

```bash
# 生成医疗病历数据
cd apps/yibao-web/backend/test_data
python3 medical_records_generator.py

# 生成规则测试用例
python3 rule_test_cases.py
```

### 2. 验证测试数据质量

```bash
# 验证数据完整性和有效性
python3 validate_test_data.py
```

### 3. 执行测试用例

```bash
# 运行测试套件(需要API服务运行)
python3 test_runner.py
```
